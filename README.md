# Agent Self-Evolution Observatory

A CVPR-oriented research website mapping self-evolving visual and multimodal agents.

## Website

- Custom domain: `https://agent-evolution.lightrain.asia`
- GitHub Pages fallback: `https://lightrain-a.github.io/agent-self-evolution-observatory/`

## Current contents

- Strict definition of self-correction vs. self-evolution
- Four-axis knowledge map
- Interactive literature matrix with 57 papers
- Open-problem map
- Six-stage idea iteration log
- Four CVPR candidate ideas
- GroundEvo experiment roadmap

The site is a dependency-free static page. Open `index.html` directly or publish the repository root with GitHub Pages.
