\section{Frozen Deterministic State Semantics}

The state-level intervention uses the exact initial spreadsheet skill plus the following incremental procedural semantics.

\paragraph{G1: output verification.}
After saving \texttt{output.xlsx}, reload it with \texttt{load\_workbook("output.xlsx", data\_only=True)} and verify the exact target cells before stopping. If verification fails, fix and save again.

\paragraph{G2: completion loop.}
For each spreadsheet task: (1) inspect workbook structure and target cells, (2) read required source data, (3) compute requested values, (4) materialize values into exact target cells, (5) save \texttt{output.xlsx} without modifying the input, and (6) reload and verify the target cells. Inspection alone is not completion.

\paragraph{G3: tool-error recovery.}
In addition to G2, if a shell, Python, or tool invocation fails or is malformed, issue a clean corrected command rather than stopping or repeating the same broken call unchanged, then continue through write, save, reload, and verification.

The automatic compiler's canonical primitive surfaces reproduce these frozen state texts byte-for-byte for corresponding typed diagnoses.
