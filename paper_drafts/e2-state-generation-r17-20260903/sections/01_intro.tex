\section{Introduction}

Self-evolving agents persist experience as skills, prompts, or memories that alter future behavior. A common abstraction is evidence $E$ entering an updater $U$, which produces persistent state $S$ for a future policy $\pi$: $E\!\rightarrow\!U\!\rightarrow\!S\!\rightarrow\!\pi\!\rightarrow\!Y$. Existing evaluations mostly intervene on $E$---success versus failure feedback, different history windows, or different retrieved trajectories---while treating $U$ as a stable conduit. But when $S$ is itself free-form generated text, that assumption need not hold: the same evidence can be rewritten with different scope, redundancy, or procedural specificity, and those state realizations may induce different behavior.

We encounter this issue while studying best-of-$K$ skill evolution. Search generates several trajectories; a verifier selects one winner for acting; a persistent updater later receives a projection of the same frozen pool. Our initial question was whether the trajectory worth serving is necessarily the trajectory worth learning from. Holding the search pool, served winner, initial skill, updater, and evaluation harness fixed, we replaced winner evidence with a deterministic rejected witness. Across 48 matched pairs, the mean effect was only +2.31 percentage points, with substantial stream heterogeneity; the preregistered superiority test did not pass. Thus the simple claim that rejected failures are universally better learning evidence is unsupported.

We then used the negative result to localize the bottleneck rather than tuning the evidence selector until it passed. A progress-based ``diagnostic'' witness selector failed its frozen continuation gate. In contrast, a historically strong First-Fail state remained directionally useful when frozen and re-evaluated. Most importantly, reconstructing the \emph{byte-identical updater evidence} did not regenerate the historical advantage: two fresh updater realizations produced matched downstream contrasts of 0/18 and $-1$/18. The evidence was the same; the generated persistent state was not equivalently useful.

This observation motivates the causal decomposition
\begin{equation}
T_K \xrightarrow{g} E \xrightarrow{U} S \xrightarrow{\pi} Y,
\end{equation}
where $T_K$ is the generated pool, $g$ is the learning projection, and $U$ is an explicit experimental factor rather than hidden plumbing. Evidence selection and state synthesis are different causal objects. Conflating them can make a lucky state realization look like an evidence effect, or make useful evidence look ineffective because the updater encoded it poorly.

We therefore study \emph{variance-controlled persistent-state generation}. At the state level, a deterministic repair ladder tests whether compact procedural semantics are sufficient. At the method level, a prospective $2\times2$ bridge crosses evidence source (Winner vs. First-Fail-4) with state generator (native free-form updater vs. a typed canonical compiler). A score-matched trajectory-blind control asks whether the compiler merely notices failures and injects generic workflow hygiene. SCREEN and VALIDATION use disjoint heldout panels, and failure of an upstream gate cannot be rescued by opening E3 or another backbone.

The novelty is deliberately narrow. Rethinking Self-Evolving Agent Skills already establishes feedback-dependent and heterogeneous skill evolution~\citep{liu2026rethinking}; SkillRevise already performs execution-grounded diagnosis and repair-principle-guided skill revision~\citep{liu2026skillrevise}; WikiSkill already separates raw experience, persistent knowledge, and executable skills~\citep{tang2026wikiskill}. We do not claim ``failures help,'' structured diagnosis, or experience-to-knowledge compilation as new. Our residual object is whether \emph{state-generation realization itself} is an independently identifiable bottleneck under matched evidence, and whether controlling that interface changes future utility.

\paragraph{Contributions.}
(1) We separate learning projection, state generation, persistent-state semantics, and downstream execution in a causal model of skill self-evolution. (2) We provide a mechanism-localization chain in which a strong frozen state survives remeasurement but byte-identical evidence fails to regenerate its historical effect. (3) We introduce a canonical typed state compiler and a prospective Evidence$\times$Generator experiment that tests generator and evidence effects separately. (4) We preregister falsifiers and decision rules so that a compiler win without a failure-evidence win remains a state-compilation result rather than being promoted into a rejected-trajectory claim.
