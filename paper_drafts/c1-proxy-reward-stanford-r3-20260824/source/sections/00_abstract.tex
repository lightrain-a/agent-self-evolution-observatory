\begin{abstract}
Self-improving agents increasingly turn terminal reward into persistent natural-language memory, so an evaluator error can alter the state reused by later episodes. We isolate this channel in the released ReasoningBank implementation using WebArena Shopping trajectories. Holding each source trajectory byte-identical, flipping only the reward-conditioned reflection mode changes all four complete paired memories, with mean token-set Jaccard distance 0.735; two additional failure-arm writes terminate at the provider response-state layer and remain a selection limitation. On a disjoint eight-trajectory control, reward-mode content divergence (0.700) exceeds stronger semantic-preserving same-mode rewording (0.595), with paired excess 0.105 and exact $p=0.0078$. Reusing the paired states changes the next structured action in 7 of 12 aligned probes. A frozen $4\times4$ source-memory--future-task terminal replication completes 256 fresh rollouts and yields mean absolute success-rate difference 0.15625 ($p=0.00074$). Effects are heterogeneous: 8/16 cells are zero, and a descriptive two-way decomposition assigns 84.1\% of centered signed-effect variation to source--future interaction rather than source or future main effects. In this configuration, reward reliability is therefore a state-consistency requirement when terminal outcomes determine persistent memory. The terminal estimand is failure-conditioned versus success-conditioned memory, not memory versus omission.
\end{abstract}
