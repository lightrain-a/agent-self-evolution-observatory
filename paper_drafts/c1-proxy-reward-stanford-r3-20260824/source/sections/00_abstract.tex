\begin{abstract}
Self-evolving agents often turn terminal self-evaluation into persistent memory, so a wrong label can become a state update rather than merely a scoring error. We study where such a label-only intervention survives along the write$\rightarrow$retrieval$\rightarrow$policy-uptake$\rightarrow$outcome path in released ReasoningBank/WebArena Shopping. Holding each source experience byte-identical, success/failure reflection produces different durable memories on 20/20 complete paired sources; reward-mode divergence also exceeds a stronger same-mode wording control (0.700 vs. 0.595; $p=0.0078$). Forced memory injection shows latent leverage (mean terminal $|\Delta|=0.15625$, $p=0.00074$), but those futures are not native retrieval hits. After expanding the bank, 125/172 held-out Shopping tasks retrieve a source memory, yet 36 frozen native-hit tasks show weak branch-specific transport: terminal $|\Delta|=0.02083$ ($p=0.4289$), and first-action TV is 0.06944 ($p=0.5801$) with 0/36 modal branch differences. A stronger same-information outcome-blind structured-memory control also misses the 0.15 terminal floor (0.04514, $p=0.0048$); 30/36 tasks have identical success, failure, neutral, raw-trajectory, and no-memory point estimates. Thus reward labels robustly change stored text, while exposure, branch-specific uptake, and realized outcome are distinct gates.
\end{abstract}
