\section{Related Work}
\paragraph{Reward and judge reliability.} JudgeBench and RewardBench establish that LLM judges and reward models can be unreliable before their outputs are used for learning~\citep{tan2025judgebench,lambert2024rewardbench}; Plan-RewardBench shows additional brittleness on tool-integrated trajectories~\citep{wang2026planrewardbench}. Our question begins one step later: what persistent state is created when such a terminal label selects a memory-writing objective?

\paragraph{Outcome-conditioned and learned memory construction.} ReasoningBank explicitly distills different memories from successful and failed trajectories~\citep{ouyang2026reasoningbank}, Reflexion stores evaluative verbal feedback for later trials~\citep{shinn2023reflexion}, and Agent Workflow Memory extracts reusable procedures from interaction histories~\citep{wang2024awm}. More directly, Mem-$\alpha$ learns how to construct external memory from downstream question-answering reward~\citep{wang2025memalpha}, while AttriMem augments outcome reward with attribution-derived process feedback to learn a memory-construction policy~\citep{li2026attrimem}. Thus feedback-driven memory construction is already prior work. Our intervention does not learn a writer policy: it freezes an existing success/failure writer pair, holds the source trajectory byte-identical, and changes only the terminal label selecting that writer mode.

\paragraph{Memory valuation, reuse, and self-improvement variance.} Memory Reward Inflation studies how imperfect proxy reward can be amplified as memories are scored and reused~\citep{asadolahi2026inflation}. RoMeRL addresses misleading trajectory-level utility updates through reduced-order memory utility states~\citep{yang2026romerl}. Ye et al. show run-to-run variance, curriculum sensitivity, and memory underspecification~\citep{ye2026fragility}. These closest works cover downstream valuation and reuse; our residual object is upstream write-time state construction followed by matched downstream action and terminal tests.

\paragraph{Claim boundary.} The paper therefore does not claim generic evaluator robustness, reward-driven memory construction as a new paradigm, universal harm from failure memories, or a new memory architecture. It identifies one narrower causal channel: with the construction policy held fixed, a reward-label error can select a different existing writer objective for an otherwise identical episode, and the resulting persistent state can change later behavior under the frozen configuration.
