\section{Experimental Setup}
\label{sec:setup}
\paragraph{Frozen units and benchmark.}
We use released WebArena Shopping task metadata and released ReasoningBank trajectories rather than collecting a new self-improvement stream. F0 requests six source trajectories balanced across their original benchmark outcomes; only the four source pairs complete in both writer conditions and are eligible for paired or downstream analysis. The prompt-sensitivity control uses eight disjoint trajectories. Terminal confirmation crosses the four complete source-memory pairs with four future tasks frozen before terminal-policy calls, yielding 16 cells.

\paragraph{Models, controls, and metrics.}
DeepSeek-V4-Flash is the memory writer at temperature zero. The decisive terminal replication uses Doubao Seed 2.0 Mini at temperature 0.2 with eight fresh rollouts per memory condition in every cell. The strongest simple writer-side reduction is a same-mode semantic-preserving prompt rewording that is lexically larger than the released success/failure instruction difference. Primary observables are token-set Jaccard distance for the written state, structured-action disagreement for behavioral reachability, and absolute terminal success-rate difference under the original deterministic WebArena evaluator. The terminal significance audit permutes memory labels within frozen cells for 100,000 draws.

\paragraph{Execution accounting and reliability.}
The study is inference-only: it performs no parameter training or local GPU fine-tuning. F0 makes 12 writer requests; 10 complete and two failure-arm calls terminate before assistant text exists. F0C makes 32 writer requests and all complete. The earlier action-existence stage contains 12 aligned paired units. Its larger distributional stress test (F1D) uses four states with eight success-memory, eight failure-memory, and eight no-memory samples per state, for 96 policy calls. The initial terminal stage uses 96 primary memory-conditioned calls plus 12 no-memory calls and does not pass its frozen gate. F2R1 then uses 256 fresh terminal-policy calls and all complete. Thus the frozen stages expose 504 directly countable writer/policy requests, excluding the low-level request count of the earlier 12-unit action-existence witness because that receipt is not available at request-level granularity in the current acceptance bundle. Raw provider outputs are content-addressed before analysis; incomplete arms are not regenerated or imputed. The 12 no-memory calls belong only to the non-passing initial terminal stage; F2R1 intentionally contains no no-memory arm, so its confirmatory estimand remains success-conditioned versus failure-conditioned memory under matched evidence.
