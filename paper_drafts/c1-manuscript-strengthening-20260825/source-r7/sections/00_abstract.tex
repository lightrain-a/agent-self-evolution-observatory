\begin{abstract}
Self-improving agents often turn terminal feedback into persistent natural-language memory, creating a two-part scientific problem: \emph{how does feedback write different persistent state from the same experience, and why does that state difference not necessarily become a behavioral difference later?} We study both parts with frozen success-versus-failure writer branches on otherwise identical trajectories, while treating the released branch switch as a bundled writer-protocol intervention rather than a pure reward-bit manipulation. First, the write channel is robust: the intervention produces different persistent memories for all 20 Shopping pairs and all 4 Reddit pairs, and a stronger same-mode wording control still leaves a significant branch-mode excess. Second, the downstream story is selective. When branch-specific memory is mechanically supplied, it has measurable terminal leverage ($|\Delta|=0.15625$, $p=0.00074$). Under native reuse, however, Shopping retrieves the branch-conditioned source-memory item in 125/172 opportunities while the first-action branch contrast is not supported (TV $=0.06944$, $p=0.5801$, 0/36 modal changes) and terminal transport is sparse ($|\Delta|=0.02083$, $p=0.4289$, 34/36 zero). Reddit again shows reliable write divergence but sparse, sign-heterogeneous native terminal differences. We therefore follow the same persistent-state contrast through write, native exposure, first-action uptake, and outcome, with forced fixed-evidence exposure as a separate capacity control. The resulting stage signature reconciles an apparent contradiction: feedback-conditioned writing can reliably create different durable memory, and that difference can have behavioral leverage when supplied, yet the deployed native reuse chain need not transport it into stable decision-level change. On the frozen Shopping tests, action uptake is the first unsupported measured native stage after write and item-level exposure have been established. Because stage units and test sensitivities are not matched, this is an evidence-localization result rather than a causal mediation estimate. The paper thus connects two questions usually studied separately: how evaluative feedback becomes persistent agent state, and where that state loses behavioral authority during reuse.
\end{abstract}
