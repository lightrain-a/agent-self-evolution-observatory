\section{Limitations}
The released success/failure branch jointly changes reflection instruction and outcome/reward semantics; per-atom decoding-seed binding at the writer intervention is unavailable, two failure-label calls ended before assistant text, and source-faithful live WebArena navigation is unavailable. We therefore estimate a bundled writer-protocol contrast, not a pure reward-bit effect. The first-action B10 audit does contain repeated same-condition decodes and now has a replay-qualified collision/MMD$^2$ reanalysis, but that reanalysis is post-hoc rather than an independent prospective replication and therefore does not license an equivalence claim.

Stage tests differ in units, samples, power, and intervention surfaces, so first-action uptake is only an \emph{evidence-localization boundary}, not an identified latent attenuation onset or mediator. The 125/172 statistic is source-item retrieval, not residual exposure or policy use; forced injection bypasses native retrieval/context composition and measures supplied-evidence capacity.

Shopping is sparse (34/36 zero); Reddit is sparse, sign-heterogeneous (6/8 zero), and lacks matched exposure/action measurements, so neither a universal effect nor cross-domain action boundary is claimed. External validity is restricted to the frozen released writer/policy configuration and the Shopping+Reddit substrate evaluated here; other writers, backbones, domains, and memory architectures are untested. The CBRG extension stopped before behavioral evaluation; no behavioral repair efficacy is claimed.

\section{Conclusion}
Coarse views of the same update disagree. In Shopping, first-action uptake is the first unsupported measured native stage after write and source-item exposure---an evidence boundary, not a latent causal bottleneck. Thus \textbf{state divergence and retrieval exposure do not by themselves establish stable decision-level uptake}. The current contribution is stage-resolved identification of that boundary; selective post-exposure authorization remains a separate prospective hypothesis.
