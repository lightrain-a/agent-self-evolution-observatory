\subsection*{Reproducibility statement}
The R2 mechanism experiments replay released controller code without model calls or GPU execution. Skill-SP is pinned to author commit \texttt{bb693c89fee66e1f824d6a777759a49b7a295a83}. The post-selection counterfactual fixes the semantic feedback multiset byte-for-byte, removes selection/retrieval before evidence assignment, and changes only the exact identity partition or semantic aggregation of evidence. The phase audit evaluates 882 deterministic cells and checks every cell against the closed-form boundary. The 2$\times$2 decomposition independently varies semantic handling at selection and credit/lifecycle. The SkillsVote structural analogue is pinned to commit \texttt{55ea783d1818457e21ed12138309d8da7e58ceb8} and executes only the released feedback-to-request transformation; no updater model is called. Natural-prevalence claims are deliberately withheld because released Skill-SP runtime \texttt{skills.json} and retired ledgers are not available.
