\begin{abstract}
Self-evolving agents convert previous trajectories into reusable textual memory. Existing analyses usually treat the retrieved memory as the relevant state variable. We study a second variable carried into that state: the provenance of the trajectory from which the memory was written. A recent financial-agent audit reports a sharp provenance-conditioned split for ReasoningBank. Success-derived retrievals achieve 0.931 accuracy over 101 cases. Failure-derived retrievals achieve 0.647 accuracy over 34 cases. All ten reported persistent W$\rightarrow$W failures occur in the failure-derived stratum. We show that this pattern is compatible with a direct causal channel because ReasoningBank writes successful trajectories and failed trajectories through different reflection modes before future retrieval. We formulate memory provenance as an intervention variable and separate its causal effect from task difficulty through a matched-memory swap. The experiment holds the future query and semantic guidance fixed while replacing failure-derived memory with a success-derived counterpart. The reverse swap provides the complementary intervention. This design tests whether failure provenance itself sustains future error. Our source-grounded decomposition also reveals that the strongest observed provenance signal concerns persistence: most failures inside the failure-derived stratum are W$\rightarrow$W cases. This motivates provenance-aware memory governance for self-evolving agents. A memory should carry information about how it was learned because semantically similar advice can encode distinct process evidence when it originates from success or failure.
\end{abstract}
