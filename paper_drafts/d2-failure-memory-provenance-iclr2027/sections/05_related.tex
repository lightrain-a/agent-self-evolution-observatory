\section{Related Work}
\paragraph{Experience memory for self-evolving agents.} ReasoningBank turns previous trajectories into reusable reasoning memories and retrieves them for future tasks \citep{ouyang2026reasoningbank}. Agent Workflow Memory stores reusable task workflows induced from experience \citep{wang2024awm}. Reflexion uses verbal feedback as persistent context for later trials \citep{shinn2023reflexion}. These systems establish external textual state as an effective route to self-improvement. Our work adds trajectory provenance as a causal variable inside that state.

\paragraph{Failure memory and memory quality.} The financial-agent audit reports strong concentration of persistent failure in failure-derived ReasoningBank retrievals \citep{li2026audit}. Memory Reward Inflation shows that erroneous memories can gain excessive effective reward and propagate through future reuse \citep{asadolahi2026inflation}. These findings establish that memory quality affects future behavior. Our intervention isolates a more specific mechanism: the process provenance attached to semantically matched guidance.

\paragraph{Causal evaluation of memory.} Existing ablations often remove a memory module or compare agents with different memory banks. Those interventions change both information and provenance. The matched provenance swap preserves the actionable guidance seen by the future agent. This creates a same-information causal test for the history encoded in the memory itself.
