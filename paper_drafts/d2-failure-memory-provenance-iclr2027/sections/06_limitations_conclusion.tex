\section{Limitations}
The current public financial-agent release provides aggregate provenance counts and transition statistics. The matched provenance swap requires the first-party per-query memory artifacts or a faithful reconstruction of the audited ReasoningBank runs. Those artifacts are announced for release upon publication and are currently experiment debt. A source-faithful reconstruction preflight recovered AgentDojo v0.1.35 with Banking v1.2.2 and the official ReasoningBank memory implementation. The current execution route rejects the exact \texttt{qwen3.7-flash-2026-07-15} executor snapshot used by the source audit, and no credential is available for \texttt{qwen3.7-text-embedding}. Source-faithful reconstruction therefore remains support debt. These provider constraints carry no scientific authority.

The reported provenance accuracies are rounded to three decimals. The integer correct counts used in our decomposition are the unique counts consistent with the reported support sizes and rounded accuracies. The transition allocation beyond the ten W$\rightarrow$W cases is therefore a derived arithmetic decomposition from public aggregate statistics.

Semantic matching between failure-derived memory and success-derived memory is an experimental design challenge. A pair can preserve procedural content while differing in wording. We therefore require an information-equivalence audit before the swap. Pair construction and verifier agreement remain experiment debt until the first-party memory artifacts are available.

The causal claim concerns future persistence under matched memory information. The existing audit supports the provenance-conditioned association and identifies task difficulty as a confound. Direct causal effect size remains experiment debt for the swap experiment in Section~\ref{sec:intervention}.

The empirical source is a financial AgentDojo setting with ReasoningBank. Replication in web agents and other external-memory architectures remains experiment debt for a broader cross-domain claim. As a narrow bridge, we held a generic procedural guidance string byte-identical and changed only structured source-outcome metadata across six fresh fixed-evidence WebArena tasks. All 144 requested calls completed. SUCCESS-provenance and FAILURE-provenance conditions produced identical task-level terminal correctness, giving a mean signed difference of 0.000. This bridge had no preregistered equivalence margin, so the result is inconclusive and has no negative authority for the natural failure-derived-memory claim. It also does not replace the source-faithful matched-memory swap because the bridge manipulates explicit provenance metadata instead of naturally generated ReasoningBank memories.

\section{Conclusion}
Self-evolving memory carries process history. The released financial-agent audit shows a large accuracy gap by memory provenance and concentrates every reported persistent W$\rightarrow$W failure in failure-derived retrievals. ReasoningBank makes provenance an upstream intervention because successful trajectories and failed trajectories are written through different reflection objectives.

We formalize the causal effect of that provenance and define a matched-memory swap that holds the future query and actionable guidance fixed. This turns memory provenance into an experimentally identifiable variable. The resulting perspective suggests a concrete design principle for self-evolving agents: store how a memory was learned and use that evidence when deciding how strongly future behavior should trust it.
