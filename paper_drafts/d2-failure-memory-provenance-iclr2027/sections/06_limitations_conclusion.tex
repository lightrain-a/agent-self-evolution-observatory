\section{Limitations}
The financial AgentDojo audit remains the source of the 0.931-versus-0.647 provenance association and the ten persistent W$\rightarrow$W cases. Its public release does not currently expose the per-query ReasoningBank artifacts needed for an exact matched swap. A reconstruction preflight recovered the benchmark and ReasoningBank implementation, while the execution environment lacks auditable access to the exact executor and embedding models used by the financial study. An exact financial replication therefore remains support and experiment debt. These access constraints carry no scientific authority.

Our executed intervention is a controlled bridge on released WebArena browser-state evidence. It tests the same-query memory channel without reproducing the financial environment. Four of six outcome-blind candidate pairs survive the information-equivalence gate. The gate combines a cosine floor with an independent verifier and literal-reference exclusion. This operationalizes semantic matching, while leaving verifier dependence and the small eligible set as sources of uncertainty.

The clean controlled swap produces a +0.1667 mean terminal-success difference in the predicted direction. The effect exceeds the preregistered 0.15 magnitude floor. Its one-sided 100,000-permutation value is $p=0.0785$, above the frozen 0.05 support threshold. The result therefore remains inconclusive under the preregistered decision rule. No equivalence margin was frozen, so this outcome is not evidence of zero provenance effect. The counterevidence gate also remains closed. A confirmatory controlled swap would require independently frozen, outcome-blind support and cannot reuse threshold changes or post-outcome pair selection.

The reported financial provenance accuracies are rounded to three decimals. The integer correct counts used in our decomposition are the unique counts consistent with the reported support sizes and rounded accuracies. The transition allocation beyond the ten W$\rightarrow$W cases is therefore derived from public aggregate statistics.

The earlier explicit-metadata bridge held generic guidance byte-identical while changing only a structured SUCCESS or FAILURE source label. Across 144 calls it produced a 0.000 terminal-success difference. That bridge had no preregistered equivalence margin and manipulates metadata instead of naturally generated ReasoningBank memories, so it does not close the causal question. Replication beyond financial agents and WebArena remains debt for a broad cross-domain claim.

\section{Conclusion}
Self-evolving memory carries process history. The released financial-agent audit shows a large accuracy gap by memory provenance and concentrates every reported persistent W$\rightarrow$W failure in failure-derived retrievals. ReasoningBank makes provenance an upstream intervention because successful trajectories and failed trajectories are written through different reflection objectives.

We operationalize that causal question with a pre-outcome information-equivalence gate and an executed matched-memory swap. The controlled effect is +16.7 percentage points in the predicted direction across four qualified pairs, while the frozen permutation test does not cross the support threshold. The causal claim therefore remains active and experimentally sharpened. The result defines a concrete governance target: persistent memory systems should preserve how an item was learned and test whether that provenance changes future reuse outcomes under matched actionable information.
