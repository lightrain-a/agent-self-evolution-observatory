\section{Limitations}
The F0 intervention requests six paired memories. Four pairs return complete outputs in both reward conditions. Two failure-label provider responses terminate as incomplete before assistant text is produced. Their provider response identifiers are archived and GET-only recovery confirms that no text is available. These two cases remain support debt. They do not change the observed 4/4 content-divergence result among complete pairs.

F0 and the fresh prompt control establish the reward-to-memory write channel. The downstream reward-to-future-outcome effect remains active experiment debt. We executed fixed-state first-action follow-ups before terminal continuation. The largest fresh distributional replication completed 96/96 policy calls over four held-out states. Its mean success-memory versus failure-memory action-distribution TV was 0.344, while the frozen 100,000-permutation audit gave $p=0.311$. The preregistered distribution-level support gate therefore remained unresolved. We then ran a narrower terminal-answer falsifier because the released live WebArena endpoint was unavailable. This test crossed all four complete F0 memory pairs with four fresh review-oriented tasks whose released browser evidence contains every deterministic benchmark reference. Across 16 source--future cells, all 108 requested policy calls completed. The mean absolute success-rate difference between paired reward-memory conditions was 0.146. The observed difference fell below the frozen $0.15$ effect floor, and the 100,000-permutation audit gave $p=0.160$, above the $0.05$ significance threshold. This fixed-evidence result therefore remains inconclusive and has no negative authority because no equivalence margin was frozen. It evaluates terminal answer correctness with benchmark reference strings while holding released browser evidence fixed; live browser navigation remains untested. The source Shopping endpoint and reset endpoint were unreachable from the execution host during preflight, so live matched terminal continuation remains environment support debt. Controlled reward-corruption experiments remain downstream experiment debt.

The paired intervention uses DeepSeek-V4-Flash as the memory writer. The released ReasoningBank implementation can use other writer models. Replication across memory-writer families remains experiment debt for a model-independent effect-size claim.

The released trajectories used for F0 come from one WebArena Shopping run. They include both original-success and original-failure episodes, which supports the mechanism across outcome strata. Broader task-family replication remains experiment debt.

Token-set Jaccard distance measures content divergence at a coarse lexical level. Title-set changes supply an additional structural measure. A semantic representation analysis can further quantify whether reward labels move memories toward distinct strategy clusters.

\section{Conclusion}
Reward-conditioned memory writing creates a direct path from evaluator error to persistent agent state. In the released ReasoningBank implementation, one reward bit selects a different reflection objective for the same trajectory. Our paired F0 intervention observes memory-content changes in every complete pair and measures mean token-set Jaccard distance of 0.735. A disjoint eight-trajectory control then shows that reward-mode memory separation exceeds stronger same-mode prompt rewording by 0.105 on average, with exact sign-flip $p=0.0078$.

This mechanism explains how reward noise can survive beyond one episode without parameter training. A corrupted reward can change the memory that future tasks retrieve. Repeated memory reuse can then turn a local evaluation error into run-level behavioral variance. The resulting design principle is simple: reward reliability must be treated as state reliability whenever an agent writes persistent memory from outcomes.
