\section{A Stronger Prompt-Perturbation Control}
\label{sec:prompt-control}
The F0 intervention changes the released reflection prompt as a consequence of the reward label. A generic prompt-sensitivity reduction therefore predicts comparable memory changes after a semantic-preserving wording change within one reflection mode. We test this reduction on eight fresh released trajectories that are disjoint from the six trajectories requested by F0. The fresh set is balanced across original success and failure outcomes.

Before provider calls, we freeze one success-mode paraphrase and one failure-mode paraphrase. Both use the same deterministic wording substitutions while preserving the original reflection objective and output format. The released success-versus-failure system prompts have token-set Jaccard distance 0.114. The success-mode original-versus-paraphrase distance is 0.171. The corresponding failure-mode distance is 0.152. The same-mode controls therefore perturb prompt wording more strongly than the released reward-mode contrast under this lexical measure.

Each fresh trajectory is written under four conditions using the same DeepSeek-V4-Flash writer at temperature zero. We compare the released success and failure memories with two same-mode paraphrase controls. For trajectory $i$, let $B_i$ denote the token-set Jaccard distance between the released success-mode and failure-mode memories. Let $W_i$ be the mean of the success-mode and failure-mode original-versus-paraphrase distances. The frozen statistic is
\begin{equation}
\Delta_{\mathrm{prompt}}=\frac{1}{8}\sum_{i=1}^{8}(B_i-W_i).
\end{equation}

All 32 control outputs complete successfully. The mean between-mode distance is 0.700, compared with 0.595 for the stronger same-mode wording perturbations. The paired excess is 0.105. An exact one-sided sign-flip test over the eight frozen trajectory-level differences gives $p=0.0078$. This passes the preregistered margin of 0.10 together with the $p<0.05$ gate. The reward-conditioned reflection contrast therefore produces memory separation beyond the generic prompt-wording effect measured by this stronger same-mode control.
