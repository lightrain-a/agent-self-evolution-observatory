\section{Targeted Skill Contracts}
\subsection{Temporal cutoff contract}
Input: target period and candidate evidence timestamps. Output: the subset that is admissible before the benchmark cutoff. The function also returns the cutoff timestamp used for filtering. The skill contains no scenario answer.

\subsection{Release alignment contract}
Input: publication date and source reporting metadata. Output: the benchmark period represented by the release. The procedure validates the selected time-series row against the normalized period key.

\subsection{Exogenous grounding contract}
Input: target period and numerical change description. Output: cutoff-valid documentary evidence spans that can support attribution. The procedure returns evidence identifiers and short excerpts for later reasoning.

\subsection{Matched generic controls}
Each targeted skill is paired with a frozen target-blind helper. The callable signature and persistent registration timing are identical. Source-token count is matched within 10\%. Abstract-syntax-tree node count is matched within 5\%. The maximum external tool-call count is identical. The cutoff-family control validates package schema without reading timestamps. The release-family control checks table and index consistency without reading release dates. The grounding-family control exposes document inventory metadata without selecting events or aligning documents to numerical changes.

\subsection{Result-row binding}
Each endpoint-condition observation binds the dataset revision and code revision to the scenario-period identity. It also binds the cutoff, failure family and skill source hash. Model configuration and harness hashes remain attached to the raw response hash. Family success and the source-native evaluator payload are recorded in the same immutable row.
