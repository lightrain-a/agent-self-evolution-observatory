\section{Limitations}
The strongest unresolved support gap is the TimeSage-EV evaluated snapshot. The source paper declares a public release, yet the May 2026 period-sequential artifacts are absent from our auditable frozen support set. This prevents the chronological replay in which a skill is written before a later release and remains available as persistent state. Repository access failures have no scientific authority against C4.

The executable interventions supply benchmark-recorded reference procedures. Skill induction is outside the intervention. The experiments estimate downstream value after a candidate procedure is registered. They do not establish that an agent can discover the same procedure from its own earlier failure.

The first formal matched-gate pass is concentrated in STL decomposition. F8 contains seven first-time STL endpoints and gives 5/7 targeted successes versus 0/7 generic successes. A deduplicated first-observation completion of the pre-outcome frozen population gives 10/20 versus 2/20 with $p=0.00390625$. Part of that support completion occurs after partial outcomes, so the combined statistic is robustness evidence and does not create a second formal closure test. One original candidate remains support hold. Three recovered candidates fail reference execution or replay. No failed candidate is replaced.

The new L2 strong-control population broadens the procedure families and strengthens the comparator. Nine endpoints pass execution qualification across five non-STL target procedures. On Qwen, one endpoint becomes invalid because the off-target arm issues a second tool call forbidden by the frozen protocol. The remaining targeted--off-target comparison is 5/8 versus 1/8 with $p=0.0625$. DeepSeek gives 5/9 versus 2/9 with $p=0.125$. The point-estimate direction is positive in both model families, while neither broad-family primary gate closes. Broad C3 therefore remains active.

The strong off-target controls are substantive procedures from the same benchmark task, yet they are still chosen from benchmark-recorded analyses. They provide a stronger alternative than neutral schema work without covering every plausible wrong procedure an evolving agent could store.

The benchmark verifier is deterministic but coarse. Keyword checks can miss a valid paraphrase. Numerical-range checks can accept an isolated in-range value without validating the full explanation. An earlier semantic audit produced zero voting judgments because both provider calls were incomplete. We later audit all 21 F8 answers with arm labels hidden. One predeclared reviewer returns valid judgments and the second is nonvoting after a parse failure; no replacement reviewer is added after labels are observed. The valid reviewer gives 6/7 targeted and 2/7 generic answers strict semantic credit, yielding $p=0.109375$ for the matched comparison. The frozen deterministic F8 score remains unchanged, while semantic measurement robustness is not established.

Two model families are evaluated for the main executable patterns. This remains a narrow basis for a claim about agent models in general. The non-STL strong-control replication reduces single-model dependence, while more model families would still strengthen external validity.

We stop same-substrate experiment expansion after a pre-outcome source audit. The unused L2 source contains zero measurement-valid fresh STL confirmation tasks after excluding the F9 candidate pool. A complete 60-task L1 snapshot yields only 12 fresh task-level strong-control candidates across stationarity, seasonality, autocorrelation and cross-correlation procedures. This is below the predeclared minimum of 16 fresh pairs required to authorize another experiment. No F12 model outcome is generated, and the minimum is not relaxed after observing the source count.

C4 requires release-to-release persistence. None of the TimeSage-MT probes contains a skill-write event followed by later-period reuse. The longitudinal claim remains experiment debt until the TimeSage-EV evaluated artifacts, or an equivalent first-party period-sequential substrate, become auditable.

\section{Conclusion}
A reusable agent skill is not one experimental object. Persistent text changes what the model reads. Supplied procedure output changes what information is placed in context. Executable state changes what computation becomes available after the model chooses to call a tool.

Our controlled experiments separate these surfaces. The weaker text and output interventions do not show matched downstream gains. Executable state produces the strongest matched effects. An independent first-time STL tranche passes the frozen deterministic targeted--generic gate at 5/7 versus 0/7 with exact $p=0.03125$. A blinded semantic diagnostic does not reproduce that inferential gate with its only valid reviewer, so measurement robustness remains open. A 20-endpoint first-observation completion supplies additional score-level robustness without changing the tranche-level authority.

A new L2 population tests five non-STL target procedure families against substantive task-local off-target procedures. Qwen gives 5/8 targeted successes versus 1/8 off-target success. DeepSeek gives 5/9 versus 2/9. Both matched directions are positive, while the exact primary gates remain open. The current evidence therefore shows a frozen deterministic executable effect within STL decomposition. Semantic robustness remains unresolved. The stronger causal control provides broader directional evidence.

The resulting evaluation standard is simple: hold the visible callable interface fixed and test the hidden implementation against a substantive matched alternative. A longitudinal self-evolution claim additionally needs the state transition that writes the procedure before later evidence arrives.
