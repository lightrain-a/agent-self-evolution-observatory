# 论文绘图精选：从完整目录到有界选图

更新：2026-09-30。默认页面：`figure-knowledge-base.html`；旧地址 `figure-gallery.html` 仍指向这个入口。

## 问题与本次修订

旧目录把配方、图片、教程、导出副本和配套资源一起索引，共2081条。这能完成来源覆盖，但不能作为论文图质量推荐。文件名自动标签也可能错误，例如 `comparison_posttraining` 原标记为grouped_bar，实际是训练进程折线。

新版保留**6个Figures4Papers精选结构参考**。其余2075条移出默认界面和默认Agent输入，仍保留在按需来源档案。默认页面下载的目录从4,220,038字节缩到10,807字节（当前构建），不是把旧条目隐藏后继续载入全量JSON。

精选集是当前ML论文任务的编辑决策，不是宣称所有归档图片都差，也不是把所有科学图型压成六种。

## 六个参考与12类选图规则的区别

| 原图参考 | 主要借鉴 | 不应误用 |
|---|---|---|
| Brainteaser correctness_by_category | 多指标比较、方法编码与集中图例 | 多类别时不照抄拥挤的分组柱 |
| CellSpliceNet ablation | 少量组件变体的紧凑比较 | 无实际重复不能复制误差条 |
| VIGIL comparison_posttraining | 有序训练进程曲线 | 不是柱状图，也不是未测量的连续性能曲线 |
| ophthal composition_heatmap | 完整行列、格内标注的矩阵 | 缺失不是零；组成比例要保留分母 |
| RNAGenScape results_sweep | 参数敏感性、不同单位分面板 | 不用双纵轴制造同步变化 |
| RNAGenScape results_comparison_speed | 实际运行成本的紧凑比较 | 不是性能—成本二维散点；先核对量纲与轴尺度 |

Flow Ink的12类简短规则覆盖效果比较、消融、配对差值、一致性、二维取舍、矩阵、样本分布、实测趋势、区间、排序、组成和互补面板。规则不是12张必须展示的参考图片；无准确匹配的原图时只引用相关设计原则，不贴错图凑数量。

原图固定在Figures4Papers提交`f0bb7559abe90f5e1828797126d4d133c1bd47d7`。链接和作者许可保留；不复制源码、模板、图片或私有论文图进公共仓库。

## 从HEIRS/ICLR继承的规则

先读当前方法、真实数据和现有builder。图号会变化，应以figure_id和脚本/数据版本交接。

HEIRS有效的增密来自每张图多回答一个相关问题：逐题/逐方向矩阵保留全部零值和不利设置；恢复—干扰与性能—成本图显示真实取舍；不同单位的量分小轴展示；3–4互补面板组织一条阅读路径。这不同于对一个问题机械生成四种图型。

已有主线和风格得到认可时，优先局部改善：固定Times New Roman等既定字体，统一方法颜色与辅助点形，短轴标签保留单位，预留图例区，缩小无意义面板间隙，按最终宽度控制图高。不要直接复制参考仓库大画布的字号，不为了“醒目”添加雷达、三维、渐变、双轴或不存在的前沿。

本轮复盘依据项目内历史笔记和当前图表脚本；不是重跑论文实验，也不是新一轮HEIRS提交PDF验收。公开文档只保留方法，不带原始实验数值或内部路径。

## 有界上下文与导出

默认：一个主方案和一个有意义的备选；特殊需要最多三个编码、最多两个参考。先检验配对、样本、区间、排序和单位条件，再判断布局与风格是否适合。没有匹配项时返回证据缺口，不自动恢复千图检索。

浏览器收藏最多两个，绑定当前目录版本，旧大目录收藏不会混入。导出只含读者问题、选择的源ID/版本、图型和字段要求，保留`BROWSER_DRAFT_NOT_SERVER_APPROVAL`。它是给Agent的参考包，不是填好项目data_refs与测量语义的原生执行brief；宿主Agent仍要绑定真实数据。

归档页面只作显式溯源；默认首页、数据准备页和导出不加载原始2081目录。原19个本地renderer仍作为合成能力档案维护，不冒充论文审美推荐。筛选图参考与筛选实验数据必须严格区分，不能因好看删主表方向、零值或负结果。
