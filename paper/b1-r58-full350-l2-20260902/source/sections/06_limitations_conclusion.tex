\section{Limitations}
The motivating financial audit provides aggregate provenance counts but not the per-query artifacts and auditable writer/embedding bindings needed for a source-native swap. Financial L3 therefore remains support and experiment debt, not a scientific negative. The completed L2 experiment runs on MemRL/OSInteraction with Qwen2.5-7B-Instruct and should be interpreted as substrate-bounded identification rather than transport to the motivating financial runtime.

L1 remains limited by both independent-unit count and imperfect information matching. R4 has four tasks, $\Delta=+0.1667$, $p=0.0785$, and an exact one-sided floor of $1/16$; stronger archived semantic audits also judge only 0/4 and 1/4 admitted pairs fully equivalent. R6 has 23 disjoint tasks, $\Delta=-0.0942$, and $p_F=0.0792$ on a non-terminal readout, while deterministic diagnostics show systematic writer-style differences. Thus L1 identifies a writer-mode bundle, not provenance alone, and neither gate may be rescued by post-hoc thresholds or extra seeds.

The clean L2 result closes a different question but remains finite and model-specific. It contains 32 paired clusters and only one discordant terminal outcome. The exact two-sided paired sign test is therefore $p=1.0$. The preregistered paired bootstrap interval $[0,0.09375]$ follows the frozen analysis, but the empirical effect distribution contains 31 zeros and one $+1$; we therefore do not promote that interval into a theorem that the population effect is below 9.375 points. The appropriate statement is that this experiment detects no statistically or preregistered-practically meaningful terminal benefit from exposing provenance beyond fixed content. Cross-backbone replication is needed before treating the low-conversion pattern as model-robust.

The behavioral diagnostics are complete-run secondary analyses, not additional primary endpoints. Provenance exposure changes first executable action in 9/32 pairs and total step count in 7/32, while terminal success changes in only 1/32. These observations support the descriptive label ``behaviorally legible, low terminal conversion,'' but they do not identify which cognitive or control mechanism mediates the local changes. The single discordant task is illustrative and cannot establish a general causal pathway.

Historical R5, R19, and R51 remain separate fail-closed objects. Their support or runtime stops are not pooled with R56 and are not reclassified as nulls. Conversely, the completed R56 result does not retroactively validate those stopped experiments. PSMG is also still a design consequence rather than a demonstrated improvement: R56 exposes provenance directly to the executor, whereas PSMG's key efficacy question concerns whether a calibrated governor using provenance improves decisions over a same-information provenance-free controller.

\section{Conclusion}
Memory provenance is not a single causal variable until its channel is specified. The L0--L3 ladder separates observational association, outcome-conditioned writer effects, exact-information provenance exposure, and source-faithful transport. That separation matters empirically: the motivating financial audit shows a large provenance association, historical L1 writer-mode contrasts have unstable descriptive directions, and a fresh support-qualified L2 experiment yields a much smaller terminal effect once actionable memory content is fixed.

In the completed L2 experiment, content-only memory succeeds on 15/32 fresh OSInteraction clusters and the same content plus truthful source provenance succeeds on 16/32, for a paired difference of $+3.125$ percentage points. Thirty-one of 32 terminal pairs agree, the exact two-sided sign test is $p=1.0$, and the 15-point practical-relevance floor is not met. Yet provenance changes first executable actions in 9/32 pairs. The resulting picture is not that provenance is invisible; rather, provenance can alter local agent control without reliably improving terminal utility. Within this substrate, the result is consistent with qualified content sufficiency.

This boundary changes the engineering default. Provenance remains valuable for auditability, debugging, and future governance, but a raw SUCCESS/FAILURE cue should not receive decision weight merely because it is available. PSMG formalizes the safer alternative: preserve lineage in the control plane, estimate whether it adds conditional information beyond content and context, and allow its influence to shrink to zero when evidence does not justify additional trust or caution. Source-faithful L3 transport, a second executor backbone, and a separate PSMG-versus-content-only governance trial remain the main open tests.
