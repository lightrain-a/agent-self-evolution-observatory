\section{Related Work}
\paragraph{Memory, provenance, and failure-derived experience.}
A-MEM and MemRL organize reusable memory by content or utility, while ReasoningBank, Agent Workflow Memory, and Reflexion convert trajectories or feedback into persistent state \citep{xu2025amem,zhang2026memrl,ouyang2026reasoningbank,wang2024awm,shinn2023reflexion}. Provenance is already an established systems object: execution-tracing work records evidence lineage, Memory Provenance Laundering studies authority loss under consolidation, and provenance-bearing memory systems retain links to source evidence \citep{wang2026tracetotrust,xu2026laundering,joshi2026eywa,zhu2026tiermem,pham2026memorai}. Separately, Learning from Failure and related reflection systems show why source failure cannot be assigned a universal negative trust sign, while Memory Reward Inflation shows that erroneous memories can still be amplified \citep{sun2026learningfromfailure,liu2026rethinkingfeedback,allard2026erl,asadolahi2026inflation}.

\paragraph{Our boundary.}
The financial-agent audit provides a strong success/failure provenance association \citep{li2026audit}, but association, writer intervention, exact-information provenance exposure, and source-runtime transport are different causal objects. Our novelty is not provenance storage or generic trust scoring. The L0--L3 ladder binds claims to those channels, and PSMG couples the identified channel to a same-information governance test in which the comparator receives every pre-outcome feature except provenance. That governance efficacy test remains future work.
