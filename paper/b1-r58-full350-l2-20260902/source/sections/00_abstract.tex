\begin{abstract}
Self-evolving agents convert prior trajectories into reusable memory, but a memory item can carry both actionable content and information about how its source trajectory ended. We ask a deliberately narrow question: once retrieved memory content is fixed, what changes when the executor is additionally shown an explicit truthful source-outcome indicator? We introduce an L0--L3 provenance-audit ladder separating observational association, outcome-conditioned writer effects, exact-information field exposure, and source-faithful transport. We then execute a prospective L2 experiment on MemRL/OSInteraction. A full 350-task source run yields 176 success-derived and 174 failure-derived memories; before any validation outcome, native retrieval supports 106/108 fresh dependency clusters and a disjoint utilization gate verifies that the memory surface can affect first actions. On 32 frozen primary clusters with Qwen2.5-7B-Instruct, the outcome field is masked in A and truthfully revealed in B over identical retrieved content/order; terminal success is 15/32 versus 16/32 ($\Delta=+0.03125$), while first executable action differs in 9/32 pairs. Meta-Llama-3.1-8B-Instruct reuses the same frozen source-bank/retrieval/task substrate and gives 17/32 versus 17/32 terminal successes with first-action differences in 8/32 pairs. The observed effects do not reach the preregistered $|\Delta|\geq0.15$ threshold, but sparse-discordance conservative 95\% paired risk-difference intervals (Qwen $[-0.128,0.183]$; Llama $[-0.225,0.225]$) do not establish $\pm0.15$ equivalence or rule out a $+0.15$ population effect. Thus explicit source-outcome-field exposure frequently perturbs local action selection while rarely changing the binary terminal label in these frozen samples. This is a closed-loop field-exposure result, not evidence that provenance generally lacks value or that the local changes reflect semantic provenance reasoning. We therefore preserve provenance for audit while separating its storage value from any automatic executor trust weight.
\end{abstract}
