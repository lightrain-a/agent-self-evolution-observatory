\begin{abstract}
Self-evolving agents convert prior trajectories into reusable memory, but a memory item can carry two distinct signals: actionable content and the process provenance of the trajectory from which that content was written. We ask whether success/failure provenance adds downstream value once actionable memory content is held fixed. We first introduce an L0--L3 provenance-audit ladder that separates observational association, outcome-conditioned writer effects, byte-identical provenance-metadata interventions, and source-faithful transport. Historical evidence motivates the question but does not identify the provenance-only effect: a released financial-agent audit reports 0.931 accuracy for 101 success-derived ReasoningBank retrievals versus 0.647 for 34 failure-derived retrievals, while controlled L1 writer-mode endpoints have inconsistent descriptive directions. We then execute a prospective L2 experiment on MemRL and OSInteraction. A full 350-task source run yields 176 success-derived and 174 failure-derived memories. Before any validation outcome, native retrieval supports 106 of 108 fresh dependency clusters; a frozen utilization gate confirms that memory changes first executable actions in a memory-specific manner. On 32 fresh paired clusters, the content-only arm succeeds on 15/32 tasks and the otherwise identical arm that additionally exposes truthful provenance succeeds on 16/32, for $\Delta=+0.03125$. Only one pair is terminally discordant; the exact two-sided sign test gives $p=1.0$, the preregistered paired bootstrap interval is $[0,0.09375]$, and the 0.15 practical-relevance floor is not met. Provenance is nevertheless behaviorally legible: first executable actions differ in 9/32 pairs and total step counts in 7/32. Thus, in this support-qualified substrate, provenance can perturb local control while adding little incremental terminal value beyond fixed content. We interpret this as qualified evidence for content sufficiency, not a proof of a universal zero effect. This boundary motivates Provenance-Separated Memory Governance (PSMG), which retains provenance as auditable control-plane state but requires separate evidence before granting it decision weight.
\end{abstract}
