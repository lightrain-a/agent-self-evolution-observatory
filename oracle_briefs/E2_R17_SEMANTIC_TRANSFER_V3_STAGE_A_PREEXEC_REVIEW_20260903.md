## 1. Why V3 exists

The previous independent GPT-5.6 Sol / extreme-thinking review returned `REVISE_BEFORE_STAGE_A` for V2. It did not reject the state-level Search-Projection Censoring object. It found four verdict-changing design defects before Stage A:

## 2. State-level causal object

Search produces a K=8 trajectory pool `T_K`. Acting always uses the deterministic verifier-selected winner `a(T_K)`. Persistent learning receives a projection `g(T_K)`.

The state-level causal question is:

> Holding the exact search pool and acting decision fixed, can changing only the learner-visible projection change future persistent skill utility?

V3 never changes acting between learning arms.

### WIN-C

The updater sees the served winner on all 8 update pools.

### MRW4

A pool is mixed iff it contains at least one verifier-success and at least one verifier-failure trajectory.

For every mixed pool, the candidate rejected witness is frozen as:

> the verifier-failure trajectory with the lowest original rollout index among trajectories that are not the served winner.

No semantic label, family ID, error taxonomy, post-update score, or later outcome can enter that selector.

After all Stage-A pools are sealed, a stream is support-qualified only if at least 4 of its 8 pools are mixed. If all 20 streams qualify, exactly 4 treated pools per stream are selected by ascending

`SHA256("semantic-transfer-mrw4-v3|stream_id|task_id")`.

On those 4 pools MRW4 exposes the frozen failed nonwinner; on the other 4 it exposes exactly the same winner as WIN-C. MRW4 is replacement, not winner+failure. Final updater-visible evidence is rendered to the same frozen token budget in both arms.

## 7. Independent mechanism units and gate

For stream s:

`D_s = mean_r[J_s,r(MRW4)-J_s,r(WIN-C)]`.

Within skeleton h and semantic cell z:

`D_h,z = mean_{two streams in (h,z)} D_s`.

Primary interaction:

`I_h = D_h,PROCEDURAL - D_h,BINDING`.

The five `I_h` values are the independent confirmatory mechanism units. Streams and R=4 replicates are measurement repetition, not independent semantic replication.

Primary mechanism gate requires:

1. mean_h I_h > 0;
2. all five I_h > 0;
3. exact one-sided sign test p=1/32=0.03125 under the all-positive outcome.

Zeros count non-positive. No 80% power claim is made because there is no independent pre-outcome estimate of between-skeleton interaction variance.

## 10. Two control-plane loopholes found and repaired before this review

During local adversarial audit after the original V3 design commit, two direct-actor bypasses were found:

1. old actor compatibility logic could have accepted a non-initial skill with an updater receipt even though V3 authorization said `allow_noninitial_skill=false`;
2. a valid Stage-A authorization was not sufficiently bound to the unique first-run runner context, so a direct actor invocation could in principle choose a different run root / prefix-K / concurrency outside the runner.

Commit `107fec32ae64b34e5fcabe8e2e7897d182936354` repairs both:

- scientific V3 Stage-A authorization now rejects any non-initial skill and any updater receipt;
- actor requires the contract-bound run root;
- actor requires exact prefix K=[1,2,4,8];
- actor requires exact concurrency;
- actor requires an active global lease with status `RUNNING_STAGE_A_V3` bound to the same contract SHA, authorization SHA, and run root;
- runner verification requires those same scope fields.

The control test suite now includes explicit tests for missing/wrong lease context and non-initial-skill rejection.
