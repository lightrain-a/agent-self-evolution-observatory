1. end-to-end unified method comparison under the common 80/40/280 public harness;
2. paired natural-unit causal transport of the exact-same-pool, acting-fixed projection effect.

For causal transport, eligibility is frozen from pre-treatment observables. Each eligible natural unit freezes one common starting persistent state, one common realized/content-addressed search-evidence object, one common verifier/served action, and one common updater/config/budget/order/evaluation panel. This prevents router selection, different search objects, different served actions, or path-dependent histories from being misinterpreted as transport of the B2 causal interface effect.
