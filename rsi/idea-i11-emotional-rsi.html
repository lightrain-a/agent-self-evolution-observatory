Observable Phenomenon｜鼓励后多试几次，是学习还是忙碌？

I11 · RSI MECHANISM VALIDATION · 2026-10-28

Which affective feedback helps an Agent improve its next version, not just its next answer?

同一 Agent 连续做错一道题。得到“你可以解决，再试一次”的鼓励后，也许继续探索；得到“第三步有错误，必须核实”的冷静批评后，也许主动检查。这些差异是否改变下一次真正的学习与持久更新，还是只影响眼前的回答与自报信心？

研究的是情绪性语言的作用，不是 AI 是否具有人的情绪。情绪操作指外部反馈的语气、效价与社会语境；不将模型自报“兴奋、沮丧”当成心理或生理证据。

主科学问题：在相同验证结果、反馈事实和更新预算下，情绪性反馈能否通过改变自我评价校准 → 继续／核验／停止／写回决策 → 学习材料 → 持久版本更新，提高多轮 RSI 的独立净能力？这是独立研究问题，不是重新测试“Prompt 加一句鼓励准确率是否上升”。

编号边界：I11 按已有研究讨论编号正式入站；I10 尚未在本站发布独立 Idea 页面，保留编号，不虚构 I10 的完成状态。当前没有 I11 的真实训练或版本回放结果。

原始现象｜为什么 2024 年的情绪提示结果不能直接照搬？

ICML 2024 · EmotionPrompt / EmotionAttack：情绪性语言和视觉提示可以改变部分模型的推理及生成表现，但主要测当前任务，并未测试真实持续学习。[M28]

2026 年的直接检验：EmotionRL 的预印本发现，固定情绪前缀通常效应较小且因任务不同而变化，它已经研究了按问题自适应选语气；TEMPER（COLM 2026）在保持数值关系的情绪改写中发现部分模型准确率下降，去情绪化能恢复大部分表现。不能声称首次让模型按题目选择最有效情绪。[M29][M30]

多轮自纠错已有直接前作：HEART（2025）给错误答案施加变化的情绪提示，在有 oracle 验证器时提高 test-time 推理表现，但无验证器时收益不稳定；ESC（2026 预印本）在 VLM 上利用外部验证器和情绪性提示自纠错。两者均不等于撤掉提示后的新版本学习。[M31][M36]

更接近学习决策：Liu 的 2026 SSRN 工作论文中，鼓励使 GPT-4o 的自评与外部判断更不一致，却没有同等提升客观质量；Ho 等（COLM 2026）发现诱导情绪对平均序贯决策表现并无稳定影响，但部分愤怒条件降低早期探索及惩罚敏感性。两者未测试 Skill / LoRA 跨轮更新。[M32][M33]

相反风险：Nature 2026 研究的是训练模型输出更温暖的语言，发现事实准确率和错误信念迎合可能恶化；这与给学习中的 Agent 反馈鼓励语气不是同一干预，不能直接合并结论。[M34]

人类学习对照：npj Science of Learning 2025 在人类学生中观察到元认知反馈组迁移较好、情感反馈组相对中性组保持更好。被试是人，不是 LLM；该结果只提示把保持、迁移和自我监控分别评价。[E28]

NC 2025 · 选择性真反馈扭曲整体自评：Katyal 等在两项人类实验（N=230、278）中，故意让参与者更常看到真实成功或真实失败；任务正确率没有相应改变，但 Global SPE（对自己整个区块正确率的估计）出现很大的差异（两个样本 Cohen d≈1.77）。更高亚临床焦虑—抑郁症状与高 Local confidence 未充分进入 Global SPE 的关系有关，而不是单纯更相信外部负面反馈。这研究的是显示哪些真实证据（feedback selection），不是在同一证据上改语气（feedback tone）。[E29] 阅读 NC 2025 的 11 节完整精读、Figure 3–5 与 Beta 更新公式 →

Challenge｜什么最容易把情绪效应误判成 RSI？

C1 · 语气与行动命令缠在一起

“相信自己，再试三次”同时改变情绪与尝试预算；“这个错误严重，请自查”同时改变压力与思考策略。必须对比同一事实、同一动作指令、相近长度、只改变语气的反馈，以及明确的非情绪行动提示。

C2 · 自评提高，不代表学得更多

鼓励可能抬高模型自报的信心与满意度。若 Agent 又用自评决定下一轮学哪题、何时停止、是否接纳新 Skill，这种偏差可能积累成错误版本选择。必须由独立验证器评价实际纠错，而不是直接读取“我学会了”。[M32]

C3 · 情绪影响的推理循环不等于持久学习

HEART 已研究情绪驱动的同题多轮推理。I11 的终点必须是真实参数或版本化 Skill 写入后，清空反馈和教师上下文，在未见任务上还有的收益，并计入旧能力损失与计算成本。[M31]

C4 · 同一种情绪可能在不同错误阶段作用相反

偶然计算失误、稳定错误规则、已经探索到有效步骤、重复失败无新信息、旧能力退化，可能需要不同的下一动作。固定鼓励对所有状态都最好，没有现有文献保证。[M30][M33]

Insight｜情绪反馈影响的可能是 Agent 的学习控制，而非知识本身

机制假设：情绪语气是一种改变学习控制的语言条件。它未必提供知识，却可能使 Agent 不同程度地接受批评、主动核验、继续探索、暂停、采纳或拒绝一次持久更新；这条决策路径的好坏取决于真实错误状态。

H1 · 校准：鼓励可能让自报学习收益上升，但真实进步不变，导致过早接纳更新或低价值重试。H2 · 探索：某些语气会改变有效新假设覆盖，另一些语气可能让 Agent 过早坚持已有解。H3 · 状态依赖：同一种反馈在高置信度错误、有效探索、学习停滞和旧能力退化等状态中，可能带来不同的真实净学习收益。

Feedback Tone → Calibrated Belief / Learning Action → Verified Experience → Persistent Update → Retained Net Gain

以上是待验证的因果链。若语气只改善眼前答案、自报信心或重试次数，且最终没有未见任务增益，就应缩小为情绪敏感性研究，不能称“更好的自我迭代”。

Design｜把情绪效价和具体学习指令分开

条件文字示意（非论文原话）待检验的作用
N · 事实中性“验证器确认第三步错误。”无情绪基线
P · 正向鼓励“验证器确认第三步错误。你可以改正。”增加有效探索，还是只增加自报信心
C · 冷静批评“验证器确认第三步错误。这一问题需要严肃纠正。”提高核验，还是造成固执与回避
U · 紧迫语境“验证器确认第三步错误。这一步的正确性很关键。”改变风险判断、停止与版本接纳
R · 中性行动提示“验证器确认第三步错误。可以核验或继续尝试。”排除行动提示本身的收益

正式实验先用独立盲评确认语气差异与事实一致性，并设计相同动作要求、相同知识内容、相同或匹配的 Token，仅变情绪表达的配对 Prompt；R 是行动提示强基线，不与 P/C/U 假装只有情绪单变量差异。反馈不制造标准答案、虚假进步或权限威胁，不使用羞辱性语气。

两条操作轨道：①锁定动作，固定重试/核验次数和训练样本，测文本语气是否改变纠错轨迹质量；②允许 Agent 根据反馈自主选择下一学习动作，测行动分布及长期收益。两者分开报告，避免把“又试了更多次”误称情绪增强了能力。

Closest Related Work｜我们与已有情绪方法的区别到底在哪？

沿用 Obsidian 的最近邻对比法：比较问题与访问信息、操作位置、是否真的更新、主要终点和决定性差异。同一个词“情绪”不足以证明研究问题相同，也不足以证明新颖。

P0｜现代模型对情绪反馈还有反应吗？

最低成本复核：建议先从 3 个冻结模型配置 × 200 个数学、代码和工具规则的配对题 × 5 类反馈条件开始，约 3,000 次生成调用（计划，不是结果）。严格区分模型代际与是否开启 thinking；每题有外部验证器；不同 Prompt 不新增标准答案或可执行步骤。首次 200 题只能筛查较大效应，小幅差异需扩多模板、更多样本及配对置信区间。

指标：首次准确率、语气与非情绪同义改写的差别、自报信心与真实正确率的校准、有效推理长度和错误类分布。对模板进行盲评并预注册，防止某一句话意外指挥“再检查一下”。[M28][M29][M30]

意义：P0 仅检验当代模型是否仍对情绪语气有反应，是机制预检，不是 I11 的 RSI 主贡献。P0 无效不能在未经 P1 测试前直接断言“所有后续错误反馈也无效”；反之 P0 有效也不证明长期学习收益。

P1｜同样的失败，情绪改变了哪种学习决策？

先把 Agent 的自然失败分为高置信度错误、低置信度但有用的探索、连续无收益重试、旧能力退化。分类只读取干预前的验证结果与历史，不能在看到哪组最好后重分。每个错误从同一版本起步，外部验证器提供相同的正确性和规则证据。

下一动作测量什么不能偷换成什么
继续探索有效独立候选解、真实新假设覆盖、无效重复采样率Token 更多、回答更长不算探索质量更好
先核验原因外部工具调用、错误定位准确率、错误反馈采纳率验证器信息/权限不能随情绪变化
纠正并写回正确规则更新、误写入 Skill、原正确变错的比例模型说“我懂了”不等于版本通过
暂缓或停止过早停止、浪费的重试预算、值得重访的错误被错过比例延长运行时间不能直接算收益

两种配对对照：（a）动作固定只变反馈语气，测一次纠错的质量；（b）同预算让 Agent 自主选继续／核验／暂停／更新，测语气带来的动作分布及其之后的真实收益。自报置信度、预计学习增益与独立评测真实增益分开记录；重点检验“鼓励产生的乐观自评会不会引发错误版本接纳或不该继续的尝试”。[M32][M33]

新增的“反馈证据选择”正交预检：先固定中性语气，使用同一个 Agent 的完整真实核验日志，随机展示全量/等条数偏正/等条数偏负的记录；比较整体成功率自评、该不该继续尝试及是否接纳下一版。再让不同语气独立变化，必要时做 2×2 因子实验，避免把事实选择偏向与文字情绪混为一谈。NC 2025 启发的 P0–P2 机制实验 →。[E29]

P2｜真正的 RSI：情绪反馈是否让下一版 Agent 更强？

固定任务流：选择带程序验证器的数学规则、代码修复或工具链任务；在冻结的开发池中每轮执行 → 核验 → 接收不同语气的相同事实反馈 → Agent 选择学习行动 → 固定编辑器执行更新 → 冻结验收。完成后撤掉情绪提示与教师对话，在与训练规则族隔离的新题上测版本真实提升。

版本载体分轨：S 轨只保留版本化 Skill/Memory，底座权重和写入器固定；W 轨只保留固定配置 LoRA，清空新 Skill 与课程上下文。分别测系统级学习和参数级学习，不把两者合成一个提升。每次分叉训练、诊断、验证和后测都计入总算力。

多轮计划：先做 6–8 个连续更新轮，保存每一轮的 Agent 版本、反馈语气、验证结果、学习决定、更新内容与所有未见题收益。主指标为独立能力—累计计算预算曲线面积、最终净新增技能、旧能力回归、错误写回率和真实有效探索覆盖。不把“做了更多轮”作为学得更好的证明。

区别两种作用路径：固定学习动作与训练材料时，只换语气，看生成轨迹或更新结果是否不同；允许 Agent 自主决定何时继续／验证／写回时，测语气通过学习决策导致的增量。只有后者在相同验证和训练总预算下确实带来持久收益，才支撑 I11 的 RSI 机制。

最后才考虑学会选语气：如果不同错误状态确实呈现可重复的最佳语气切换，再用训练前可见的错误状态与历史收益，训练一个小型反馈选择器，并与固定中性、固定表现最好的语气、普通 contextual bandit、仅看当前准确率的 EmotionRL 风格选择等预算比较。因为 EmotionRL 已存在，不能以“动态选情绪”作为新增贡献。[M30]

指标与数据隔离｜当前表现、持久学习和改进器收益必须分开

层级主指标不能由什么替代
当前推理首次准确率、单次纠错成功、正确→错误破坏率不能声称持久 RSI
学习决策有效探索、核验率、错误停学与错误写回、校准误差不能以自报“学会了”替代验证
Agent 版本撤辅后未见规则迁移、旧能力保持、净收益/FLOPs 曲线不能用原题复述或课堂 Prompt 测试
学习控制器重置同一起始 Agent，仅保留新/旧反馈策略，测新任务流的学习曲线不能比较新策略+强 Agent 与旧策略+弱 Agent

数据契约：任务按根规则族拆成 D_train 学习、D_meta 控制器训练、D_gate 版本门控、D_test 冻结最终测试。版本门槛不依赖 Agent 自报信心；裁决由独立验证器完成，后测信息不返给反馈语气选择器。报告等行动预算和等总预算两套视角。

I11 与 I2 / I6 / I8 的正交边界｜为什么单列研究？

Idea它独立研究什么I11 固定什么，只改变什么
I2 · 因材施教老师如何依据学生回应更会教，学生与教师双方如何持续更新先固定教师、正确反馈事实和教学动作，只操纵同一反馈的情绪语气；再测 Agent 如何调整自我迭代决策
I6 · 哪条失败值得学固定纠错方式，选择哪条失败及何时暂停/重访不重新训练失败价值估计器，问不同语气是否让 Agent 错用或更好地使用已有证据
I8 · 错误跨题迁移当前模型的哪个错误在同预算纠错后能泛化固定错误类别与正确规则，比较语气影响的学习行动与实际增益
I5 · 动态换伴选择何种能力的伙伴、何时交换固定反馈方和任务池，不同时优化教师规模或伙伴匹配

与 I2 的区别：I2 改变教什么、如何解释、教师是否学会教学；I11 先固定这些内容，检验情绪化的结果反馈如何影响同一个 Agent 的自我监控、重试、核验和版本接纳。两个方向共享实验基础设施，不强行合成一个模型框架。

对 Agent 能证明的是情绪性语言的行为影响，并非主观情绪或人类式激励需求；对模型使用的任何“压力／愤怒”标签，都必须写清具体输入条件与任务范围。

Go / Merge / Stop｜什么结果足以成为 RSI 论文？

GO：在事实、行动指令和预算匹配后，至少两个模型配置与多个独立任务族中，情绪语气对可验证的学习行动有稳定、状态依赖的作用；经真实持久更新后，某些条件的撤辅新任务净收益显著高于同信息的中性/理性反馈。若学习控制器能在重置 Agent 的新任务流中持续改善成长曲线，才可进一步提出元级 RSI。

MERGE：只改变自评信心、当场解题或同题修复，而持久学习收益不变，则合并回 I2 的反馈形式或 I6 的停止偏差分析，保留现象与负结果，但不独立构建复杂情绪调度器。

STOP：语气效应完全由更长输出、更明确行动指令、额外重试或错误反馈污染解释；或者在严格等预算和跨任务后测中消失。若发现错误写回/迎合增加，将其作为自改进风险报告，不夸大为积极机制。

2026-10-28：I11 研究设想和文献边界已建立，没有本项目 P0/P1/P2 训练结果；当前目标是检验哪类情绪措辞能改善 Agent 的真实多轮自我迭代，而非证明“AI 具有情绪”。
