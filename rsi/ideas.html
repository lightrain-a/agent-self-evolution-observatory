I1：脚手架学习法——哪些该自己学会，哪些用时再查？

采不采得到吸收了会不会丢

一句话：调试思路最好自己掌握，但经常变化的 API 规则可以用时再查。Agent 能自己判断哪些该学会、哪些该留作外部帮助吗？

Challenge （难在哪里）

在帮助下完成任务，不等于撤掉帮助后还能独立做。什么都写进 Skill，可能把过时规则也记住；什么都留在外部，又要反复查询。难的是还不知道未来任务怎么变，就要先决定哪些知识值得长期掌握。

现有工作 （别人研究了什么）

R²Orch 研究的是怎样把 Skill 内化、什么时候可以撤掉 Skill；PATS 研究的是随着学习进展怎样调整并撤除临时支架。我们不是再做一次“帮助逐渐减少”，而是研究不同经验究竟该留在哪里。[S26][S27]

Insight （为何可解）

外部帮助并不都一样。稳定且反复使用的操作方法可能适合自己学会；容易变化的事实可能更适合按需查询。比较撤除帮助后的独立能力、知识变化频率和长期成本，有机会学会这两种方式的取舍。

Design （如何做）

将辅助经验分成稳定方法、易变规则和临时提示，让 Agent 选择内化、外置查询或混合保留。分开测“完全不给帮助”和“允许按需查询”的表现，再根据这些结果更新下一轮的选择方式。

拆分辅助经验稳定方法 / 易变知识
选择存放方式内化 / 查询 / 混合
新任务测能力撤辅与查询分开
更新取舍规则比较收益和成本

实验设计 （怎么验证）

准备稳定的调试技巧与会变动的 API 规则，在相同预算下比较全部内化、全部外置、固定渐隐、自适应取舍，并与 R²Orch/PATS 的可复现做法比较。重点看无辅助的新任务成功率、API 更新后的适应性、调用成本和旧能力退化。如果固定规则同样好，说明动态选择还没有额外价值。

I2：因材施教——学生变强，教师也能越来越会教吗？

信号对不对吸收了会不会丢

一句话：学生通过教学学会解题，教师通过学生真正的学习结果学会教学；当学生能力变化，教师继续修订教法。

Challenge （难在哪里）

同一个学生变强后，原来最有用的教法可能不再合适。但师生两边分数都上涨，不代表教师更会教——也可能只是学生本来就更容易教了。必须把教师教学能力与学生解题能力分开测。

现有工作 （别人研究了什么）

INTERACT（ACL 2025） 已让 LLM 学生多轮追问以在上下文中学习；AToM（ACL 2024） 已根据学生误解调整示例；LbT（NeurIPS 2024） 已用学生反馈改进教师；Sherpa 已训练自适应教学；OPCoD 已让两个模型互相反馈并更新参数。因此“双向对话”“识别误解”和“师生共同更新”都不能当首次贡献。[S105][S106][S20][S103][S33] Bayesian Teaching、RLT 与 SOAR 还分别研究了监督目标、生成可学的解释和用真实学生增益训练教师。我们需要证明真实学生逐轮回应是否提供静态诊断无法替代的信息，并最终让学生和教师分别获得持久收益。[S100][S101][S17] RSIFlow 与 MetaSkill-Evolve 已涵盖更新对象/元技能选择；I2 仍固定更新器。[S28][S06]

Insight （为何可解）

学生对不同教法的学习反应可能随能力改变。它在互动中的真实追问、错误应用和反驳，也可能暴露静态能力分数看不出的知识缺口；但是复制反馈与正确应用必须分开。npj 2025 发现 Apply 与原题提升相关，却没有观察到它与新主题迁移的显著直接相关。[E27] 少量同起点试教检验这些回应是否真的改变后续学习，再将有效规律写入教师教学策略。

Design （如何做）

固定伙伴、教材和教学顺序，从同一学生快照试教；学生真实更新后，清空课堂对话并测新题。用独立收益改进教师教法，同时保留学生新能力；下一轮面对成长后的学生继续循环。原 I2 的固定 Skill 更新轨道保留，双 LoRA 参数更新单独验证。

I3：温故知新——新方法有用，却和旧方法冲突怎么办？

吸收了会不会丢安全

一句话：Agent 学会一个更快的新方法，却把以前在另一种场景下正确的做法弄坏了。新旧本事能不能都留下来？

Challenge （难在哪里）

新 Skill 确实提高了部分任务的成功率，却可能让旧任务变差。直接回滚就失去了新进步；把所有旧题重做一遍又浪费预算。首先得弄清是旧知识真忘了，还是新旧规则用错了地方。

现有工作 （别人研究了什么）

HCL 研究的是 Harness 更新后如何兼顾新任务与旧任务；SkillBoost 研究的是用回归检查和约束防止新 Skill 伤害旧能力。我们进一步研究当新旧方法都各有用处时，怎样通过复习修好冲突，而不是只能拒绝新更新。[S29][S30] Why SFT Fails to Learn（ACL 2026） 已研究 left-side forgetting，用全局 shuffle 和退化数据重采样恢复较早样本；这属于已有保留基线，不是 I3 首次提出的机制。[M27]

Insight （为何可解）

有些退化未必是忘记，而是两个原本都有效的方法，被用在了不适合的场景。只要找到“什么时候用旧规则、什么时候用新规则”的区别，少量针对这些边界的练习，可能比全部重放旧经验更有效。

Design （如何做）

比较修改前后的失败轨迹，找到出现冲突的条件，自动生成少量只改变一个关键条件的练习。用这些例子修订 Skill 的适用范围或选择规则，必要时再对参数做巩固。最终既要会用新方法，也不能丢旧能力。

实验设计 （怎么验证）

准备两套分别有效、合起来容易冲突的 Skill，并加入自然学习中出现的冲突案例。比较退化即回滚、均匀重放、MIR 风格重放、针对冲突条件复习；固定复习次数和记忆预算。分别测旧能力保持、新能力增益、组合任务成功率。如果优势只来自存了更多规则或多练了题，就不能归因于我们的复习方法。[M09]

NC 2021 带来的评测提醒：Ten 等在人类活动选择模型中使用学习表现变化的绝对值作为 LP，下降和上升都可能形成高变化信号；检测退步的做法与既有 TSCL/MIR 有关，不是 I3 的新颖性。[E19][M04] I3 可以额外构造“旧技能退化 → 重练恢复 → 再次退化”的对照轨迹，报告三个不同指标：①近期能力变化绝对值；②真正新增技能的独立收益；③经历其他更新后仍保留的净能力增益。若前者很高、后两者趋零，就不能把系统描述为持续变好。这是待验证的 RSI 失败模式，不是 NC 论文已经发现的 LLM 现象。

I4：生产性失败——失败一次就总结，还是再试几次？

信号对不对有没有新东西采不采得到

一句话：API 超时一次，Agent 就总结“这个工具以后别用”，可能学错。什么时候应该继续试，什么时候才值得把经验写进 Skill？

Challenge （难在哪里）

一次失败可能是策略错了，也可能只是网络偶尔超时。太早总结，会把偶然现象当成通用规律；继续试太久，又会浪费探索预算。RSI 不一定有人告诉它正确做法，需要它自己根据执行反馈辨别原因。

现有工作 （别人研究了什么）

ActiveSaddler 研究的是哪些失败模式更值得继续训练；Trace2Skill 研究的是怎样从多条执行轨迹提炼可复用 Skill。我们研究的是面对这一次失败，下一步试什么，什么时候证据够了可以开始总结。[S16][S31] Ding 等（npj 2026）已在人类运动学习中发现有结构的多峰探索和突然的规则切换；它支持“区分竞争解释比机械重复更有价值”这一机制动机，但没有检验 LLM 的 Skill 更新。[E26] 看随机探索与假设检验的原文证据。

Insight （为何可解）

不同失败原因，往往会对下一次尝试给出不同预测。一次只改变一个关键条件，就有可能排除错误解释。当继续探索已经很难提供新信息时，再停止并总结经验。关键不是失败越多越好，而是每次尝试能否帮助弄清原因。要让两个可能原因对某次试验给出不同预测，否则这次重试再成功，也无法区分它们。

Design （如何做）

失败后先列出两三个可能原因，选择最能把它们区分开的安全小实验，例如同样条件重试或只改变一个 API 参数。持续记录支持和反对各原因的证据，足够确定再更新 Skill；证据不够时允许暂不总结。所有试验只在受控环境运行。

实验设计 （怎么验证）

在 API 异常、工具使用和代码执行任务上，比较失败后立即总结、固定重试 N 次、随机补充尝试、针对可能原因选试验并决定停止。匹配 Token、环境调用和总预算，混合可控故障与自然失败。主要比较写入错误规则的比例、未见场景的迁移、单位成本的学习收益；不把“多试几次自然多成功”误当成新机制。整个过程不需要外部教师告诉标准答案。

I5：十模型互教——什么时候交换舞伴，才能一起变强？

I6：失败学习价值——同样答错，哪条失败更值得学习？

信号对不对有没有新东西采不采得到

一句话：同一个模型解同一道积分题，两次都给出相同的错误答案：一次直接套错公式，一次尝试了几个正确步骤却仍答错。用哪一次失败来学习，才能让以后更多新题做对？又该在什么时候停止重试、改天再学？

Challenge （难在哪里）

只看最终答案，两条失败都是零分；但错误过程中有没有正确子步骤、有没有暴露新原因，可能决定这次纠错能学到什么。失败轨迹更长、看起来更接近答案，也未必更值得训练。如果同一道题已连续失败，继续采样可能浪费预算；可现在学不会，不代表补过基础后仍学不会。

现有工作 （别人研究了什么）

Learn from Failure 研究如何利用失败的定理证明轨迹；SOAR 根据学生实际进步生成值得学习的新题；BEACON 研究推理时何时停止继续采样；Region of Proximal Learning 研究人类何时离开当前学习材料。我们研究的是同题同样答错时，哪条失败过程在固定纠错后更能提高未来独立能力，以及何时停止收集这种失败，不是更换教学方式或提高当前 pass@k。[S47][S48][E16] Why SFT Fails to Learn（ACL 2026） 从训练后的失败题分析五种可能原因，提示“同样答错，背后状态不一定一样”，但它没有在同题相同终点上隔离失败轨迹过程本身的学习价值。[M27] Hypothesis Testing（npj 2026）则在人类运动学习中观测到结构化的候选规则探索，训练位置都能达标的 476 人在新位置却分成七类迁移轨迹。I6 要验证的仍是同一道题的两条失败过程，哪个在固定纠错后更有跨题净收益。[E26]

Insight （为何可解）

失败过程比最终对错多提供一层信息：模型已经走对了哪几步、在哪个规则上反复走错、下一次失败是否仍会暴露新缺口。从相同模型出发，用相同正确反馈分别纠正不同失败，再比较未见题的独立进步，就可以为每条失败估计真实学习价值。如果新失败已很难增加收益，就应比较纠正已有失败、换题或暂缓后重访。

Design （如何做）

从同一模型检查点在同一道题上采集多条自然失败，尽量匹配最终错误、轨迹长度与反馈信息；随机指定其中一条作为学习材料。固定正确答案、教学顺序、更新器和训练预算，分叉更新并在撤掉提示后测新题。先用真实迁移增益给失败定价，再训练只看纠错前信息的轻量预测器；比较继续收集、纠正已有、换题、暂缓重访的下一次投入。

固定纠错方法同反馈、同 LoRA/Skill 预算
新题独立后测迁移、旧能力回归、成本
选失败与停止时机继续 / 换题 / 暂缓重访

实验设计 （怎么验证）

先做同题配对实验，比较只看正确解法、随机失败、最长失败、最接近正确的失败、按置信度选、预测学习增益选；模型快照、教师反馈和总 token/FLOPs 匹配。报告无提示未见题提升、旧能力损失与失败价值的跨题稳定性。再比较固定重试 K 次、简单学习进展阈值、收益驱动停止/暂缓，并事先约定重访条件。如果差异只来自更长轨迹或更多训练，或早停没超过简单阈值，就缩小主张，不另加复杂停止模块。[M12][S45]

I7：学习顺序——先看例题，还是先独立尝试？

采不采得到吸收了会不会丢

一句话：学同一道多步骤数学题，模型 A 先看完整解法再练习，模型 B 先独立尝试、失败后再看同一解法。学完撤掉例题，谁更会解新题？这种优势会不会随着模型变强而反过来？

Challenge （难在哪里）

看过示范后立即答对，可能只是照着步骤模仿；先做再学的提升，也可能只是比另一组多练了一次。更难的是，两种顺序可能让模型探索到不同的正确解题路径，而当前分数却差不多。只比较一次做题正确率，无法判断模型有没有在后续更新中真正学会、是否丢掉了原有的解法。

现有工作 （别人研究了什么）

Sinha & Kapur（2021） 汇总 53 项人类教育研究，发现某些概念知识和迁移任务中“先解题后教学”有优势，但程序性知识未显示同样的总体差异；Najar 等（2015） 已研究按学生状态选择示范或练习；He 等（2025） 还观察到不同人群的顺序优势可能相反。我们不是首次比较教学顺序，而是研究 LLM 经过相同预算的持久更新后，独立解题能力、可采样的正确解法和多轮迁移如何受顺序影响。

Insight （为何可解）

两组都能看到同一份正确示范，但先试的人在看到答案前，已经走过自己的候选路径；先看的人可能更快掌握标准步骤，却可能更依赖示范。这两种影响不能靠眼前一道题判断。只改变学习先后，撤掉教师和临时上下文后再测新题，就能判断顺序究竟改变了独立能力，还是只改变了即时模仿。

Design （如何做）

在同一个模型检查点、同一组题目上随机分成两支：A 先看示范再练习，B 先独立尝试再看相同示范。控制示范内容、尝试次数、采样配置、教师调用、训练 token 和 LoRA/Skill 更新步数。更新完清空示范上下文，在未见题上独立测试。只有先证明不同任务或模型阶段的最佳顺序确实会变化，才考虑用先前历史训练顺序选择器。

只交换先后次序先学再做 / 先做再学
撤掉示范独立考试新题正确率与正确解法
多轮更新后复测顺序优势是否改变

实验设计 （怎么验证）

先选一类多步骤数学题，比较固定先学、固定先试、匹配次数的额外练习、无示范基线；后续只有在发现稳定顺序异质性时，才增加按历史能力选择和 contextual bandit 对照。用同预算的无提示 pass@1、固定 k 下的 pass@k、不同且正确的解法数量、旧能力保持及跨多轮更新的迁移作为指标。按知识点聚类统计，不按同题多次采样扩大样本量。如果优势只是练习次数更多或无效答案更多，就不能说顺序提高了探索与自我改进。

I8：错误学习迁移——为什么改正一种错误能学会一类题？

信号对不对吸收了会不会丢安全

一句话：两个模型都把一道积分题做错。一个看完正确答案只会重做原题；另一个却学会同一公式，连几十道新题也能做。纠正哪个错误更可能举一反三？能否在真正训练前判断？

Challenge （难在哪里）

模型很自信地答错，不代表它缺的知识少，也不代表纠正后进步一定大。当前题答对、同模板变体答对、真正掌握一条规则是不同的结果。每个错题都完整训练一遍才能知道收益，成本太高；直接按难度、置信度或损失排序，又可能选中只会记住答案、却不会迁移的错误。

现有工作 （别人研究了什么）

Hypercorrection 与 Nature Communications 2018 的人类学习研究发现，已有信念与可信反馈的冲突可能影响纠错记忆，但不等于 LLM 已能跨题学习。Self-Error-Instruct 已按模型错误类型生成并筛选训练数据；LESS 和 DATAPROPHET 已研究训练前预测数据价值；RULE-EDIT 已区分规则文本修复与实例迁移。Why SFT Fails to Learn（ACL 2026） 还把已训练却没学会的样本拆成缺知识、旧知识冲突、SFT 内部冲突、遗忘和训练不足；但主要评价训练样本的恢复，而非新题规则迁移。[M27] Hypothesis Testing（npj 2026）显示人类在已练位置成功后，仍可能使用无法迁移的平移规则；这提供了“排除错误规则”与“纠正一道题”需要区分的实验动机，不是 LLM 已验证的机制。[E26] 我们研究的是这个模型当前犯的某个错误，在固定纠错预算后究竟能让多少未见同规则题变好，而不是首次使用错题或首次预测训练价值。[E12][E18][S40][M10][M13][S41]

Insight （为何可解）

一个错误有多值得纠正，至少可能受三个条件影响：模型是否已有理解正确规则的基础、这条错误规则影响多少道不同题、当前更新方式能否真正改变规则的使用。例如，遗漏同一积分公式分母的模型可能只差关键一步；但若连基本运算都不会，直接给公式未必能被吸收。置信度或强烈的“原来我错了”可以作为候选信号，不能直接等于真实学习收益。

I9：集中还是交错——什么时候应该切换练习方式？

采不采得到吸收了会不会丢

一句话：同样练 A、B、C 三类题，连续做 A 可能越做越顺，混合起来却容易用错方法；但基础尚未形成就直接交错，也可能学不进去。模型什么时候该集中建立规则，什么时候该交错练习不同规则？进一步问：同一批 A/B 材料不同顺序后，即使当前能力相近，下一次学习未见规则 C 的速度是否仍不同？

Challenge （难在哪里）

连续练同类题时训练正确率很高，不代表新题里知道该用哪条规则；交错训练又可能太早。交错还同时改变复习间隔、最近练习时间和相邻类别对比，因此一次后测提升不能自动归因于学会选规则。更难的是模型能力会不断变化，固定时点切换未必合适。仅比较训练结束时谁分数高，也可能看不出哪个历史让模型下一次更容易学新规则。

现有工作 （别人研究了什么）

Insight （为何可解）

模型的学习可能经历两种不同需求：先把某一条规则学稳，再学会从多个规则中选对一个。因此，只看训练正确率容易误判；独立单主题题是否掌握、混合题是否选错规则、经历其他更新后是否退化，可能预测下一步该采用哪种练习安排。这是待验证假设，不预设一定先集中后交错。新增的解释可能是：两种历史得到类似当前分数，却形成不同规则表征；有的路径只适合原题的局部捷径，有的更利于吸收新规则。npj 2026 的人类运动学习只提供这一可能性的机制类比，不是 LLM 实测。[E26] NC 2025 新边界：规则是否相同与输入特征是否部分重叠要分开；部分重叠可能使两任务更难在早期交错中建立区分。I9 不能只用“题目文字相似度”代替规则关系，也不能把交错初期慢误读为最终迁移差。[E99]

Challenge （难在哪里）

高频知识、语义相关与图谱枢纽不等于必要前置；当前题做对也不代表下一轮学得更快。必须区分补 P 的直接迁移、学 T 的额外可学习性及预算增加。

现有工作 （别人研究了什么）

Nature Communications 2026 Compressive Learning 研究人类学习网络中枢纽的预学习，不证明 LLM 数学先修；SkillGraph/SkillDAG/SE-GoS 已维护技能依赖图与执行检索；ESCO-PrereqSkill 已预测先修边；SOAR 已训练有价值的中间题；ACL 2026 ILP 已检查缺少基础知识。我们需要直接检验补因果前置知识能否解锁多任务未来学习。[E401][S401][S402][S403][S404][S47][M27]

Insight （为何可解）

多个下游失败可能共同受某条尚未掌握的 P 限制；补 P 的价值不是其出现频率，而是它是否改变模型下一轮从同一 T 训练流中吸收知识的能力。这种状态依赖先修关系需要因果试训而非纯语义评分。

Design （如何做）

从多任务失败簇提候选 P → 用独立知识探针和少量试训核查 → 固定 LoRA 更新器补 P → 再用相同 T 任务流训练 → 清空辅助，在未见题上测第二段独立增益。对比随机 P、高频非先修 P、更多直接练 T 和 SOAR 式中间题，全部计入预算。

失败任务簇共享错误但未必同一缺口
主动核验 P因果前置 vs 相关图边
持久学习 P固定 LoRA / 验证器
再次学习 T独立增益 × 多任务族

实验设计 （怎么验证）

P0：可验证规则 DAG，匹配因果前置与高频非前置，并设已经会 P 的负对照；P1：真实前置图对 Agent 隐藏，从失败中提案，比较 SkillGraph、SkillDAG、ESCO-PrereqSkill 和 SOAR 相关强基线；P2：两级依赖链中检验学习机会是否跨轮解锁。主指标是补 P 后再学 T 的第二阶段净学习增量、解锁任务族数量、旧能力回归和总成本。只提高当前题准确率就不独立立题。

正交边界：I8 纠正一个错误后测同规则迁移；I12 要证明补前置 P 后不同 T 的后续学习潜力增加；I9 只改课程顺序，I2 改教学方式。I12 完整论文定位、公式、P0–P2 与 Go/Merge/Stop →
