RSI RESEARCH DOSSIER / 09

Adaptive Teaching through Teacher–Student Co-Evolution

I2：因材施教的师生共进化——学生变强，教师也更会教

固定师生、教材与更新器，研究学生真实回应能否比单向示范提供更多知识状态信息；再检验这种信息能否促成学生的持久独立学习，以及教师跨学生的教学能力增长。

更新 2026-10-28来源可追踪提案尚待实验

核心问题：学生在变强，教师能否越来越会教？

I2：同一个学生，早期可能需要补全关键步骤，后来可能只需要指出错误前提。教师能否从过去“怎样教、学生后来真正学会了什么”的经验中改进教学，并随着学生的成长持续调整？

例如，学生最初不会设置二重积分的积分边界，教师给出分步解释；学生掌握基础后，逐步展开可能只是在重复旧知识，比较两个相似区域的差别反而更有帮助。这个顺序只是待验证例子，不预设弱学生必须看示范、强学生必须自主探索。

学生学会解题

把知识写入自己的能力

真实更新参数或版本化任务 Skill。清空课堂对话、撤掉教师后，在新题和后续轮次上独立进步。

教师学会教学

把教学经验写入自己的教法

真实更新教学策略、教学 Skill 或教学 LoRA。对同一批冻结学生，后期教师比早期教师带来更高的独立学习增益。

合并而不是另起编号：保留原 I2 的“同样犯错，最合适的学法可能不同”与小预算试学；把试学结果用于教师自身的持久更新。这次新增的是一个可验证的信息来源：学生在双向交流中的真实追问、错误应用与反驳，是否让教师比只看原题与静态诊断更准确地判断怎样教？这不是另一个通用多 Agent 系统。

Bayesian Teaching 提供的启发：正确答案不等于好的教学目标

论文实际做了什么：Qiu 等的 Bayesian teaching enables probabilistic reasoning in large language models（Nature Communications，2026）让模型模仿根据当前证据更新判断的 Bayesian Assistant，并与始终给出正确选项的 Oracle 比较；在所测推荐任务中，Bayesian 教学更有效，并展示跨任务迁移。[S100]

可以迁移的洞察：教学监督要对应学生未来能执行的判断，而不能仅由教师答案正确率来评价。Oracle 利用真实偏好给出正确选项，未必示范如何从有限证据逐步判断。

不能扩大成的结论：该论文训练的是学生去模仿预测行为，不是训练一个持续进化的 LLM 教师，也没有证明必须传递显式思维链；它不主张故意给错答案、更弱教师永远更好，或禁止教师使用额外信息。I2 将其作为教学目标的启发，不把它当作师生共进化已经有效的证据。

npj 2025：双向交流改变的是接收反馈的方式吗？

原文的可观察现象。Yin 等（npj Science of Learning，2025）对 100 对人类参与者进行创造力任务实验，设置双向反馈、单向反馈、无关交流和无反馈四种条件。接受者先提出鞋子的不同用途，再收到建议，后测原主题和新的雨伞/书籍主题。双向反馈条件在多项原题习得及新主题表现上更好；研究同时观察脑间同步，但这些相关信号不能当作 LLM 的训练模块。[E27]

研究者把反馈吸收分成 Ignore / Copy / Apply：不使用、照搬具体建议、在原题上发展出新的用法。双向反馈组的 Apply 数量显著更高；但 Copy/Apply 标签是结合原题后测回答事后编码的，不能直接当作教学过程中已经知道的学生理解程度。更重要的是：Apply 与原题习得显著相关，却没有观察到 Apply 与新主题迁移之间的显著直接相关。[E27]

从论文能直接得到什么不能得到什么I2 打算多验证什么
双向互动可能使反馈更容易被应用，而非简单减少 Ignore；反馈量也不同不是互动本身唯一造成 Apply；Apply 的比例差异不能直接当成所有指标显著同教师/同总预算，比较真实回应与错配回应，隔离学生状态信息
反馈应用与原题表现关联不能说明学生掌握持久的新知识，也未直接解释新主题迁移反馈后独立探针、真实 LoRA 更新后的跨题迁移和后续保持分开测
脑间同步与创造力提高关联不能证明同步本身导致学习；不能把它对应为 LLM 隐层同步只取可操作的回应—教学调整—学习收益关系，不迁移人脑测量设备

对 I2 的新问题：真实的学生回应，究竟只是增加 Token、引导教师再说一遍，还是暴露出只有这个学生才有的知识缺口，让教师能提供更有效的下一条反馈？这与原 I2“教法要随学生成长改变”的主线一致。

Challenge：两边分数都涨，还不能证明教师更会教

第一，学生变了，教法的效果也可能变。同一错误标签不能说明已有子技能、可理解的解释和最有效的练习方式。旧反馈可能不再代表当前学生的真实学习反应。

第二，教师评价存在混淆。学生因训练而变强，本来就更容易答对；不能把教师后来面对更强学生时的课堂成功率，当成教师教学能力提高。

第三，当场听懂不等于学会。教师话语、标准答案甚至学生自己的课堂笔记留在上下文中，都可能改善眼前表现，但不一定转化为持久能力。

第四，试教也花计算。真实更新学生副本才知道哪种教法有效，但多分支会增加训练成本。每次诊断、候选教学、学生更新和独立后测都要计费，不能只比较学生主分支的步数。

第五，学生回应可能有信息，也可能只是重复或误导。学生说“我懂了”，不能证明已掌握；学生的追问可能指出真正的规则边界，也可能仅增加对话长度。若等到后测答对才将其标成 Apply，再拿该标签预测后测，便存在结果信息混用。I2 必须在真实参数更新前单独记录学生回应，控制反馈者可见信息与学习总预算。[E27][S105][S106]

Insight：学习反应会变化，而真实反馈能教会教师如何跟上

待检验关系：随着学生获得新能力，教学方式的收益排序可能改变；教师若持续利用当前学生更新后的独立学习增益，就可能学会跟随这种变化，而不仅是反复输出更正确的答案。

“因材施教”在这里不是让教师给学生贴一个静态标签，而是用真实经历更新判断：什么状态的学生，接受什么解释或练习后，能够在新问题上独立进步。原 I2 的试学用于获得这种证据，教师的持久更新用于把一次经验转成以后可复用的教法。

这条关系可能不成立：若固定教法已经足够，或固定教师仅凭当前学生描述就能同样好地调整，就没有证据说明必须持续训练教师。实验要允许这些结果，而不是预设共进化一定获胜。

从双向交流得到的新增机制假设：教师本来知道题目和正确答案，却未必知道学生究竟误解哪条规则；学生在交流中尝试应用、提出边界问题或反驳，可能提供比静态学生画像更及时的状态证据。真正要验证的是：这种回应与当前学生的一一对应关系，能否在相同信息/更新预算下改善教师下一条反馈及学生后续的持久净学习？而不是证明“多聊几轮更好”。[E27][S106]

最近邻：共同进化已经存在，I2 需要多证明哪一步？

历史起点：Learning to Teach（ICLR 2018）已明确用学生反馈优化教师策略，提出师生共进化。因此“教师和学生都更新”不是新的研究主张。[M100] 下表区分论文实际更新什么、反馈来自哪里，以及 I2 的决定性对照。

Closest work已有机制与共同点I2 的具体差别为什么重要 / 必需证据
INTERACT，ACL 2025 [S105]让 LLM 学生在多轮师生对话中主动追问，通过上下文学习新概念，改善当前对话内测试表现。I2 需要学生经过真实参数/Skill 更新、清空课堂会话后仍有未见题收益；还要证明真实回应相较错配回应的增量信息。同轮数、同 Token 的单向/固定多轮/真实回应/错配回应；不能把 INTERACT 的上下文收益当持久学习基线原表。
AToM / AdapT，ACL 2024 [S106]已有通过模拟 Bayesian 学生与人类被试，推断学生误解并自适应选择示例的研究。“教师识别学生误解”不是空白；I2 更具体地问真实逐轮回应对持久更新后的收益是否有超出独立诊断的作用。额外设“教师只看同预算静态诊断”基线；避免把表面互动改善归因于额外的误解标签。
Learning by Teaching，NeurIPS 2024 [S20]利用学生反馈改善教师推理示范，也可用偏好训练持久更新教师。不能声称首次“学生反馈教会教师”；I2 进一步研究学生回应怎样改变教学内容，并在未见学生快照上检验教学能力。固定教师版本交叉评估，比较真实回应、错配回应与只使用学生最终成绩作为教师更新信号。
RLT，2025 [S101]教师看到题目和答案，学习产生适合学生的解释；以学生对解释/答案的概率等信号训练教师，再蒸馏学生。原文明确未探索两者并行训练；I2 持续保留学生成长，并以真实更新后的新题收益修订教法。比较固定 RLT 教师、持续条件化但不更新的教师与持续更新教师，不能只胜过通用 Prompt。
SCAS，2026 预印本 [S102]在已经核实正确的教师答案中，依据学生相关的学习成本代理选择监督。I2 不只从固定答案池选答案，而是更新教学策略；主要反馈是持久学习收益。与学生感知的答案选择和相同代理奖励比较，检验真实反馈是否有增量信息。此处只记录已核对预印本，不沿用未核实的会议标签。
Sherpa，2026-10 预印本 [S103]多轮 RL 训练教师适应不同模拟学生；学生骨干冻结，收益由教学后的上下文表现定义。I2 学生必须真实持久更新，下一轮需求由学习自然改变，不靠预设学习偏好标签。把同样的教学接口接到可更新学生上，验证课堂收益与独立更新后收益是否不同。
Eduardo / Assistance Dilemma，2026-10 [S19]遮蔽教师话语，在新变体上后测；冻结学生，保留学生自己的课堂话语。I2 主要后测清空双方临时对话，只保留允许的学习产物。分别报告原文的“只留学生笔记”后测与无课堂笔记的持久学习测试，不把两种目标混用。
SOAR · 完整精读，ICML 2026 [S17][S47]教师生成64题集合，真正训练多个Student分支；用困难题的更新前后准确率差训练Teacher，并通过Promotion持续提高Student基准。真实增益奖励及双边更新均已有直接先例。I2 首先固定题目与答案，研究怎样表达、解释与纠错，以及教法能否在变化中的不同学生之间迁移，不再重新做题目生成。保留SOAR式真实学习奖励作为强基线；固定课程，比较读取当前学生历史/状态与仅使用平均反馈的教师。需教师版本×冻结学生快照交叉测试，不能声称首次用真实学习增益训练教师。
OPCoD，2026 [S33]互补模型轮流互教，双方参数持续更新；依据认知状态门控反馈并锚定问题。I2 单独用受教者的学习增益更新教师教学能力，不把教师自身答题变强等同于更会教。比较只更新解题能力的互教，与显式更新教学策略的方案；对同一冻结学生库交叉评估教师版本。
Pedagogical RL，作者研究报告 2026-05 [S104]特权信息辅助教师生成正确且学生较易吸收的轨迹，随后以 surprisal-gated imitation 更新学生。I2 研究持续教学经验是否能追踪变化中的学生，以及代理可学性与真实跨题增益是否一致。同监督源、同成本比较概率代理与真实学习反馈；该来源是作者报告，不标作已发表会议论文。
Bayesian Teaching，Nature Communications 2026 [S100]监督学生模仿证据条件下的规范预测行为，展示策略迁移。I2 的教师策略本身可更新，目标是对当前学生产生可持续学习收益。作为“结果正确性不是唯一教学质量指标”的证据，不作为共同进化的直接基线。

保留原 I2 的边界：RSIFlow 研究改模型、Harness 还是任务产物；MetaSkill-Evolve 研究任务与元技能的共同改进。I2 固定更新对象与更新器，不再同时做更新表面路由。[S28][S06]

范围判断：INTERACT 已让模型通过互动提问学习，AToM 已利用学生误解调整示例，LbT 已从学生反馈更新教师，Sherpa 已训练多轮适应性教师，OPCoD 已进行双向参数共进化。因而 I2 目前能争取的新证据，只能来自学生真实回应相较能力匹配的错配回应，是否对持久学习与后续教师教学能力有可重复的因果增量；不是给“双向对话”换一个名称。[S105][S106][S20][S103][S33]

Design：教一轮、真学习、独立测，再更新教法

保存师生版本教师 T_t 与学生 S_t
固定教材试教同题、同答案、不同表达
学生真实更新固定训练器 / Skill 写入器
撤辅独立测试新题收益与旧能力保持
教师改进教法保留经验，面对 S_(t+1)

1. 固定配对和教学材料，隔离“怎样教”

第一阶段只用一个教师与一个持续成长的学生；不同学生起点作为独立重复，而非动态换伴。所有对照共享题目流、参考答案、题目难度和教师可用知识。固定“先完成统一诊断尝试 → 教师反馈 → 学生更新”的顺序，不优化 I7 的先后顺序。

2. 先用三种可检查的教学形式

同一知识点生成分步解释、关键反例对比、针对错误步骤的引导修正。这三种形式只是启动实验的候选，不是三个声称新颖的模块。教师读取学生历史与诊断证据，学习如何组织当前反馈；不得读取最终测试答案。

3. 原 I2 的小预算试学，变成教师的经验来源

从同一个 S_t 快照复制配对分支，使用不同教学内容、相同学生更新步数与随机种子集合。清空课堂上下文，在另一个开发题集测收益。只在可信差异下形成“哪种教法更好”的反馈；差异小于噪声时保留为不确定，不强行选冠军。

4. 教师与学生分别保留不同的学习产物

Skill 验证轨道：继承原 I2 的固定任务 Skill 写入器；学生更新任务 Skill，教师更新有长度上限的教学 Skill。冻结底座、编辑器与权限，测的是系统层持久学习，不称权重增长。参数验证轨道：教师教学 LoRA 与学生解题 LoRA 分开保存，学生更新规则固定；教师可先用配对教学收益形成偏好更新，再比较 RL。两条轨道分别报告，不把载体切换收益归功于因材施教。

跨轮闭环：保留 S_(t+1) 的真实更新，教师保留 T_(t+1) 的教学更新；下一轮针对已经变化的学生重新教学。每个测量窗口内冻结教师和学生起点，窗口结束后再交替更新，避免把同时漂移的两个变量混在一次因果比较里。

教师在主实验中不增加新的教材或答案权限，以便隔离教学经验的作用；它的自身解题能力作为辅助指标记录。允许后续研究知识与教法共同增长，但不把它塞入首篇 I2。

教师的奖励：不是把眼前题讲对，而是学生以后自己会做

S'_t(a) = U(S_t, Teach(T_t, x, history_t; a); B_S)

U 是每组相同的学生更新器，a 表示教学候选。教师反馈在真实更新后计算，而不是用学生点头、复述答案或当前题解出与否替代。

G_t(a) = Acc_ind(S'_t(a), D_meta) − Acc_ind(S_t, D_meta)
R_T(a) = G_t(a) − λ · Regression_old(a) − μ · Cost(a)

D_meta 是用于教师学习的开发集，不是最终未见测试集。能力回归按旧任务独立评估；成本包括诊断、教师生成、学生分支训练、教师更新与后测。λ、μ 与预算在开发阶段固定，同时分开报告原始收益、回归和花费，不只报告一个合成分数。

同一 S_t 的候选教法可以相互作为配对基线。跨阶段比较时，优先增加一个固定教学策略的同起点分支，避免学生自然变强导致教师获得虚高奖励。最终测试族和教师交叉评估学生库不进入教师训练。

P0｜真实双向回应，究竟提供了多少独立学习信息？

先定义一个可以否定的假设：对同一个学生、同一道题和相同的更新预算，教师根据这个学生的真实追问与规则应用尝试调整反馈，可能比仅提供同量解释或根据另一个相近学生的回应调整反馈，让它在真正更新参数后学会更多未见题。这个差异不应先归因于多轮聊天。[E27][S105][S106]

分支教师能看到什么下一轮怎么教主要排除什么解释
A · 单向解释题目、统一前测与正确规则，不读取学生回应一次性给同等预算的完整解释直接示范是否已经足够
B · 固定多轮同一教材及先前的静态诊断；学生可作回应，但教师不据此改话术按预注册模板分轮解释与练习是不是只因拆成更多轮、学生多练了几次
C · 真实双向该学生刚刚对同一规则的真实追问、误用或反驳只在预设知识范围内根据真实回应调整下一条反馈回应是否暴露了学生特有的知识缺口
D · 错配回应同一题目、相近初始能力和回应类型，但回应来自另一位学生仍由同一个教师按所见回应调整任何貌似互动的文本、额外诊断 Token 是否就足够

关键 C−D 比较：在同一学生快照上随机分配各分支，C 与 D 都使用相同教学接口和轮数；D 的回应来自同题同技能、前测能力相近且语义上可信的其他学生，而非故意塞不相关或错误文本。记录各轮学生实际输出、教师看到的来源 ID、总 Token、纠正规则以及反馈正确性。避免 D 明显不通顺，导致“教师被扰乱”被误算成学生个体信息价值。

共同的真实学习终点：所有分支使用相同 SFT / LoRA 更新器或固定的 Skill 写入器，并分别报告，不能把当前会话里的复述算作学习。更新后清空师生对话与临时答案，测未见同规则异结构题、旧能力回归和若干后续更新后的保持。还应单列反馈刚结束时的独立规则应用探针，但必须用独立于最终测试的题目；不能像人类论文事后编码那样，先看最终后测再定义“已 Apply”。[E27][S107]

执行次序：P0 冻结教师，只研究学生回应是否具有可用的额外信息；如果 C 相对 D 有稳定优势，再用 P0 开发轨迹的学习收益训练教师教学 Skill / LoRA，并执行原 E2：教师版本 × 冻结学生快照。这样分开回答“真实回应有没有价值”与“教师能否把利用回应的本领学进去”。

反证条件：若 C 仅让当场作答提高、撤掉会话后没有跨题收益，不能称持久学习；若 C≈D，真实回应的一一对应可能没有新增信息；若固定教师结合静态误解诊断已与 C 相当，则直接使用简单诊断，不再增加教师反馈解释器。只有对应关系、独立学习收益和教师跨学生迁移均得到受控支持，才考虑复杂的共同进化优化。

决定性实验：分开证明学生会做、教师会教、两者需要共同更新

E0 先行：采用 A 单向 / B 固定多轮 / C 真实回应 / D 匹配错配回应 的 P0 四分支。先用冻结教师判断双向回应是否额外改善真实更新后的独立迁移，再验证教师能否把这种信息用法持久学会。E0 的试教、训练与诊断成本额外计入，下述原先的 216 分支只是其他教法对照的计划规模，不包含 E0。

E1 · 学生变强后，原来的最佳教法真的会改变吗？

保存同一学生在早、中、后三个真实学习阶段的快照。固定知识点、教师参考知识与训练预算，随机分叉三种教学形式，估计各自新题学习增益。比较错误标签/当前正确率、普通 contextual bandit、少量试学响应和学生感知答案选择，检验是否存在可重复的教法排序变化。没有变化也要保留，不能只展示发生反转的题。

E2 · 教师越来越会教，还是学生越来越好教？

教师版本 × 冻结学生快照的交叉评估。让早期教师 T_0、后期教师 T_k 分别教同一个 S_0、同一个 S_k，以及训练中从未见过的学生快照。每一格重新复制该学生、实施同量教学与更新，比较它在未知题上的增益。若 T_k 只在和自己一起长大的 S_k 上有效，只能说明局部适配；在新学生/新任务上也改善，才支持教学能力的迁移。

TeachingGain(T, S) = Acc_ind(U(S, Teach(T); B), D_audit) − Acc_ind(S, D_audit)

不能比较 T_0 教弱学生的绝对分数与 T_k 教强学生的绝对分数。也不能把某个单一静态学生上的教法提升自动称为普遍教学能力提高。

另做两项消融：把真实学习增益换成当场成功率/概率代理；打乱同预算试教的学生—反馈对应关系。加入真实学习奖励相同但不读取当前学生状态的教师，以及普通 bandit、RLT 风格解释、SCAS 监督筛选。SOAR 原版课程生成及Grounded Reward与 OPCoD 互教单列为相邻强基线；SOAR也已报告Intrinsic代理的训练不稳定与语义多样性下降，不能单纯把“更换真实奖励”称为新机制。若为固定教材做适配，明确标注改动，不把适配结果冒充原论文复现。

最小验证规模与数据隔离

先用一对师生和 4 个知识点检查管线；再扩到 12 个任务族、2 个学生能力快照、3 种教法、3 个更新重复，共 216 个学生试学分支（计划数，不是结果）。连续学习先运行 6 轮，逐轮保存师生快照；出现稳定现象后，再扩跨模型和更多任务。

数据按题目模板与知识点家族拆分为教学、诊断、教师奖励、版本选择和最终审计；教师奖励集会被训练利用，不能称未见测试。教师升级不以最终测试成绩作奖励。主指标是未知题独立学习曲线、旧能力保持和固定学生库上的教师教学增益；全部分支与教师训练费用计入预算，同时报告匹配学生更新次数和匹配总算力两个视角。

支持继续：真实学生成长伴随稳定的教学收益变化；在独立 E0 中，真实回应（C）在同题同能力匹配下优于错配回应（D）且能保持参数更新后的未见题增益；后期教师在固定学生交叉评估中更有效；闭环优于可看当前状态的固定教师、固定学生库训练教师及相同奖励的通用策略，并能排除更多预算和答案泄漏。

缩小主张：只有共同成长的一对师生受益，报告配对内适应；没有跨学生提升就不称通用教学能力。如果静态条件化教师同样有效，则保留学习响应现象，不宣称教师持久更新必不可少。

定位：双边更新本身是已有方法。I2 希望解释和利用的是学生学习反应的变化，以及教师如何从这种变化中学会更有效的教法。需要新的受控证据，而不是“两个 Agent + 双层优化”的命名。
