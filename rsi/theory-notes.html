快学习与慢元学习：任务内状态变化和跨会话学法形成如何分离？

主归属 · 学习调控关联 · 能力形成
论文机制（按原文解释）Two Time Scales / Meta-RL

研究问题：一名学习者可以在短期内改变行动，还能经过长期训练改变自己利用反馈的方式；怎样用可操作干预分开两者？

机制主张：人工RNN会话内权重固定、依靠隐藏状态整合奖励，跨会话由A2C更新长期权重；真实小鼠的OFC CaMKII依赖可塑性和活动阶段性干预提供对应的神经因果证据。

关键公式与含义

快层：固定权重下更新历史状态（教学抽象）h[t+1]=f_φ(h[t],a[t],r[t])

逐项解释：RNN会话内接收动作/奖励历史，活动状态变化会改变选择，φ在本次500 trial中不更新。

边界：本式用trial为单位压缩实际网络多time step计算；小鼠神经元不一定采用这个递归函数。

LaTeX 源码（用于论文与笔记引用）
h_{t+1}=f_\phi(h_t,a_t,r_t)
慢层：会话结束后更新网络权重（教学抽象）φ[k+1]=MetaA2C(φ[k],session[k]); φ fixed within session k

逐项解释：慢更新让下一会话面对奖励反转时有更有效的快速状态响应；人工模型用A2C + RMSProp, 每session500 trials。

边界：Nature论文没有给出一条统一的生物梯度公式；MetaA2C是本站教学记号。

LaTeX 源码（用于论文与笔记引用）
\phi_{k+1}=\operatorname{MetaA2C}(\phi_k,\mathcal D_k),\qquad \phi_t=\phi_k\ \text{within session }k

推导顺序 / 机制解释

  1. 先区分时间轴：t为当前session内trial，k为跨session训练轮次；一个状态函数不等于两个参数优化器。
  2. 检查没有慢更新的快适应：冻结当前session的φ，仍可借历史活动改变行动和预测，即fast RL。
  3. 检测慢规则逐步形成：跨session改变φ后，后期奖励历史核增强并逐渐稳定，说明快行为的利用方式变了。
  4. 利用分阶段神经阻断验证：初期抑制CaMKII可塑性影响慢形成；专家时抑制同类可塑性未明显损害fast RL；短暂抑制OFC活动则损害专家的history dependence。

Policy Axis：怎样定量测量学习方式的改变而不只看最终任务分数？

主归属 · 学习调控关联 · 能力形成
论文机制（按原文解释）Learning Strategy Measurement

研究问题：两个模型当前正确率都很高，怎样知道它们利用过去反馈的方式已经不同？

机制主张：逐session从过去五轮动作与奖励历史拟合行为Logistic核，将奖励系数构成Policy Axis；其大小和方向稳定性提供观察更新策略的独立维度。

关键公式与含义

五步奖励与动作历史核logit P_left(t)=β0+Σ_{i=1}^5 βr,i(rL[t−i]−rR[t−i])+Σ_{i=1}^5 βc,i(cL[t−i]−cR[t−i])

逐项解释：奖励历史核说明小鼠如何利用近期奖励，选择历史核说明是否受自身动作序列影响；逐session独立拟合。

边界：是对原论文Eq.(12)结构的重写，具体编码需按作者真实左右动作/奖励指示变量复现。

LaTeX 源码（用于论文与笔记引用）
\log\frac{P_L(t)}{1-P_L(t)}=\beta_0+\sum_{i=1}^5\beta_{r,i}[r_L(t-i)-r_R(t-i)]+\sum_{i=1}^5\beta_{c,i}[c_L(t-i)-c_R(t-i)]
奖励策略轴相似度p_r(k)=[βr,1(k),...,βr,5(k)]; cos(p_r(k),p_r(j))

逐项解释：对比不同session奖励核方向，后期更稳定说明奖励历史策略形成趋于一致。

边界：稳定也可能是稳定的错误规则，所以余弦不是元学习净收益、效果大小或跨任务泛化指标。

LaTeX 源码（用于论文与笔记引用）
\mathbf p_r^{(k)}=(\beta_{r,1}^{(k)},\ldots,\beta_{r,5}^{(k)}),\quad\operatorname{sim}(k,j)=\frac{\langle\mathbf p_r^{(k)},\mathbf p_r^{(j)}\rangle}{\|\mathbf p_r^{(k)}\|\,\|\mathbf p_r^{(j)}\|}

推导顺序 / 机制解释

  1. 在每个会话拟合相同统计模型：固定相同特征定义和五轮历史窗口，避免后期强行为收益只是更好拟合不同输入格式。
  2. 分开强度与形状：核权重总和衡量依赖程度；向量夹角衡量对不同历史时距的加权结构。
  3. 在跨会话上观察策略形成：不能只看当天奖励，需比较后期策略轴相对早期是否稳定及是否跟随回报提升。
  4. 把策略指标和未来学习结果并列：RSI可以用类似核记录过去失败如何影响更新动作，但最终必须在真实任务C上测新规则的AULC和旧能力保持。

Meta-RSI 决定性干预：区分学法形成、任务执行与持久学习收益

主归属 · 学习调控关联 · 能力形成
RSI 研究假设（待验证）Causal Meta-Improvement Validation

研究问题：怎样排除‘Agent只是当前做得更好’，证明它经过历史学习以后真的更会更新自己？

机制主张：独立冻结/替换任务学习器和元学习规则，用相同初始检查点、相同学习材料、相同反馈及总预算比较新/旧元策略在真正未见任务的学习曲线增益。

关键公式与含义

未见C任务的元学习增益（本站假设）ΔMeta= AULC_C(ηnew,θ0) − AULC_C(ηold,θ0)

逐项解释：仅改变元更新规则η、固定任务学习者θ0与新任务C数据/训练步骤，比较从零真实学习曲线面积。

边界：AULC的积分点、归一化、总训练预算都须事先固定；不同初始C可解性不能被算作学法提升。

LaTeX 源码（用于论文与笔记引用）
\Delta_{\rm Meta}=\operatorname{AULC}_C(\eta_{\rm new},\theta_0)-\operatorname{AULC}_C(\eta_{\rm old},\theta_0)
考虑旧能力与总成本的净目标（本站假设）G_net=ΔMeta − λ OldRegress − β TotalCost(η discovery+evaluation)

逐项解释：既要计算新的未来学习，又要结算元规则训练开销、每次目标生成调用/训练成本和旧能力退化。

边界：不是Hattori/DiscoRL原始统一指标；两篇论文没有在LLM持续LoRA学习上实测它。

LaTeX 源码（用于论文与笔记引用）
G_{\rm net}=\Delta_{\rm Meta}-\lambda \operatorname{Regress}_{\rm old}-\beta C_{\rm meta+eval}

推导顺序 / 机制解释

  1. 只改规则不换题：A/B训练池与顺序、教师、反馈、学生初始化、每次更新token/FLOPs均固定；ηold/ηnew是唯一主干预。
  2. 新任务学生重置：在C之前从相同θ0和相同LoRA优化器状态起跑，只继承已验证元策略，不继承旧任务答案或上下文。
  3. 分阶段冻结与移除：比较允许/禁止Meta更新、允许/禁止任务学生更新、是否移除Meta策略输入；把‘形成/执行’与‘应用后实际学习’分开。
  4. 超越先例的必要条件：胜过最优固定学习规则、同容量历史条件路由、静态Loss调整及随机历史；在未见规则族和模型快照保持效果，才有足够基础支持已编号的I14继续独立推进。

Experience-Following 与单条 Memory 的反事实使用价值

主归属 · 能力形成关联 · 学习调控关联 · 学习信号
教学推导（非原文原式）Episodic Retrieval / Causal Utility

研究问题：检索一次正确但条件失配的经验，是否会改变未来任务表现？怎样区分过去的调用相关性与该条记录的真实作用？

机制主张：Experience-following说明输入相似时输出倾向模仿召回示范；但历史效用指标受任务难度、其他检索项和分布变化影响，严格因果贡献需要同任务随机保留/遮蔽。

逐项解释：Need表示预计再次用到的机会，Gain表示发生重放价值更新后未来决策回报预计改善多少。

\operatorname{Need}(s)=\sum_{k=0}^{\infty}\gamma^k\,P(S_{t+k}=s\mid\pi)

逐项解释：衡量策略改变后的预期收益，不是当前TD误差或原题错得多严重。

边界：这是标准理论直观形式；获取π_new常涉及假想更新，必须在训练前从合法开发信息估计，不能用最终B收益定义事前优先级。

LaTeX 源码（用于论文与笔记引用）

研究问题：在LLM参数空间里，同一条纠错反馈为什么能够或不能够改善从未直接训练的相关题？

机制主张：小步SGD时B损失的改变由A/B梯度内积的一阶近似决定；梯度对齐是可能的解释线索，而非充分因果证明。

关键公式与含义

GradSim（EMNLP 2024）GradSim(A,B)=⟨g_A,g_B⟩/(||g_A||·||g_B||); g=∇θL

逐项解释：模型在A/B目标上的损失梯度方向一致程度；原文报告与知识编辑Ripple成功正相关。

边界：要计算g_B往往需要B的正确监督，不能在最终留出B标签上算后宣称事前预测。

LaTeX 源码（用于论文与笔记引用）
\mathrm{GradSim}(A,B)=\frac{\langle\nabla_\theta L_A,\nabla_\theta L_B\rangle}{\|\nabla_\theta L_A\|\|\nabla_\theta L_B\|}
跨题损失的一阶展开θ′=θ−αg_A; ΔL_B≈−α⟨g_B,g_A⟩

逐项解释：内积正时B损失一阶近似下降，负时B可能受伤，接近零时一阶影响小。

边界：多步Adam、LoRA低秩约束、RL策略采样与最终生成正确率不由该式直接决定。

LaTeX 源码（用于论文与笔记引用）
\theta'=\theta-\alpha\nabla_\theta L_A,\qquad\Delta L_B\approx-\alpha\langle\nabla_\theta L_B,\nabla_\theta L_A\rangle

推导顺序 / 机制解释

  1. 明确更新A：对A损失做一个小SGD步长，得到θ′=θ−α∇L_A。
  2. 只看B损失如何变化：一阶展开L_B(θ′)≈L_B(θ)+∇L_Bᵀ(θ′−θ)。
  3. 代入A更新方向：得到ΔL_B≈−α∇L_Bᵀ∇L_A，因此产生正/负迁移的局部几何解释。
  4. 为事前预测设置防泄漏机制：实际研究中B作为留出题，不可用其标签或测得的训练后改进来决定A是否被训练；需用独立开发集代理、无标签特征或规则前测来预测。

RSI 假设：一次纠错的非局部净迁移与错误传播惩罚

主归属 · 能力形成关联 · 学习信号关联 · 学习调控
RSI 研究假设（待验证）RSI Nonlocal Learning

研究问题：固定训练器和纠错A后，B没有被训练但能否获得持久的净能力增长？

机制主张：真正主指标是未训练B的独立测试进步，并对规则错误传播到C、旧技能损失和全流程预算进行惩罚。

关键公式与含义

非局部参数更新净增益Δ_B = Acc_B(θ_after_edit_A) − Acc_B(θ_before)

逐项解释：不将B训练材料放入梯度；更新后去掉纠错A的临时答案、提示与辅助Skill，在未见规则题B上评测。

边界：若测试前仍让外部记忆或教师提供B规则，则不能当作参数内化。

LaTeX 源码（用于论文与笔记引用）
\Delta_B=\operatorname{Acc}_B(\theta_{\rm after\ edit\ A})-\operatorname{Acc}_B(\theta_{\rm before})
净收益目标G_net = Δ_B − λ Harm_C − μ Forget_old − β Cost_total

逐项解释：Harm_C是不同规则题的误传播，Forget_old是旧能力回归，成本含诊断、训练、选题/重放。

边界：权重必须预先确定并做Pareto敏感性，不能用事后结果任意挑选。

LaTeX 源码（用于论文与笔记引用）
G_{\rm net}=\Delta_B-\lambda\operatorname{Harm}_C-\mu\operatorname{Forget}_{\rm old}-\beta\operatorname{Cost}_{\rm total}

推导顺序 / 机制解释

  1. 冻结前测规则关系：模型当前是否知道A/B共享规则应由独立诊断集测试；B最终答案要在开发及训练过程不可见。
  2. 单因素纠错A：固定反馈与训练预算，A训练方法一致；先证实B的纯参数变化，再增加Need/Gain优先回放。
  3. 检查C误传播与旧能力：C与A表面近似但规则不同；如果C因错误规则转移而变差，净收益应扣除。
  4. 和LEAP/ChainEdit明确区分：若显式生成并训练了B的监督内容，属于主动传播/额外训练，不再是“B未直接训练”的非局部参数迁移。

目标生成式学习规则：为什么学目标比只调 Loss 更灵活？

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
论文机制（按原文解释）Target Generation

研究问题：如何把一条可学习的更新规则，表示为目标生成器而不是一段优化器代码？

机制主张：固定训练算子的形式，让元网络决定当前策略和未预定义语义的预测应该靠近什么目标。

关键公式与含义

元网络接收已完成的轨迹m_η(τ[t:t+n]) = (π̂_t, ŷ_t, ẑ_t)

逐项解释：τ 包含 Agent 当前/EMA 预测、行动、奖励与终止信息；目标在收集经验后产生。

边界：这是结构性简写，论文元网络还包括用于跨动作与跨时间聚合的架构。

LaTeX 源码（用于论文与笔记引用）
m_\eta(\tau_{t:t+n})=(\hat\pi_t,\hat y_t,\hat z_t)
Agent 内层目标损失L(θ;η)=E[D_KL(sg(π̂)||πθ)+D_KL(sg(ŷ)||yθ)+D_KL(sg(ẑ)||zθ)+L_aux]

逐项解释：用 stop-gradient（sg）强调执行该内层更新时把元网络输出视为固定目标；q/p 仍使用预定义辅助目标。

边界：sg 为教学注记，不是逐字逐符复刻 Nature 的记号；对元参数 η 的外层求导仍要保留目标生成的依赖。

LaTeX 源码（用于论文与笔记引用）
\mathcal L(\theta;\eta)=\mathbb E[D_{\rm KL}(\operatorname{sg}(\hat\pi)\|\pi_\theta)+D_{\rm KL}(\operatorname{sg}(\hat y)\|y_\theta)+D_{\rm KL}(\operatorname{sg}(\hat z)\|z_\theta)+\mathcal L_{\rm aux}]
分类策略的 logit 梯度∂D_KL(π̂||πθ)/∂logit_i = πθ(i) − π̂(i)

逐项解释：策略概率 [0.6,0.4]、目标 [0.2,0.8] 时，梯度 [0.4,−0.4]，下降后增加第二动作的相对概率。

边界：条件是将 π̂ 当作与当前 logit 独立的固定目标；不等于元网络只能输出这两个动作。

LaTeX 源码（用于论文与笔记引用）
\frac{\partial D_{\rm KL}(\hat\pi\|\pi_\theta)}{\partial\ell_i}=\pi_\theta(i)-\hat\pi(i)

推导顺序 / 机制解释

  1. 识别哪些量已固定：给定输入轨迹 τ 和当前 η，生成 π̂、ŷ、ẑ；Agent 仍有 πθ/qθ/pθ/yθ/zθ 五类输出。
  2. 分离目标语义：q 的价值预测与 p 的下一策略辅助目标是人工预定义；y(s)、z(s,a) 的语义不预先写死。
  3. 内层梯度真正作用哪里：先固定目标，再用 KL 对当前 Agent 输出求梯度。由此仍可以复用可靠的优化器、正则和数值稳定处理。
  4. 元网络间接控制更新：改变 η 会改变目标，进而改变 Agent 的未来参数与回报；这种对未来表现的依赖由双层元优化学习。

不可越界解释

半梯度与可表达性：为什么不只搜索一个普通标量 Loss？

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
教学推导（非原文原式）Semi-gradient

研究问题：直接拟合一个可微标量损失，是否足以表示所有常见 RL 更新？

机制主张：目标固定后求梯度可以形成非保守更新向量场；这类半梯度规则未必是某个普通光滑标量势函数的完整梯度。

关键公式与含义

TD / Q-learning 半梯度δ_t = r_t + γ max_a Qθ(s[t+1],a) − Qθ(s[t],a[t]); Δθ = α δ_t ∇θ Qθ(s[t],a[t])

逐项解释：实际更新对当前 Q 求梯度，把 bootstrap target 当作常量；target 里虽含当前/EMA 模型预测，却不反传其目标端梯度。

边界：动作价值估计及行为/目标网络的选择依具体算法而异，这里是教学形式。

LaTeX 源码（用于论文与笔记引用）
\delta_t=r_t+\gamma\max_a Q_\theta(s_{t+1},a)-Q_\theta(s_t,a_t),\quad\Delta\theta=\alpha\,\delta_t\nabla_\theta Q_\theta(s_t,a_t)
一个不能来自普通光滑势函数的更新向量场g(θ1,θ2)=(θ2−θ1, 0); ∂g1/∂θ2=1 ≠ 0=∂g2/∂θ1

逐项解释：若存在光滑标量 F 使 g=−∇F，且定义域单连通，则必要的交叉偏导对称性被违反。

边界：这是为读者构造的数学反例，不是 Nature 的实验公式或作者给出的例子。

LaTeX 源码（用于论文与笔记引用）
g(\theta_1,\theta_2)=(\theta_2-\theta_1,0),\quad\frac{\partial g_1}{\partial\theta_2}=1\ne 0=\frac{\partial g_2}{\partial\theta_1}
但可由停止目标梯度的代理损失实现L_sur=½(θ1−sg(θ2))² ⇒ −∇θ L_sur=(θ2−θ1,0)

逐项解释：梯度符号上的 ~ 表示含 stop-gradient 的程序式导数，不把 θ2 当作可追踪目标参数。

边界：不能夸大为“任何标量程序都表示不了”；自定义梯度、stop-gradient 与目标生成同样可以让标量代理损失实现半梯度。

LaTeX 源码（用于论文与笔记引用）
\mathcal L_{\rm sur}=\frac12(\theta_1-\operatorname{sg}(\theta_2))^2\ \Longrightarrow\ -\widetilde\nabla_\theta\mathcal L_{\rm sur}=(\theta_2-\theta_1,0)

推导顺序 / 机制解释

  1. 先写想要的更新：取两个参数 θ1、θ2；希望 θ1 追随 θ2，但 θ2 不变。对应向量场 g=(θ2−θ1,0)。
  2. 检查梯度场必要条件：如果 g 是单个光滑标量势函数的负梯度，混合二阶偏导须对称；这里 1 与 0 不相等。
  3. 引入停止梯度目标：设训练目标为 sg(θ2)，对 ½(θ1−sg(θ2))² 执行程序式梯度下降，就得到该更新向量场。
  4. 回到 DiscoRL 的搜索空间：元网络生成要靠近的 π̂、ŷ、ẑ；内层可把这些目标视为固定，表示更丰富的学习更新关系。

双层元梯度：未来回报怎样穿过多次 Agent 更新返回元网络？

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
教学推导（非原文原式）Meta-gradient

研究问题：一个更新目标是否好，怎样由“按它训练后的 Agent 回报”来反传判断？

机制主张：外层不是最小化当前样本 Loss，而是通过 Agent 的参数更新链路，优化未来实际回报。

关键公式与含义

内层 SGD 版本θ[k+1] = θ[k] − α ∇θ L_k(θ[k];η)

逐项解释：此式是为展示链式依赖而写的 SGD 简化，原方法实际使用 Adam 等优化状态。

边界：不应把它当作 Nature 中实现的完整优化器。

LaTeX 源码（用于论文与笔记引用）
\theta_{k+1}=\theta_k-\alpha\nabla_\theta \mathcal L_k(\theta_k;\eta)
定义元敏感度S_k = ∂θ[k]/∂η; S[k+1]=(I−α Hθθ[k])S_k−α Hθη[k]

逐项解释：Hθθ 是当前内层 Hessian，Hθη 是 θ 对 η 的混合二阶导；若 θ0 不依赖 η，则 S0=0。

边界：递推是教学推导，假定数据采样路径固定且目标足够光滑；随机体验依赖还需要策略梯度处理。

LaTeX 源码（用于论文与笔记引用）
S_k=\frac{\partial\theta_k}{\partial\eta},\quad S_{k+1}=(I-\alpha H_{\theta\theta}^{(k)})S_k-\alpha H_{\theta\eta}^{(k)}
外层回报梯度∇η J(θK(η)) ≈ S_Kᵀ ∇θ J(θK)

逐项解释：元梯度由“学习规则对最终参数的影响”乘以“参数对实际回报的影响”组成。

边界：完整元 RL 使用 Actor–Critic 估计回报梯度，包含环境采样噪声；不能只按监督学习式链式法则忽略策略采样依赖。

LaTeX 源码（用于论文与笔记引用）
\nabla_\eta J(\theta_K(\eta))\approx S_K^\top\nabla_\theta J(\theta_K)

推导顺序 / 机制解释

  1. 一步更新的一阶依赖：θ[k+1] 对 η 的影响同时经过 θ[k] 的历史路径与当前 L_k 对 η 的直接依赖。
  2. 对 SGD 公式求导：dθ[k+1]/dη = dθ[k]/dη − α(∂²L/∂θ² · dθ[k]/dη + ∂²L/∂θ∂η)。
  3. 从末端回报反传：外层只关心 Agent 按该规则更新以后能取得的回报 J；据此计算 ∂J/∂η。
  4. 截断长学习生涯：DiscoRL 对最近 20 次 Agent 更新进行滑动窗口截断反传；近似降低内存和二阶计算，但带来长时信用分配偏差。

研究“真正改变训练规则，是否提升未来独立学习收益”以及是否值得计算昂贵 Meta-gradient 时引用。

两个时间尺度：轨迹内的未来信用与跨更新的学习历史

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
论文机制（按原文解释）Two Time Scales

研究问题：一条学习规则既要理解本次轨迹的未来结果，也要理解当前 Agent 已经训练到什么阶段，怎样表示？

机制主张：反向轨迹 LSTM 管一次经验如何反向归因；前向 meta-RNN 管跨若干更新的学习状态。

关键公式与含义

轨迹级目标（快时间尺度）(π̂_t, ŷ_t, ẑ_t)=mη(fθ(s[t:t+n]),r[t:t+n],a[t:t+n],b[t:t+n])

逐项解释：一段已经发生的轨迹沿时间倒序处理，得出当前状态/动作应学的目标。

边界：实际实现还包含 EMA 目标网络输出和按动作共享的处理结构。

LaTeX 源码（用于论文与笔记引用）
(\hat\pi_t,\hat y_t,\hat z_t)=m_\eta(f_\theta(s_{t:t+n}),r_{t:t+n},a_{t:t+n},b_{t:t+n})
跨更新状态（慢时间尺度）h[k+1] = MetaRNNη(h[k], summary(batch[k], θ[k]))

逐项解释：meta-RNN 消化更新历史统计，调整目标生成网络对学习阶段的判断。

边界：这是结构性教学形式；原文的额外 meta-RNN 只带来较小总体增益，不等同于长时知识储存。

LaTeX 源码（用于论文与笔记引用）
h_{k+1}=\operatorname{MetaRNN}_\eta(h_k,\operatorname{summary}(\text{batch}_k,\theta_k))

推导顺序 / 机制解释

  1. 不要混淆 t 与 k：t 索引游戏轨迹时间，k 索引参数更新次数；两者尺度、依赖与可测信号均不同。
  2. 快尺度回答的问题：沿轨迹回看，哪个早期预测或行动应对后来的成功/失败负责？
  3. 慢尺度回答的问题：已经更新了很多次后，当前 Agent 是否需要和早期不同的学习规则？
  4. 验证第二个时间轴的必要性：必须与相同容量的无历史网络、窗口汇总统计、仅当前状态网络比较；原论文 meta-RNN 提升不大。

开放语义预测与 Bootstrap：怎样检验新中间变量真的有用？

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
论文机制（按原文解释）Auxiliary Predictions

研究问题：给 Agent 新增 y/z 预测头后，怎样知道它们不是无用的辅助参数？

机制主张：先检验是否含未来相关信息，再切断未来预测进入当前目标的路径，最后切断它们进入策略目标的路径。

关键公式与含义

新预测没有预定标签yθ(s), zθ(s,a); (ŷ_t,ẑ_t)=mη(τ[t:t+n])

逐项解释：学习系统通过元优化发现值得预测的对象，而不是先给 y/z 人工定义未来奖励标签。

边界：有用信息由后续探针与消融发现，不是实验前就宣称 y/z 一定预测未来策略熵。

LaTeX 源码（用于论文与笔记引用）
y_\theta(s),z_\theta(s,a),\qquad(\hat y_t,\hat z_t)=m_\eta(\tau_{t:t+n})
Bootstrapping 依赖的可检验形式∂ẑ_t / ∂z[t+k] ≠ 0 （有用的轨迹/状态范围内）

逐项解释：作者扰动未来 z 输入，当前 ẑ 目标明显变化，说明未来预测参与当前目标构造。

边界：该式是对作者敏感性实验的概括，并非声称所有状态的导数处处非零。

LaTeX 源码（用于论文与笔记引用）
\frac{\partial\hat z_t}{\partial z_{t+k}}\ne0\quad\text{(observed dependency)}

推导顺序 / 机制解释

  1. 探针：这两个变量编码了什么：在 10 个 Atari 上用 y/z 等预测未来高奖励事件和策略熵，与 π/q 表示对照。
  2. 机制：未来信息有没有进入目标：扰动未来 z[t+k]，观察当前 ẑ_t 是否改变（Fig. 4d）。
  3. 消融一：关闭新预测自举：计算 ŷ/ẑ 时将相关 y/z 输入置零，破坏未来预测贡献，观察性能下降。
  4. 消融二：再切断对策略目标的作用：计算所有目标（包括 π̂）时将 y/z 输入置零，性能进一步下降，支持它们确实用于改善策略。

探针相关不意味着变量具有唯一语义；性能消融支持在给定系统中的因果贡献，但不保证任何新辅助头都能带来提升。

跨环境元优化的稳定性：优势归一化、分 Agent Adam、KL 与熵

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
论文机制（按原文解释）Meta-optimization Stability

研究问题：数百个 Agent 的奖励尺度、学习阶段不同，怎样防止元梯度被某个环境支配并让目标突然坍塌？

机制主张：先将不同 Agent 的优势与元梯度尺度归一，再限制目标策略偏移并鼓励未定义预测保持一定信息熵。

关键公式与含义

优势标准化Ā=(A−μ)/σ

逐项解释：μ 和 σ 是 Agent 生涯内优势的 EMA 均值与标准差，平衡跨环境回报尺度。

边界：实践计算需要对 σ 太小的情况做数值保护；本文表示原始简化公式。

LaTeX 源码（用于论文与笔记引用）
\bar A=\frac{A-\mu}{\sigma}
每个 Agent 先经 Adam 再聚合η ← η + (1/N) Σ_i Adam_i(g_i)

逐项解释：与先平均原始梯度再做一个 Adam 不同；减轻少数大尺度任务的支配。

边界：符号 Adam_i(g_i) 表示每个 Agent 自己的优化器状态转换，不是一次普通标量乘法。

LaTeX 源码（用于论文与笔记引用）
\eta\leftarrow\eta+\frac1N\sum_{i=1}^N\operatorname{Adam}_i(g_i)
熵 / 策略目标偏移正则L_ent=−E[H(yθ)+H(zθ)]; L_KL = D_KL(π_{θ−} || π̂)

逐项解释：最大化 J−L_ent−L_KL 相当于奖励预测熵并惩罚过激的新目标策略。

边界：两项用于元优化稳定，不是应用于每一步 Agent 的固定人工策略更新目标。

LaTeX 源码（用于论文与笔记引用）
\mathcal L_{\rm ent}=-\mathbb E[H(y_\theta)+H(z_\theta)],\quad\mathcal L_{\rm KL}=D_{\rm KL}(\pi_{\theta^-}\|\hat\pi)

推导顺序 / 机制解释

  1. 跨环境尺度不一致：环境 A 的 Advantage 可能远大于 B，即使 B 的规则同样有价值，原始梯度合并也易被 A 主导。
  2. 两层归一：对优势做 EMA 归一，并在汇总之前独立 Adam 处理每个 Agent 的元梯度。
  3. 防止预测退化：−H 作为要减掉的元正则，使高熵受到鼓励，降低 y/z 过早收敛到常量类别的风险。
  4. 防止元规则过于激进：控制 π̂ 与 EMA 策略的 KL，防止目标突然跳到远离当前策略的分布。

不可越界解释

数值稳定化不等于安全性、可信性或反奖励投机；不能把它当作完整的自改进治理方案。

RSI 扩展：从当前回报转向未来可学习性（尚待验证）

主归属 · 学习调控关联 · 学习信号关联 · 能力形成
RSI 研究假设（待验证）RSI Research Hypothesis

研究问题：当两套更新规则让 Agent 当前 A/B 能力一样时，未来学习陌生任务 C 的速度是否仍不同？

机制主张：元规则的好坏不能只看当前奖励，还应在匹配当前能力与资源后评估未来新能力净增长及旧能力损失。

关键公式与含义

未来新任务的真实学习增益Δ_C(η)=A_C(θ_after(η))−A_C(θ_before(η))

逐项解释：C 是外层学习规则发现期间留出的任务家族；对 C 需要执行等预算的实际参数更新。

边界：这个指标是我们提出的科研目标，DiscoRL没有测 LLM 的下一轮任务 C 可学习性。

LaTeX 源码（用于论文与笔记引用）
\Delta_C(\eta)=A_C(\theta_{\rm after}(\eta))-A_C(\theta_{\rm before}(\eta))
候选净收益目标G_future(η)=Δ_C(η)−λF_old(η)−βC_total(η)

逐项解释：F_old 是旧 A/B 能力损失，C_total 应计入元发现与未来更新成本；λ/β 在实验前锁定。

边界：没有现成最优权重；在不同 λ/β 下应呈现 Pareto 敏感性，而非只挑最好看的组合。

LaTeX 源码（用于论文与笔记引用）
G_{\rm future}(\eta)=\Delta_C(\eta)-\lambda F_{\rm old}(\eta)-\beta C_{\rm total}(\eta)

推导顺序 / 机制解释

  1. 先匹配初始条件：同底座、同 A/B 数据、同优化预算；比较固定更新规则与条件化目标生成器，确认 A/B 当前后测处于可比范围。
  2. 只改变规则而非课程：样本、目标任务、评估器、训练 token 相同；改变的必须是训练目标或参数更新机制，而非仅换示范顺序。
  3. 对新 C 独立更新：从各分支检查点出发提供同一 C 训练材料，用同样步骤继续真实学习，并测未见 C 的学习曲线与 A/B 保留。
  4. 判断是否值得做 Meta-Updater：若只有当下性能提升或算力节省、却没有未来独立净收益，不能声称发现了持续 RSI 学习规则。
