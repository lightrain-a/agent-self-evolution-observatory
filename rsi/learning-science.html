教育学与学习科学：如何转成机器机制

教育学提供提出假设的依据，不是 LLM 上已成立的结论。区分学习过程、即时表现、保持与迁移，再设计模型能够实际经历的干预。

八类来源的可操作映射

来源可借鉴机制机器实验变量不能照搬
自我调节学习 [E01]目标、监控、策略调整的反馈。依据可执行证据改变学习动作。三个 Agent 对应三个教学阶段就是创新。
近端可学区域 [E02]不会但可能取得进展，不是盲目追难题。同难度题在不同支持下的学习收益。模型自报“不懂”是可信能力标签。
练习性检索 [E03]主动恢复知识，而非只重读。不看答案生成、验证、持久写回。冻结模型输出一次就改变了权重。
间隔学习 [E04]练习组织与后测时距影响保持。隔若干其他能力更新后重练。静止参数随日历时间自然遗忘。
例题渐隐 / 自我解释 [E05]完整例题到自行补步骤。帮助强度、撤除时机、可验证解释。解释越长理解越深。
生产性失败 [E06]尝试生成后对照与整合知识。先尝试后讲解 vs 先讲解后尝试。所有错误都有学习价值。
帮助困境 [E07]帮助过少与过多都可能不利。提示、示范和独立练习的选择。帮助越少越高级，强教师必然更差。
表现与学习不一致 [E08]当前顺利未必长期学得最好。即时完成与延迟新任务分开。暂时低分就是“更深学习”。

新增机制来源：让教师观察学生独立行动

2013 年 Okita 与 Schwartz 的原始实验将 Recursive Feedback（RF） 与直接反馈区分：学生必须在新情境独立行动，教师再将学生的行为映射回自己曾教过的知识。这给 I5 教学反馈自进化提供了明确的机器实验条件；但 RF 是教育学概念，不等于 RSI。[E09]

2026 年 Behaviormetrika 研究进一步发现，在它的人类教育实验中，教师回答可教代理追问时，知识建构型回应与概念/程序能力后测呈正向关系；它提示可设计追问与对照解释，而不能证明 LLM 的参数或技能会因解释而更新。[E10]

相邻 AI 工作已覆盖学生反馈微调教师（NeurIPS 2024 LbT）、学生主动追问（arXiv 25.12）和 Teacher–Student 提示优化（AAAI 2026 MARS），因此仅以费曼学习法命名模型没有创新性。[S20][S24][S21]

Hypercorrection：最自信的错误为什么反而可能更容易纠正？

Butterfield 与 Metcalfe（2001）发现 Hypercorrection Effect；Carpenter 等（2018）在真实大学课堂观察到高置信度错误在得到正确反馈后有时更容易被纠正。[E12][E13]

这不等于“自信错误必然值得训练”。Sitzman 等（2014）发现，学习者已有的领域知识与纠错表现密切相关；Foster 等（2022）观察了数学在线诊断题中的置信度与后续相似题表现。[E14][E15]

神经机制的补充：Pine 等（Nature Communications，2018）发现，来自事实反馈的语义预测误差与一周后的记忆更新有关，腹侧纹状体等脑区对该信号敏感。但原研究还展示了错误反馈也可能形成错误记忆，提醒 RSI 必须验证反馈来源，不是冲突越大就越应该直接写入。[E18]

对 LLM，应区分正确反馈后的原题修复、参数的真实持久更新以及未见题的规则级迁移。详细机制与受控实验在 I8：错误可学习性与跨题迁移。

这些思想已经部分进入 AI

课程、知识追踪和学习型教学早已转化部分教育学问题；SOAR、ActiveSaddler、EduardoRL 又进入 LLM 与 Agent 场景。贡献须是新增机制或适用条件，而不是首次使用“自学、老师、考试”。[M03][M05][M06][S16][S17][S19]

EduardoRL 已遮蔽教师话语。我们的候选不是重做这一后测，而是问：后续不同能力学习带来干扰时，怎样组织帮助—独立练习—巩固的完整序列？须与短程目标、固定渐隐及普通重放直接比较。

贯穿例子：分页工具调用

失败现象

Agent 处理第一页却漏后续页。完整调用示范使当前任务成功，但换数据和 API 名称又失败。

四种学习动作

A：给完整示范；B：仅提示检查 continuation token；C：先要求提出终止条件再给反例；D：无提示独立尝试。随后使用同一个固定更新器。

三个层次

原任务完成率；不同名称、页数的新任务独立成功率；学习另一种分页 / 重试机制后，原能力是否保留。近迁移不能仅替换答案数字；远迁移需改变工具组合、依赖或恢复条件。

防止偷换概念

保留技能文件时报告系统层面学习。只保留 LoRA 且清空会话与技能时，才评价参数学习。分栏报告，不相加为同一能力分。

必须允许的相反结果

强示范最好：强教师示范加固定蒸馏可能在所有保持测试上占优。接受结果，不强行宣称“适度困难”有效。

延迟只是更多训练：控制曝光、梯度步数和更新顺序后差异若消失，不能归因于间隔机制。

只有上下文记住了：清空会话后增益消失，就属于上下文适应，不能改写为持久自进化。

人类学习效应有任务、先备知识和教学设计条件。机器研究也要找适用边界，而不是只挑支持类比的例子。
