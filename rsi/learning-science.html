新增机制来源：让教师观察学生独立行动

2013 年 Okita 与 Schwartz 的原始实验将 Recursive Feedback（RF） 与直接反馈区分：学生必须在新情境独立行动，教师再将学生的行为映射回自己曾教过的知识。这给 I5 教学反馈自进化提供了明确的机器实验条件；但 RF 是教育学概念，不等于 RSI。[E09]

2026 年 Behaviormetrika 研究进一步发现，在它的人类教育实验中，教师回答可教代理追问时，知识建构型回应与概念/程序能力后测呈正向关系；它提示可设计追问与对照解释，而不能证明 LLM 的参数或技能会因解释而更新。[E10]

相邻 AI 工作已覆盖学生反馈微调教师（NeurIPS 2024 LbT）、学生主动追问（arXiv 25.12）和 Teacher–Student 提示优化（AAAI 2026 MARS），因此仅以费曼学习法命名模型没有创新性。[S20][S24][S21]

npj 2025｜双向反馈改变了什么：忽略、复制还是应用？

实验到底做了什么？Yin 等（npj Science of Learning，2025）分析 100 对参与者的创造力用途测试：先独立想“鞋子还能做什么”，随机分配面对面双向反馈（IF）、单向听反馈（OF）、无关交流（IC）、无反馈（NF），再测鞋子及雨伞、书籍两个新物品。在此实验设置下，IF 在原题创造力习得和部分新物品迁移指标上表现较好。研究同时使用 fNIRS 测量脑间同步（INS），它是相关信号，不能推断同步导致学习。[E27]

反馈吸收方式判定依据对模型学习的启发
Ignore · 忽略后测没有使用对方提出的内容反馈抵达上下文，未必改变行为
Copy · 复制重复或照搬了反馈里的具体用途原题会复述，不等于形成可复用规则
Apply · 应用在原题上将反馈发展为新的用途需要继续验证是否能迁移到未见结构以及后续更新后是否保持

容易漏掉的两项结果：IF / OF 中 Ignore 比例约 46.26% / 47.32%，Copy 约 32.84% / 41.07%，Apply 约 20.90% / 11.61%。研究发现 IF 的 Apply 数量和反馈总量较高，但不能直接把百分比差异或脑同步视为“互动必然让学生理解”的因果证明。Apply 与原题习得指标呈显著正相关，研究没有观察到 Apply 与迁移成绩的显著直接相关。[E27]

关键测量限制：Ignore / Copy / Apply 是评分者结合对话和鞋子后测回答才标出来的。因而它是反馈使用方式的事后编码，不是教师在教学进行中可直接使用的、与后测独立的“学生已掌握”预测信号。真正要研究双向交流的额外信息价值，必须让教学器只读更新前的学生实际回应或独立诊断题，不能在试教期间看最终测试。[E27]

对 RSI 的正交落点：I2 固定教学伙伴，检验真实学生回应对下一轮教学是否有独立帮助，并训练教师持久更新；I8 固定纠错方式，测接受反馈和跨题净迁移之间的差别；I5 继续研究十个模型的动态换伴，不因这项人类研究改变主线。双向互动、错误解释和学生知识诊断在现有 LLM 文献中均有直接近邻。[S105][S106][S103]

Nature 2025｜Centaur：会预测下一步，不等于知道学生真的学进了什么

Observable Phenomenon：Binz 等（Nature 2025）将 160 种心理学实验统一为 Psych-101 语言轨迹，涉及 60,092 人、10,681,650 次选择。在 Llama 3.1 70B 进行 rank=8 的 QLoRA 微调后，留出被试上的平均 NLL 为 0.44，优于原始 Llama 的 0.58 和已实现的领域模型 0.56。NLL 是对真实选择的预测概率，不是做题正确率。[E701]

Related Work：Binz 与 Schulz 的 ICLR 2024 Turning large language models into cognitive models 已研究行为微调与有限跨实验泛化，Centaur 的推进在于 160 实验和系统 OOD/开放环证据。[E703] 2026 年学生模拟有效性研究还提出 competence paradox：强基础 LLM 扮演弱学生时可能不真实地“懂得太多”，因此不能只看语言角色扮演的流畅程度。[E704]

Nature 2023｜MLC：如何通过组合任务元学习规则？

原文：Lake 与 Baroni 的 Nature 2023 MLC 用 100,000 个随机解释语法 Episodes 训练小型 Transformer，通过少量 Study 示例预测当前语法下未见的 Query。元测试权重冻结，依赖上下文学习新组合，不等于持续 LoRA 内化。[E350]

Nature Human Behaviour 2025｜从动作纠错，到学习依赖哪种决策策略

Challenge：一次好结果究竟强化了“这个动作”，还是强化了产生动作的整个决策方法？Maier、Cheung 与 Lieder 将二者拆开：13 次道德两难题中，遵循规则（Rule）和成本—收益推理（CBR）有时对应行动、有时对应不行动，反馈条件则随机控制哪种策略持续得到好结果。四项预注册实验共 2,328 人。[E311]

Insight & Design：结果可以更新具体动作的价值，也可能更新上层“下一题依赖 Rule 还是 CBR”的信任。作者比较 model-free / model-based / 无学习 × 行动层 / 策略层的六种计算模型；并用新道德问题、态度量表、真实经济激励捐赠和看似独立的后续实验判断转移。CBR 是被选的策略，不等于元控制器的 model-based 学习。[E311]

实验必须记住的结果证据边界
Exp 1 · N=387CBR Success 的 CBR 选择 51.8%→68.2%；Rule Success 的 CBR 选择 55.7%→44.3%行为变化本身还不能证明更新的是哪一层
Exp 2 · N=380CBR Success 策略层拟合占 89.4%；Rule Success 只有 27.9%，行动层则占 67.3%这是模型推断的类别占比，不是直接读出人脑内部机制
Exp 3 · N=834对新道德情境的策略结果预测和态度量表有转移；全样本捐赠差异单侧 p=0.061全样本捐赠差异未达显著，不能说人人发生迁移
Exp 4 · N=727跨至另一表面独立的实验，平均间隔 121 分钟；元策略学习相关交互仍显著是约数小时的相关道德情境迁移，不是长期人格或模型能力更新

Related Work 与新意：Rieskamp & Otto（2006）已提出反馈驱动的策略选择学习；Lieder & Griffiths（2017）研究不同启发式的收益与思考成本；Crockett 与 Cushman（2013）讨论道德行动和后果价值的不同机制。本文的推进是在道德领域将策略层与行动层的学习分开测量，并检验它是否迁移，而不是第一次提出元策略学习。[E312][E313][E314][E315]

对 RSI 的边界：I4 可借鉴“失败以后是否要更换决策方式”，I6 可把动作层/策略层反馈归因作为研究变量，但二者的主问题暂不改。此文没有训练 LLM 权重或 Skill；算法可学习的策略信任也不能覆盖真实授权、安全与不可变规则。阅读完整 C-I-D-R 精读、四项实验及 Related Work →

I11｜情绪鼓励对人类学习有用，对 AI 的自我迭代呢？

人类实验的作用范围：Yin 等（npj Science of Learning，2025）比较人类学生接收的元认知、情感与中性 Chatbot 反馈；元认知组新题迁移和敏感度较高，情感组相对中性组在学习后知识保持表现较好。这并不证明 LLM 会像人一样因鼓励学得更好。[E28]

机器研究已经形成不一致但有价值的证据：ICML 2024 EmotionPrompt 发现部分任务受情绪提示影响；2026 TEMPER 发现情绪输入有时会使推理更差；EmotionRL 已基于当前任务自适应选择情绪；HEART 已做验证器驱动的情绪多轮自纠错。情绪是否“帮助学习”不能从单次准确率直接推出。[M28][M29][M30][M31]

效应层次目前有哪类证据RSI 需要另外测什么
情绪影响当前解题EmotionPrompt、TEMPER 的输入敏感性结果同事实且同策略指令，只变语气是否仍有效
情绪影响自评与决策SSRN 同伴鼓励与自评偏差；COLM 2026 序贯决策中的条件性惩罚/探索效应 [M32][M33]错误之后核验、停止、继续和版本接纳的真实决定
情绪影响持久自我迭代目前所列最近邻尚未直接建立完整的多轮 Skill / LoRA 撤辅净收益链匹配反馈、训练及调用预算后，测未来独立任务的净能力曲线

具体 I11 问题：鼓励可能帮助 Agent 继续探索，也可能让它过高估计自己的学习价值；冷静批评可能改善核验，也可能造成低效重复。我们应先判断 Agent 的学习决策有没有变好，再判断真实版本更新后的独立能力是否保留。进入 I11 长期自迭代实验设计 →

“情绪”指反馈文本的表达与语境；模型不必具有主观情绪。Nature 2026 将模型微调成更温暖的回答风格所产生的准确性风险，与输入端给 Agent 鼓励属于不同干预，不可混用结论。[M34]

NC 2025｜反馈全部真实，也能让学习者错误估计自己的整体能力

论文记录：Katyal、Huys、Dolan 与 Fleming（Nature Communications 16:1854，2025）研究两批独立人类样本（探索 N=230、预注册验证 N=278）。难度阶梯将知觉/记忆任务正确率维持在约 71%；每道题后询问 Local Confidence，每个区块后询问 Global SPE（自己觉得这一组答对多少题）。研究者让审查员更频繁地展示真实成功或失败，反馈没有造假，只改变哪些结果出现。[E29]

Figure 3 的核心结果：两个实验都观察到强烈的整体自评偏移（p<0.001，Cohen d≈1.77），但任务准确率没有相应显著变化。局部信心在 Exp1 没有发现显著反馈效应，在 Exp2 出现较小差异；不能将整体自评变化写作真实能力改变。反馈对知觉/记忆任务之间自评偏差的影响有方向与时长边界，不是技能迁移。[E29]

本文真正强调的另一层机制：作者比较 D1（高局部信心未充分整合到整体信心）、D2（对正负外部反馈赋予不同学习权重）和 D3（泛化的消极报告偏差）。与亚临床焦虑—抑郁症状相关的欠自信主要支持 D1，并没有同样明确的外部负反馈学习异常。统计关联和 Beta 模型不能推出某种临床因果机制，更不能赋予 LLM 类似心理症状。[E29]

Hypercorrection：最自信的错误为什么反而可能更容易纠正？

Butterfield 与 Metcalfe（2001）发现 Hypercorrection Effect；Carpenter 等（2018）在真实大学课堂观察到高置信度错误在得到正确反馈后有时更容易被纠正。[E12][E13]

这不等于“自信错误必然值得训练”。Sitzman 等（2014）发现，学习者已有的领域知识与纠错表现密切相关；Foster 等（2022）观察了数学在线诊断题中的置信度与后续相似题表现。[E14][E15]

神经机制的补充：Pine 等（Nature Communications，2018）发现，来自事实反馈的语义预测误差与一周后的记忆更新有关，腹侧纹状体等脑区对该信号敏感。但原研究还展示了错误反馈也可能形成错误记忆，提醒 RSI 必须验证反馈来源，不是冲突越大就越应该直接写入。[E18]

对 LLM，应区分正确反馈后的原题修复、参数的真实持久更新以及未见题的规则级迁移。详细机制与受控实验在 I8：错误可学习性与跨题迁移。

npj 2023｜不同失败解法与后续学习：有启发，但不必多生成

真实观察：Kapur、Saba 与 Roll（npj Science of Learning，2023）研究了 112 名七年级和 105 名八年级学生的两项 Productive Failure 准实验。先由小组尝试陌生数学题，再接受教师统一教学；小组创造的不同数学表示与解法（RSM）数量，比以往数学成绩与个人一周后后测的关联更强。研究没有随机操纵 RSM 数量，也没有测 LLM 或探索成本。[E98]

对 RSI 的取舍：它支持研究“不同失败过程可能提供不同学习信息”，不支持默认让模型在每道题上生成大量不同错误。多轨迹生成、分类和真实更新成本可能很高；能否在常规学习平台期突破当前能力上限仍是猜想。当前建议：Watch／非主线，优先直接纠错或适中难度练习；只有既有失败池已显示互补信息时，才用零新增采样的 P0 检验学习收益与计算成本。完整的 Challenge → Insight → Design → Result、证据表和成本判断见 论文精读笔记；与 I6 失败轨迹学习价值保持关联但不修改其核心方法。

NC 2026｜为什么旧解题结构有时应该保留，有时必须改变？

NC 2021｜人会看学习变化，但变化不一定是净增长

Observable Phenomenon｜为什么不是“挑难题”这么简单？Ten、Kaushik、Oudeyer 与 Gottlieb（Nature Communications，2021）分析 382 人对四种活动的自由选择：前三项可学，第四项反馈随机、不可学习。每人经过熟悉阶段后可自由选学 250 次。明确要求尽可能掌握活动的参与者，反而把 36.92% 的时间投入随机任务；无明确学习目标者为 23.43%。然而明确目标组整体难度加权学习表现较好，不能简单归因于“挑战越多越糟”。[E19]

Why｜研究解释到哪一步？作者用任务近期正确率（PC）与近期表现变化（LP）拟合下一次活动选择；同时包含二者的模型通常比只用其中一项的模型拟合更好。目标指令主要影响对困难任务的偏好，未显著改变 LP 敏感性。该研究展示了行为上的分离，不是随机操纵两套神经学习模块。模型中的 LP 取正确率变化的绝对值，所以能力下降也会被视为变化，便于重新关注可能遗忘的任务。[E19]

论文确实观察到我们容易过度推出什么RSI 应如何检验
困难偏好与近期学习变化都与人类任务选择相关“LP 选任务”是 LLM 新机制先与 TSCL、Graves、SPaCe 等已有学习进度课程方法对照 [M04][M12][S45]
有目标可能增加挑战，也可能增加对随机任务的无效投入给 Agent 强学习目标一定让它陷入难题固定模型与任务池，检验目标压力是否导致同预算下更多无效失败采样
绝对 LP 同时响应上升与下降高 LP 就是新能力增长分开评测近期变化、旧能力恢复、跨轮净保持；见 I3 巩固
当前活动长期缺少 LP 时，参与者较少继续选它当前学不会，就应永久丢弃该任务在不同前置知识条件下制造相同平台期，比较补基础后重访与持续死磕；见 I6 的受控实验

Challenge → Insight → Design：相同的近期正确率与学习变化，不一定对应相同的未来可学习性；一次外部知识更新可能改变学得会的范围。因而 I6 的重访检验必须固定纠错器和预算，随机对照“继续采样失败 / 补充预定义前置知识后重访 / 无关更新后重访”，再用未见题净收益判断，不是把 LP 换个名字做路由。[E19]

证据边界：本文是人类行为与计算模型拟合，原任务的 A4 真正随机不可学习，不能把真实 LLM 暂时低分一概视为不可学习。论文没有检验模型权重更新，也没有证明 Agent 会因为绝对 LP 奖励反复遗忘。以上 RSI 实验属于本站的待验证构想。

npj 2026｜为什么 p≈0.5 仍可能只学到局部技巧？

Observable Phenomenon：Ding 等（npj Science of Learning 2026）把 560 名参与者分为两项 60° 光标旋转实验。训练目标很近时，利用局部技巧可以较快减少错误；目标排列更能排除错误的平移/镜像等假设时，早期训练较慢，却在没有反馈的新目标上更接近真实旋转规则。实验 2 通过八个训练目标把最近训练点至探针的距离统一为 110°，仍出现迁移差异。[E26]

NC 2025｜任务规则相同，为什么交错学习初期反而更慢？

Observable Phenomenon：Menghi 等在 Nature Communications（2025）让两组参与者交错学习概念和空间分类，控制两任务低维决策结构相同（SameSt）或正交（DiffSt）。54 名参与者的训练期平均正确率分别为 60.44% vs 66.61%（p=0.005）。但后期测试组间差异未达显著（p=0.159），新刺激泛化也无显著差异（p=0.709）：这说明早期干扰，不等于长期泛化较差。[E99]

作者操纵的变量观察到什么我们应怎样理解

训练顺序人类两组都交错训练；没有直接比较 Blocked vs Interleaved不能据此宣布“先集中再交错最好”

Related Work：Holton 等（NHB 2025 在线/2026 期刊）的 A→B→A 顺序训练发现相似任务更易迁移、但也更易遗忘先前 A；Menghi 研究的是 A/B 共同形成表示时的短期干扰，两种实验时序不同。[E100]

I9｜集中练习与交错练习：什么时候该换方法？

Observable Phenomenon：Samani 与 Pan（npj Science of Learning，2021）在350名大学生、8周物理作业安排中发现，集中练习的作业成绩更高，交错练习却提高了意外延迟测试中的新题表现。学生觉得交错更难，也更容易误以为自己学得差。正式期中考试差异未达显著，论文没有单独隔离复习间隔等所有机制。[E20]

NC 2026｜马赛克式记忆：不同文本可能重复强化同一原文

Observable Phenomenon：Shilov、Meeus 与 de Montjoye（Nature Communications，2026）发现，训练文本即使替换部分 Token、加入噪声或打乱短语顺序，仍可能加强模型对已出现原文的记忆。四个主要模型在替换10% Token时的精确重复等效系数ρ约为0.60–0.65；替换50%仍约为0.13–0.19。作者用成员推断AUC校准这个相对贡献，不是测量新增规则。[M17]

重要机制边界：该研究中原文与九个模糊副本一起参与Member组训练；从三类语义改写的对照来看，局部Token/n-gram重叠比“意思一样”更能解释当前设置下的原文记忆。论文没有证明所有语义记忆都不存在，也没有测试模型是否在新题上形成了独立新能力。

区分什么为什么重要怎样在 RSI 中验证
文本新颖换词、换变量、乱序仍可能是旧内容的重复保留 Token/n-gram 相似度与模糊重复审计
规则新颖外观变化不一定引入新的适用条件；相近措辞也可能包含关键反例固定原题数量，按规则族与反例条件分组
能力新增记住文本与能在新题中独立应用，是两种不同结果真实更新并撤辅后，分别测同规则与跨规则新题净增益

与当前 Idea 的关系：I5 互教不能把不同题面当新增知识；I6 不宜把不同失败轨迹直接当不同规则；I8 应排除原题/近改写题记忆；I9 应验证交错主题确实不同规则。进入10节完整精读与受控实验 →；阅读C-I-D-R速览卡片。

证据边界：原论文的目标是文本记忆、隐私风险、去重与基准去污染；“模糊重复不是新知识”是对RSI的待验证推断，不能直接代替新规则后测。

ACL 2026｜为什么训练题给了正确答案，模型仍可能学不会？

Observable Phenomenon：Xue 等（ACL 2026）在 SFT 收敛后，将原监督样本转换成四选一，重复测试，平均 15.3%±2.1% 的样本未被稳定恢复。原文区分基础知识不足、预训练旧信念冲突、SFT 数据内部矛盾、顺序训练造成的前期遗忘，以及稀有模式训练不充分；五种模式的 Table 10 占比合计只有 78%，不能把这些诊断当作互斥根因真值。[M27]

论文证据作者结果对应我们的问题
缺基础知识 · Table 4MedQA Learn Rate：2轮SFT 65.3%，10轮 66.8%，CPT+SFT 82.1%I8：前置知识与目标规则迁移的交互是否真实存在？
Left-side forgetting · Table 11前10% ROUGE-L：0.41→0.53；末尾0.61→0.60I3：普通 replay 恢复旧题，与条件冲突巩固有何区别？
同样失败、可能不同原因五种潜在原因需由原模型状态、标签审计和训练顺序分别检查I6：先匹配这些状态，才能隔离“失败轨迹过程本身”的价值

最重要的边界：训练后在选择题上重新做对、自由文本恢复和未见同规则题真正掌握，不是同一个结果。补知识还增加了语料及训练计算，不能直接宣称“相关前置知识”是唯一原因。完整证据与原表见 五种 ILP 原因精读，速览卡片。

ICLR 2026｜先记忆再泛化：能调用旧事实，不等于会做两跳推理

Challenge：Wu 等的 Rote Learning Considered Useful（ICLR 2026）研究先用无语义 token [X] 记住一批实体关联，再以少量自然语言示范学会关系含义。关键区别是：Phase 2 的“未见事实”早在 Phase 1 已被模型记忆过，因此不是学会全训练未出现的新事实。[M24]

Insight / Design：同类事实共享 [X]，少量语义训练可能一次性让许多已记忆事实可通过不同问法取回。作者在8个LLM的合成事实设置中测试 Phase 1 参数记忆、Phase 2 语义映射和后续语义调用；这和 Agent 把轨迹放进外部 Memory 的做法不是一回事。

任务 / 条件论文结果应怎样理解
简单语义访问：Phase 2 50条事实、1种语义提示76% 生成准确率第一阶段已记忆、第二阶段留出的事实可以被重新调用
两跳：不做 Phase 1 记忆 → 记忆20 epochs生成 14% → 36%；多选 8% → 16%记忆加深能帮助一点组合推理，但成功率仍很低
ICL：两条原始事实直接出现在上下文两跳约 95%说明任务在事实直接可见时容易得多；但ICL的信息访问方式与参数内取回不同，不能当作严格同条件优劣排序

我们对论文的判断：“先记忆再少量语义解释”的可控现象成立，但不能据此声称学到了可靠复杂推理能力。2026年 EMNLP Findings 专门研究原子事实都知道却不能两跳组合的机制；2025年 EMNLP 的 Reason to Rote 也研究记忆与推理的关系，但与本篇的两阶段语义映射问题不同。[M25][M26]

对 RSI 的启发：模型记下失败轨迹，不代表它之后能够组合旧经验解决新任务。需要把事实记忆、语义访问、独立两跳与旧能力保持分开评估，尤其区分参数内化与外置检索；这与 I7 学习顺序和 I8 规则迁移有关，但不急于新立方向。进入完整精读：结果、边界与3项决定性实验；查看C-I-D-R卡片。

实验状态：这里复述的是作者报告的数据，未进行独立复现；ICLR论文里 Section 6.2 已把复杂推理拓展称为初步证据，不能把两跳36%写成强推理结果。

Nature Communications 2026｜学习网络骨架，是否意味着先修知识真的被补好了？

原文发现：Ren 等（Nature Communications 2026）让人类学习具有 16 个节点的图片转换网络；实验二同频率改顺序，先出现高连接枢纽的 HubToLeaf 预学习在后续共同的随机游走学习中取得更好表现。实验三的 MEG 与两阶段模型提供更高阶网络结构表征的补充证据。作者没有在 LLM 上证明规则前置关系。[E401]

可借鉴不能推出I12 应该怎样验证
早期认识全局的高阶结构可能帮助整合后续经验“度数最高的数学规则”就是所有目标题的必要前提对真实依赖 P 与同频率的非前置 H 分别进行真实参数更新，并统一后续学习 T
相同输入频率、不同学习路径影响后续学习人类路径实验已证明 LLM 的课程顺序或 Skill 更新有效由独立诊断发现先修 P，再看学完 P 后 T 的第二阶段收益；排序效应交给 I9
高阶网络结构比只记一步转移更有解释力“外部技能图能查询”就等于知识内化与 SkillGraph / SkillDAG / SE-GoS 等检索方案做同预算对照，撤除图谱后独立测试。[S401][S402][S403]

研究定位：I12 · 共同前置知识瓶颈 寻找多题共享的状态依赖因果先修并检验未来学习机会是否扩大；I8 研究某个错误的纠正是否迁移；I9 固定材料只改课程编排。高频节点、先修关系、补先修后的可学习性是三件不同的事。

这些思想已经部分进入 AI

课程、知识追踪和学习型教学早已转化部分教育学问题；SOAR、ActiveSaddler、EduardoRL 又进入 LLM 与 Agent 场景。贡献须是新增机制或适用条件，而不是首次使用“自学、老师、考试”。[M03][M05][M06][S16][S17][S19]

EduardoRL 已遮蔽教师话语。我们的候选不是重做这一后测，而是问：后续不同能力学习带来干扰时，怎样组织帮助—独立练习—巩固的完整序列？须与短程目标、固定渐隐及普通重放直接比较。

贯穿例子：分页工具调用

失败现象

Agent 处理第一页却漏后续页。完整调用示范使当前任务成功，但换数据和 API 名称又失败。

四种学习动作

A：给完整示范；B：仅提示检查 continuation token；C：先要求提出终止条件再给反例；D：无提示独立尝试。随后使用同一个固定更新器。

三个层次

原任务完成率；不同名称、页数的新任务独立成功率；学习另一种分页 / 重试机制后，原能力是否保留。近迁移不能仅替换答案数字；远迁移需改变工具组合、依赖或恢复条件。

防止偷换概念

保留技能文件时报告系统层面学习。只保留 LoRA 且清空会话与技能时，才评价参数学习。分栏报告，不相加为同一能力分。

必须允许的相反结果

强示范最好：强教师示范加固定蒸馏可能在所有保持测试上占优。接受结果，不强行宣称“适度困难”有效。

延迟只是更多训练：控制曝光、梯度步数和更新顺序后差异若消失，不能归因于间隔机制。

只有上下文记住了：清空会话后增益消失，就属于上下文适应，不能改写为持久自进化。

人类学习效应有任务、先备知识和教学设计条件。机器研究也要找适用边界，而不是只挑支持类比的例子。
