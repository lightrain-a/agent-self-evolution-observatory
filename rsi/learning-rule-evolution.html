I14 · 学习规则自进化：Agent 何时真正变得更会学习？

Hattori（Nature Neuroscience 2023）提供快/慢机制的分阶段干预，DiscoRL（Nature 2025）提供可学习的训练目标生成。这里研究相同学生、相同数据和预算下，学习规则本身的改变是否提升未见任务的真实学习能力。正式编号 I14，现象与方法尚待实验验证。

I14 · 正式研究方向：学会任务，与学会学习有什么不同？

I14 · RSI META-LEARNING · P0/P1 UNVERIFIED · 2026-10-29

Same Current Ability, Different Future Learnability

泛化与未来可学习性 · 总专题：知识结构、训练历史与未来C真实学习曲线提供统一L0–L4评测语言。I14与I9区别在于固定学生、数据和顺序，唯一操纵学习规则η，然后对同一后续C任务真实更新。跨代元规则比较 →

观察问题：两个 Agent 当前都能完成同样的 A/B 任务，但过去使用过不同的更新机制；即使它们在 A/B 后测能力相近、当前 C 前测也匹配，后续学习陌生规则 C 的速度是否仍然不同？如果有，这种差异是否来自学习规则本身，而不是更多样本、课程顺序、教师提示或优化器状态？

编号与证据状态：I14 已正式纳入 RSI 研究池，用于独立跟踪文献、假设、实验和版本。编号不表示方法已经被验证，也不意味着元学习概念本身是首次提出。快环/慢环与自动学习训练目标都有成熟先例；研究仍须通过同预算真实学习实验。若关键现象不成立，后续允许降级、收窄或合并。I14 不改变 I2 的教学策略或 I9 的课程顺序；原 I1–I13 的历史排名暂时保留，I14 尚待单独评估。

两篇已经精读的论文：谁负责提出机制，谁负责给出算法？

论文真实研究对象/改进层次最值得继承的实验思想不足以直接证明什么
Hattori et al. · Nat Neurosci 2023小鼠概率反转学习+5个A2C RNN。OFC慢速可塑性形成策略，活动动态执行快策略。在新手/专家阶段分别抑制可塑性，再于专家阶段抑制活动；用奖励历史核与Policy Axis解释策略形成。不是LLM权重更新；同类概率反转任务内的元学习不等于跨任意规则族泛化。
DiscoRL · Nature 2025群体Agent跨57/103环境对目标生成元网络η做Meta-gradient，生成π̂/ŷ/ẑ等学习目标。固定更新接口、让学习目标本身可学；重置Agent，用所得η在新环境重新训练。没有让部署中的同一个LLM持续改写自己，也没有计入元发现成本的无条件训练效率优势。

最近邻还包括：Learning to Reinforcement Learn、RL²，以及 metaTextGrad。因此双层优化、RNN历史学习、自动调学习目标或文本优化器都不是首次提出；需要在持续LLM参数更新的独立未来学习收益上建立剩余科学问题。

快/慢机制理论Policy Axis测量DiscoRL Target Generation

为什么必须区分当前任务、持久知识和元策略三个不同的进步？

能力层级在机器中真实改变的对象最低证据要求常见误判
L1 · 当前任务执行变好Context / RNN hidden state / 临时工具或工作记忆同一上下文的新反馈能改善当前执行当场接受提示后答对，就叫学会
L2 · 长期任务能力变好可版本化Memory、Skill或参数θ撤除老师及一次性答案，未见任务仍有独立收益还在检索答案或直接使用Teacher
L3 · 学习规则本身变好从过去学得的更新规则η或Meta-policy重置同一任务学习者后，新η比旧η使后续任务真实更新得更快或更稳只是当前任务分数更高、更多任务样本或更会挑题

重要的是快层在Hattori动物/人工RNN中主要为活动状态而非每trial权重更新。映射到LLM RSI时，可以重新操作性定义为任务Skill/LoRA真实更新，但不能声称其神经机制同一。慢层策略变化必须与未来任务C的独立学习证据联合报告。

核心科学假设：同样会做题，学法的适用条件可能已经不同

设任务学习者为θ、历史状态为b、元规则为η。与I9固定更新器只改变A/B题目顺序不同，这里固定A/B的具体数据和训练顺序，只允许η决定相同材料形成何种目标或更新操作。例如目标生成、稳定旧能力的梯度约束、轨迹条件化的预测目标；都要由同等反馈与训练预算形成。

θ[k+1] = Update(θ[k] ; Data[k], η, feedback[k])
η[new] = MetaUpdate(η[old] ; prior training outcomes)

如果学习历史提供了真实的状态信息，新的η可能能够识别哪些规则需要保持、哪些预测目标需要改变；若只是复杂模型容量增加，历史打乱后也可能同样提升，因此要设置同容量随机历史及最优固定更新器基线。

两个可证伪假设：H1，相同初始能力的学生对不同更新规则有不同的未来学习响应，且这种差异随任务规则冲突/共享结构系统变化；H2，历史学习结果能帮助η预测这种响应并改善未见任务的同预算净增益。H1不成立就不能直接投入昂贵的元梯度系统。

P0 · 现象验证：相同任务数据，不同学法是否产生未来可学习性差异？

第一阶段先不训练复杂的Meta-Updater，只建立可复现的学习规则对照。在可验证数学规则或简化代码/形式任务中，固定同一基础模型、A/B相同样本multiset、相同顺序与教师反馈。比较普通SFT、旧能力兼容约束、目标生成式更新等；为每种情况准备完全相同的C训练与留出测试。若参数预算不同，匹配可训练参数/训练步数并单列额外诊断及元训练成本。

训练C之前必须锁定C测试集、学生检查点和优化器状态。若更新历史使θ本身不同，本组证明的是“历史对可学习性的差异”，还不能直接归因于η；独立的双层分叉在P1完成。

评审中最容易质疑：元学习训练规则在RL²/DiscoRL已有，为什么这不是简单的领域迁移？需要将科学问题压缩到真实LLM多轮参数更新中，何种已观察学习状态使新旧规则的未来增益出现可预测交互，以及不同规则对长期旧能力保持的影响，而不是再次证明Meta-RL概念。

I14 · Go / 缩题 / 降级：何时继续投入元学习规则？

I14 保持独立推进的 Go 条件：（1）同数据/同顺序/同教师/同预算下，在多个任务族重复发现‘当前能力相近但学法变化影响未来C’；（2）提前的历史状态信号能够预测哪种更新规则有利，且对未知任务关系仍稳定；（3）冻结和重置干预显示增益来自可继承的η而不是上下文/样本选择；（4）胜过最佳固定Rule和随机历史，扣除元发现成本依然有净收益。

若证据不足，允许降级：只有训练历史导致未来C差异、却无法归因于学习规则本身时，可并入I9的历史可学习性机制；也可保留为跨I科学测量，不扩建Meta-Updater。如果固定最佳Rule同样好：不训练Meta-Updater；保留负面结果和失效条件。如果只提高当前任务：只证明训练方法更有效，不能主张递归地更会学习。

技术上优先用小模型、受控合成规则和独立版本分支，先验证因果效应，再决定是否投入DiscoRL级别的Meta-gradient算力。所有结论都需在没有教师/测试答案泄漏的独立未来任务上测量。
