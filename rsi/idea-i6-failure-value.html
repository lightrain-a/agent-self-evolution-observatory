Not All Failures Are Equally Learnable

I6 · 为什么有些错误更值得学习？

同一道题、同样答错，失败轨迹却可能具有不同的后续学习价值。只研究错误的学习收益，不改变先做还是先学的顺序。

一句话科学问题

I6：同一模型面对同一道题，甚至最终给出相同的错误答案，却可能经历不同的失败过程。为什么使用其中一条失败轨迹纠错，比使用另一条更能帮助模型在后续独立解题时进步？

这里的“学习”必须对应可持续的参数或外置技能更新，之后撤掉原题答案与教师提示再测新题；单次纠错后能复述答案不算学会。

研究边界：本篇只改变提供给固定学习器的失败轨迹，固定教学顺序、反馈形式、示范信息、更新器和训练预算。I7 才研究“先看示范还是先自主尝试”，不把两者塞入同一个 Router。

一个可观察的现象

轨迹 A · 直接猜错

没有形成有效中间过程

模型面对一道多元积分题，直接套用错误公式，给出错误结果。

轨迹 B · 尝试后答错

形成部分有效步骤

同一模型在同题上尝试坐标变换、检查边界，却最终仍得到相同的错误结果。

两条轨迹从同一个模型检查点产生，问题与最终答案都一致。假设分别用它们作为学习材料，且获得相同正确解法与等预算更新，模型在新积分题上的收益仍可能不同。这是待验证现象，并不是断言 B 一定优于 A。

与 I8 不同：I8 以高置信度错误、前置知识与规则适用范围为切口，解释什么错误规则经纠正后能够跨题迁移；I6 则尽量固定题目和错误结果，只比较不同失败过程本身作为纠错材料的增量学习收益。高置信度与规则范围不作为 I6 的主要处理变量。

先解释原因，再定义模块

Challenge · 难在哪里Insight · 为什么可能解决Design · 如何验证
当前正确率只能告诉我们“没做对”，不能告诉我们一次纠错将改变多少未来能力。错误过程可能暴露已具备的子步骤、错误的知识规则以及缺口与其他题的共享程度。先随机抽取失败轨迹，采用固定纠错程序逐条更新；再用未见题的独立增益为每条失败定价。
失败轨迹越长、越接近答案、越自信，可能只是更耗 token 或原本更接近正确。学习价值应由更新后的因果收益定义，不能由“表面离正确答案多远”替代。匹配题目、初始检查点、错误长度、教师反馈、更新步数与评测；增加错误严重度、置信度、语义相似度强基线。
纠正同一道题不代表学会同一规则，更不代表跨任务迁移。某条轨迹可改写只针对原题的模式，也可能揭示跨题共用的推理规则。把原题重做、同模板新题、结构变形题和旧能力回归分开统计，并评估多个后续更新之后是否保持。

方法只放最必要的部分：先用标准化纠错更新建立每条失败的实际学习价值，再训练一个轻量 Failure Value Estimator。预测器只能读取纠错前的轨迹特征与历史，不得偷看纠错答案或最终后测。

学习价值分析解释差异与事前预测

P0：先选一个数学任务族及一组跨题共享规则，收集同一检查点在同一道题上的多条自然失败轨迹。随机指定某条失败轨迹为学习材料；另一分支只读正确解法作基线。每个分支从同一初始检查点重新开始，而不是顺序累积训练。

配对控制：优先匹配同一目标题、同一错误终点与已知错误规则，只让失败轨迹的中间过程不同；固定教师正确解法、训练器、token 上限、学习率、更新步数和测试集，并对轨迹长度/额外解释文本做预算敏感性分析。保留“只看答案”“随机失败”“按置信度选错误”“按答案距离选错误”等对照。

定义：G(f)=Acc_after(f, D_holdout) − Acc_before(D_holdout)，并同时报告相对于“只看正确解法”的增量；D_holdout 按知识点与模板去重。分层估计同题组内的学习收益差，不把一题上的多个 Probe 当成独立样本。

下一步：用不同题/不同模型上的纠错前轨迹预测 G(f)，比较随机选错误、按难度/置信度/长度选错误与收益预测选择；报告预算相同时的迁移增益和选择 regret。

最近邻：做到了哪里、我们还要回答什么

相关工作已研究的关系I6 的独立问题
I8：高置信度错误与规则级迁移针对错误的知识准备程度、规则覆盖范围以及持久更新后的跨题净收益。固定题目与错误终点，仅研究失败轨迹过程是否提供额外有用信息。
Learn from Failure · ACL 2024形式定理证明中，失败搜索轨迹可成为有价值的训练数据。不是证明失败“可以用”，而是研究哪条失败更值得用。
MENTOR: Learning from Failure with On-Policy Pedagogical Intervention · 2026 预印本训练停滞时依据失败原因生成教学提示，帮助恢复学习信号。固定教学方式后，仅比较失败轨迹本身的可学习价值，避免归功于更好的提示。
Productive / Unproductive Failure 学习科学文献失败及其后续整合可能有不同教学结果。把启发转为可审计的模型更新与无教师后测，不声称人类结论自动迁移到 LLM。

文献证据支持研究动机；同题失败价值差异、预测有效性和跨模型迁移尚待本项目验证。

怎样决定继续还是停止

继续：匹配题目、示范与计算预算后，失败轨迹之间仍有可重复的迁移增益差异；简单的错误严重度、置信度、轨迹长度无法解释全部差异；预测器在未见任务上能减少同预算的错误选择。

缩题：只发现纠错收益差异而无法事前预测时，优先做现象与机制分析，不夸大为学习策略优化系统。

停止：不同错误的差异在同反馈/同预算后消失，或只在原题重复出现、撤掉教师后失效。
