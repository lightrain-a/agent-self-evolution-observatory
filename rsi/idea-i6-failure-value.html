Not All Failures Are Equally Learnable

I6 · 为什么有些错误更值得学习？

同一道题、同样答错，不同失败过程可能有不同的学习价值。I6 先回答哪条失败值得纠正，再研究何时继续尝试、换一道题，或暂缓后重新回来学。

更新 2026-10-28来源可追踪提案尚待实验

一句话科学问题

I6：同一模型面对同一道题，甚至最终给出相同的错误答案，却可能经历不同的失败过程。为什么使用其中一条失败轨迹纠错，比使用另一条更能帮助模型在后续独立解题时进步？

发现 E 并入 I6：当同一道题反复失败时，下一条失败轨迹是否还值得收集？如果预计新增失败的学习价值已小于成本，是否应该停止当前尝试、把预算用在别的错题上，或者暂缓后再回来？停止当前题 ≠ 永远放弃这道题。

这里的“学习”必须对应可持续的参数或外置技能更新，之后撤掉原题答案与教师提示再测新题；单次纠错后能复述答案不算学会。

研究边界：核心因果实验只改变提供给固定学习器的失败轨迹，固定教学顺序、反馈形式、示范信息、更新器和训练预算。新增的停止实验仅决定是否继续收集当前题的错误、改用另一题的错误，或暂缓重访，不自行选择教学方法。I7 才研究“先看示范还是先自主尝试”；旧版跨轮瓶颈路由作为历史草案单独保留。

一个可观察的现象

轨迹 A · 直接猜错

没有形成有效中间过程

模型面对一道多元积分题，直接套用错误公式，给出错误结果。

轨迹 B · 尝试后答错

形成部分有效步骤

同一模型在同题上尝试坐标变换、检查边界，却最终仍得到相同的错误结果。

两条轨迹从同一个模型检查点产生，问题与最终答案都一致。假设分别用它们作为学习材料，且获得相同正确解法与等预算更新，模型在新积分题上的收益仍可能不同。这是待验证现象，并不是断言 B 一定优于 A。

再进一步：如果模型已经反复产出同一种错误过程，继续在这道题上重采样可能只得到更多相似失败；另一个暂时不会做的题，反而可能提供一种更容易学会的新规则。两道题都没进展，并不代表下一条失败轨迹有同样的学习价值。这也是 I6 中“何时停止当前学习”需要验证的现象。

与 I8 不同：I8 以高置信度错误、前置知识与规则适用范围为切口，解释什么错误规则经纠正后能够跨题迁移；I6 则尽量固定题目和错误结果，只比较不同失败过程本身作为纠错材料的增量学习收益。高置信度与规则范围不作为 I6 的主要处理变量。

先解释原因，再定义模块

Challenge · 难在哪里Insight · 为什么可能解决Design · 如何验证
当前正确率只能告诉我们“没做对”，不能告诉我们一次纠错将改变多少未来能力。错误过程可能暴露已具备的子步骤、错误的知识规则以及缺口与其他题的共享程度。先随机抽取失败轨迹，采用固定纠错程序逐条更新；再用未见题的独立增益为每条失败定价。
失败轨迹越长、越接近答案、越自信，可能只是更耗 token 或原本更接近正确。学习价值应由更新后的因果收益定义，不能由“表面离正确答案多远”替代。匹配题目、初始检查点、错误长度、教师反馈、更新步数与评测；增加错误严重度、置信度、语义相似度强基线。
纠正同一道题不代表学会同一规则，更不代表跨任务迁移。某条轨迹可改写只针对原题的模式，也可能揭示跨题共用的推理规则。把原题重做、同模板新题、结构变形题和旧能力回归分开统计，并评估多个后续更新之后是否保持。

方法只放最必要的部分：先用标准化纠错更新建立每条失败的实际学习价值，再训练一个轻量 Failure Value Estimator。预测器只能读取纠错前的轨迹特征与历史，不得偷看纠错答案或最终后测。停止机制只复用它的收益估计和不确定性，不另外训练一个负责选择教学法的大型 Router。

学习价值分析解释差异与事前预测

P0：先选一个数学任务族及一组跨题共享规则，收集同一检查点在同一道题上的多条自然失败轨迹。随机指定某条失败轨迹为学习材料；另一分支只读正确解法作基线。每个分支从同一初始检查点重新开始，而不是顺序累积训练。

配对控制：优先匹配同一目标题、同一错误终点与已知错误规则，只让失败轨迹的中间过程不同；固定教师正确解法、训练器、token 上限、学习率、更新步数和测试集，并对轨迹长度/额外解释文本做预算敏感性分析。保留“只看答案”“随机失败”“按置信度选错误”“按答案距离选错误”等对照。

定义：G(f)=Acc_after(f, D_holdout) − Acc_before(D_holdout)，并同时报告相对于“只看正确解法”的增量；D_holdout 按知识点与模板去重。分层估计同题组内的学习收益差，不把一题上的多个 Probe 当成独立样本。

下一步：用不同题/不同模型上的纠错前轨迹预测 G(f)，比较随机选错误、按难度/置信度/长度选错误与收益预测选择；报告预算相同时的迁移增益和选择 regret。

发现 E · 何时停止当前错误的学习，何时重新回来？

Challenge｜难在哪里？模型连续做错同一道题，并不说明再来一次毫无价值。也许下一条失败轨迹会暴露新的推理缺口；也许模型已经反复犯同一种错，继续采样只会浪费预算。更难的是，现在学不动，不代表补充知识或模型版本改变后依旧学不动。

Insight｜可以比较什么？I6 已经要预测“纠正一条失败轨迹，能够让未来的独立能力提高多少”。顺着这个指标，进一步比较：继续收集这道题的新失败，与纠正手头已有错误、换另一道题的错误，哪个给下一轮带来的净学习收益更高？当新增轨迹的边际收益变小，而其他失败更值得学时，就应该停止当前题的尝试。这里的目标是学习价值，不是最低当前解题时间。

可选行动为什么这样做必须检查的风险
继续尝试当前题预计再得到一条不同失败后，按固定纠错程序学习，仍有新增迁移收益。不能把更长轨迹、更多采样或当前题 pass@k 上升算成独立能力提升。
纠正已有错误当前已经收集到高价值失败，再采样的边际价值不如直接开始固定更新。纠错答案、更新器与教学顺序固定，预测器不许偷看正确答案。
换其他错题另一个待学失败在相同学习成本下预计贡献更大的跨题增益。不能把换成了更强教师、更简单训练器算作选择收益。
暂缓并重访目前没有值得继续投入的失败轨迹，但前置能力或下一版模型可能改变它的可学习性。事前写明重访条件，不根据独立终测结果决定何时回来。
结束本轮投入题目已掌握，或在既定预算内所有可选失败的预计收益都不足。严格区分“已掌握”“当前不值得学”和“还无法判断”，不能声称永远学不会。

Design｜怎样实施？沿用 I6 的 Failure Value Estimator，记录当前失败池、已有失败的预计纠错增益、再次采样可能获得的新轨迹价值、其他待学错误的机会成本，以及实际 token / 更新 FLOPs。选择预计独立净收益最高的行动；在估计不可靠时保留探索份额，防止把稀有但高价值的错误过早排除。所有 Probe、额外轨迹、纠错更新和重访都算入总预算。

同题失败池同版模型，记录新失败是否真的提供不同信息
预估学习增益固定纠错后，新题独立表现将改变多少
比较下一次投入继续收集 / 纠正已有 / 换错题 / 暂缓
按条件重访前置能力变强、模型版本更新或预定复测点
真实更新后验收撤辅助、未见题迁移与旧能力保持

暂缓的错误进入 Deferred Failure Queue，附原模型版本、估计收益区间和重访条件。重访不一定更有效：同一个错误在新模型上可能已经掌握，也可能变得更难学，必须重新测可学习性，而不能沿用旧分数。

学习科学启发，而非既有 RSI 结论。Metcalfe 与 Kornell（2005）的 Region of Proximal Learning 区分选择学习材料与决定学习多久，用 jROL（对学习速率的判断）解释停止当前材料。[E16] MetaCLASS（EMNLP 2026）在教学动作预测里观察到：41.7% 的标注轮次无需干预，最佳模型预测“不干预”却只有 6.6%。[E17] 两者分别来自人类学习和教学决策，不能直接证明 LLM 停学有效；I6 必须用真实更新后的独立迁移来验证。

不扩写成大而全的策略路由：I6 的新增选择对象是哪条失败轨迹值得继续投入，不是换哪一种训练算法。固定纠错方法的局部选法属于 I2；I7 研究尝试与示范的先后；I8 研究错误规则与知识准备对迁移的作用。

NC 2021 精读迁移｜同样没有进步，未来可学性可能不同

原论文的真正发现。Ten 等（Nature Communications，2021）让 382 名参与者在 3 项可以学习、1 项随机不可学习的任务间自主选择，共完成 250 次自由选择。有明确学习目标的一组将 36.92% 的尝试花在随机不可学习任务上，无明确目标组为 23.43%；与此同时，明确目标组在难度加权学习表现上总体更好。挑战倾向可能帮助人攻克难题，也可能造成无效投入，这两个结果必须一起报告。[E19]

论文通过行为模型分离近期正确率 PC 与学习进步 LP；同时含有二者的模型更好拟合活动选择。论文的 LP 是不同近期窗口正确率之差的绝对值，因此下降也可能带来高变化信号。这反映人类的自由选择规律和模型拟合，不是对 LLM 停止/重访策略的因果证明。[E19]

同样的近期表现可能发生了什么I6 必须区别的行动价值
低正确率、LP≈0反馈本身随机，不含稳定可学规律及时停止，不应永远投入；作为负对照
低正确率、LP≈0题目有规律，但模型缺少必要的前置知识暂缓并在预定前置能力更新后重访，检查是否重新可学
低正确率、LP≈0重复得到同一失败轨迹，没有新增可用于纠错的信息当前不再采样；利用已有失败学习或换另一条失败
大幅 |LP|、总体不增长旧技能被干扰后恢复，又在后续更新中再次丢失区分重新修复旧能力与真正新增持久能力；见 I3

Challenge：目前的 PC / LP 只描述“这个模型在既定学习条件下过去发生了什么”，并不回答“同一道题在前置知识补齐后能否学会”。Insight（待验证）：可学习性可能是模型状态 × 错误材料 × 更新方法的条件属性，而非题目固定难度或历史进步率。Design：保留 I6 原有的固定纠错方式和 Failure Value 目标，预测下一条失败的边际学习收益，并为低收益错误设置事前规定的重访触发；不扩展为 I2 的通用教学方法路由。

最小辨别实验：Same Plateau, Different Future Learnability

从同一基座模型生成两类当前 PC 与 LP 匹配、但机制不同的学习停滞：一类是可通过固定的前置知识学习重新打开的数学规则错误；另一类用随机反馈任务作不可学习负对照。先冻结规则族、错误轨迹、诊断预算和最终未见题集。然后随机分配相同总预算：继续在原题采集失败 / 暂缓，完成预设前置学习，再回到原题 / 暂缓但不给目标相关前置知识。之后统一使用相同纠错器，撤掉辅助，比较规则级新题净增益、重访成本、过早放弃率与是否错过可恢复错误。前置学习与目标任务必须分集，且不能依据终测成绩决定重访时机。

不能声称的新意：依据 learning progress 选任务、用绝对 LP 发现退步、学习停滞后换题，在 TSCL、Graves 与 SPaCe 等方法中都已有研究。I6 需要证明的是：同样的观测平台期，为何对“再收集一条失败”或“换状态后重访”产生不同的未来学习收益，并且增益在等反馈、等训练量下超越简单 LP 阈值。[M04][M12][S45]

E2 · 继续、停止、暂缓与重访的辨别实验

先验证现象。选同一道题上反复产生失败的冻结模型状态，记录各次新增轨迹；从同一 checkpoint 分叉，把每一条轨迹单独送入同一个纠错程序。测新增轨迹的实际跨题独立收益，看看“同样连续答错”，下一条失败的学习价值是否有可重复差异。以题目/规则簇作为统计单位，不把一次题目的几十条采样当几十个独立任务。

再验证停止决策。固定同一个可用错误池与计算预算，比较：固定采样 K 次、随机挑错误、近期正确率或 jROL 式学习速率阈值、有符号 LP / 绝对值 LP课程选择、I6 的失败价值预测 + 停止决策。把不允许停止/暂缓作为消融；将实际纠错后的最佳行动只作为事后 oracle 上界，不能提前交给策略。PC/LP 均来自冻结开发轨迹，筛选成本计入预算；不能把“某组变化更大”直接解释为学会了更多新知识。[E19]

最后验证重访。将当轮预计低收益的困难题随机分为“持续采集失败”“离开且不返回”“暂缓、在前置能力/检查点发生预定义变化后重访”。先固定重访触发条件与后续任务流，再用未见题测净收益，避免按测试答案挑时机。只有出现重访后明显增益，才能说“暂停比继续死磕更好”；否则只支持任务切换而不支持重访。

统一结果：未来未见题的撤辅增益 / 总计算成本、旧能力回归、过早停止率、错过可恢复失败的比例，以及重访的增量收益。教师答案、训练器、示范顺序、更新步数都固定；探索阶段可记录不同长度，但评测须有严格等 token / FLOPs 对照。

Science 2024｜哪些经历只是被记下，哪些真正值得后续巩固？

动物实验而非LLM：Yang 等（Science，2024）记录6只小鼠、26个会话、4,469个海马CA1神经单元；借助seqNMF/UMAP解码相同迷宫不同试次的群体活动。约33%的清醒SPW-R具有显著重放序列。在5只小鼠的16个会话中，清醒时被重放较多的五试次经历块，在之后睡眠中也更常被重放（R=0.86，p<3.1×10−34）。作者将其解释为候选的清醒“记忆标记”；没有随机操作特定重放，也没有测试成功/失败经历的长期行为收益。 进入完整精读、Fig.1–4数据与样本层级 →

研究方向的 Go / 缩题 / Stop（与模型的停学决策分开）

继续：匹配题目、示范与计算预算后，失败轨迹之间仍有可重复的迁移增益差异；简单的错误严重度、置信度、轨迹长度无法解释全部差异；预测器在未见任务上能减少同预算的错误选择。新增的停止/重访策略若也能带来独立净收益，作为 I6 的强化证据。

缩题：只发现纠错收益差异而无法事前预测时，优先做现象与机制分析，不夸大为学习策略优化系统；若停止策略没有超越简单阈值，保留主线并撤掉停止控制器，不强行增设模块。

停止：不同错误的差异在同反馈/同预算后消失，或只在原题重复出现、撤掉教师后失效。
