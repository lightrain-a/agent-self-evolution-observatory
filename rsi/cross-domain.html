来源迁移对象强简单替代继续的依据
元学习 / 学习优化器 [M01][M02]跨初始 Agent 学到可重用改进策略。固定优化器、同容量历史条件策略。重置学习者后仍改善新任务学习曲线。
课程 / Learning-to-Teach [M03][M04][M06]联合选择任务、帮助和巩固方式。均匀、难度优先、学习进展 bandit。任务相同时，干预方式或次序仍重要。
知识追踪 [M05]跟踪独立表现、帮助依赖和受干扰后的状态。历史成功率、DKT 风格序列预测。预测干预效果，而非仅预测下一题成败。
双重控制 [M07]Probe 既练习又辨别瓶颈。随机、最高不确定性 Probe；普通 bandit。信息真正改变后续决策和延迟收益。
持续学习 / 重放 [M08][M09]按更新干扰安排重练与固化。随机重放、PER、MIR、TSCL。多看一遍旧数据不能解释收益。
预测辅助规划 [S11][S13]从环境动作后果转向学习干预后的能力变化。直接总分预测、任务语义先验。多步规划比单步选择有用，误差可控。

候选核心：学习响应，而非自评分数表

系统状态为 s_t = (θ_t, h_t, m_t)：参数、Harness 与持久记忆；元策略为 π_φ。学习动作 a_t 指定练习对象、帮助方式和更新操作。我们拟学习：

F_ψ(b_t, a_t, Δ_t) → distribution(Δc_now, Δc_after-H)

b_t 是依据执行形成的能力状态估计，Δ_t 描述后续干扰，c 是多个能力族的独立表现向量。预测同时包括目标收益与其他能力退化。这是待验证设计，不预先宣称能够识别所有隐变量。

同一旧版本冻结快照与环境
随机分配干预帮助 / 更新动作
即时与延迟探测不用训练答案
学习响应分布收益、退化、不确定性
新状态选动作以执行校正

“某动作常在困难样本上失败”不代表动作有害。先用同版本分叉和随机干预获取局部效应，再谈建模。与知识追踪及前瞻课程的区别须通过此设计验证，而非靠“因果世界模型”命名。[M05][S18]

什么时候值得多做一次诊断？

理想信息价值：得到诊断后，最佳改进决策的期望收益增加多少，再减诊断成本。

VOI(q) = E_q[max_a E(U(a) | D,q)] − max_a E(U(a) | D) − cost(q)

这是目标，不是假设能精确求解的公式。先用小型预测集成和一步候选重排，比较随机、最高分歧与收益相关的 Probe。只有信息确实改善后续选择，才扩大为多步元 RL。双重控制的现成理论保证不能直接套用到非平稳 LLM 自修改。[M07]

反例：Probe 准确判断某个 API 是否存在，但所有候选修复都不依赖该 API；信息很多，却没有决策价值。

重置学习者，保留元策略

条件保留重置 / 破坏检验
旧元策略固定 π₀相同参数、Harness、空历史。学习效率基线。
新元策略训练后的 π₁与上行完全相同。元经验迁移。
打乱历史相同长度、数量记录。破坏干预和结果的对应。是否只是更多上下文。
持续更新消融底层 Agent 都允许更新。仅一组冻结元策略。在线元更新是否有效。

重置测试沿用元学习思想，不是独立算法创新。它是 Meta-RSI 主张所需证据之一；双方获得同等长度历史和调用额度。[M02][S08]

避免模块堆叠

第一版只引入一个新决策：何时、如何提供与撤除学习支持。编辑器、底座、任务池、验证器共享。若出现长期收益，再加入响应模型；若固定规则同样有效，保留机制结论，不强行加入 RL。

通用预测器 + contextual bandit 不是弱基线，须得到同样的轨迹、参数规模和执行预算。若它们足以解释结果，复杂结构就没有必要性。
