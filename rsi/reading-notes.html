为什么当前 Coding Agent 高分不等于未来有更强后代？HGM 如何定义、估计后代支系潜力，它的定理和实测优势分别能证明什么？

先记住这些术语

Archive / 版本树
每个节点是一份可运行的 Coding Agent 代码版本；父节点修改代码产生子节点，留出多条后代分支。
MPM
Metaproductivity–Performance Mismatch；当前代码成功率不可靠地反映未来搜索出强后代的潜力。
GMP
Global Metaproductivity，选择某节点扩展后，整棵树最终可能找到的最好 Agent 的期望效用。
CMP
Clade-Metaproductivity，只考虑以当前节点为根的未来后代支系；与历史成功率估计是两个不同量。
Thompson Sampling
利用任务成功/失败证据采样可能的收益，不完全贪心；扩展阶段用支系统计，评测阶段用单节点统计。
Best-belief Agent
在最终版本树中按效用后验的指定分位数挑选返回的 Coding Agent，而非只看单次测试结果。

01 · Challenge

难在哪里

DGM/SICA 按当前任务分数选择修改对象，但高分父代未必能产生强后代；有限预算应该扩展哪条分支？

§1：为什么当前高分，不一定是最值得继续进化的父代？展开细节

想象一条 Agent 搜索树：A 今天的代码修复成绩较高，但之后每次改写都没有产生更好版本；B 当前略弱，却有更易扩展的工具接口或可修改执行策略，未来反而产生更强的子代。这是本站用于说明直觉的例子，不是论文的具体数值。

MPM 的核心

SICA 和 DGM 倾向根据当前性能优先发展某个版本，可能过早放弃目前分数较低、但后续修改更有价值的祖先。这种偏差被作者命名为 Metaproductivity–Performance Mismatch。

02 · Insight

为什么可解

未来自改进价值应考虑整条后代支系可找到的最好版本，而不只是父代眼前的代码成功率。

§3.2：GMP 看整个树，CMP 看某个祖先的后代展开细节

GMP（Global Metaproductivity）看从某个扩展决策出发，后续整个代码演化树最终能够找到多强的 Agent。CMP（Clade-Metaproductivity）则限制在当前节点 a 的子树里，衡量其后代谱系的未来价值。

§3.2 · GMP（概念表达）GMP_pi(T,a) = E_{T_B | T,a,pi}[ U(argmax_{v in T_B} Score_pi(v)) ]

怎么理解：状态是目前的完整版本树 T，动作是选择从哪个父代继续扩展，未来结果依赖后续策略 π。

边界：这是对未来演化过程的期望，不是现在某个版本在 benchmark 上的经验得分。

§3.2 · CMP（概念表达）CMP_pi(T,a) = E_{T_B | T,a,pi}[ U(argmax_{v in Clade(T_B,a)} Score_pi(v)) ]

怎么理解：只看 a 的未来后代支系，不包括其他无关兄弟分支。

边界：真实 CMP 需要考虑还没生成的后代；后文用历史统计计算的 CMP_hat 只是代理，不得视为同一对象。

为什么这是 RSI 研究的重要前作

它已经提出并讨论“当前能力 ≠ 后续改进潜力”的问题，因此不能把这一现象再声称为我们新的首次发现。

Theorem 1：为什么作者并没有证明现实中的 HGM 全局最优？展开细节
  • 假设 A：目标只依赖预算结束后最终选中的 Agent，改写过程中没有其他奖励。
  • 假设 B：所有任务评测可重置、可重复，过去评测不影响之后同一 Agent–Task 的期望结果。
  • 假设 C：形式证明不消耗预算，任何一次自修改恰好消耗相同一单位预算。
  • 在这些条件下，真实 CMP Oracle 能支持论文定义的 Gödel Machine 决策。
理论 Oracle ≠ 实际经验估计

HGM 本身没有访问未来的真 CMP，仅从已观察到的版本树中聚合证据。因此这个定理不能推导出现实系统中 HGM 已达到自改进全局最优，更不等于所有 LLM 参数型 RSI 都最优。

03 · Design

具体怎么做

为代码版本建树；聚合支系的成功/失败评测；用 Thompson Sampling 选父代，独立决定扩展、评测与最终版本。

§2：自修改如何变成一棵树，而不是只保留最新代码？展开细节
  1. 从初始版本开始

    a0 是根节点。每次运行自修改操作 m_a，都生成一个新的 Coding Agent 子节点并归档。

  2. 扩展与评测是两个动作

    扩展创造新节点；评测 v_a 则在一个新任务上测试已有节点，增加该节点的成功或失败证据。

  3. 用完预算后选最终 Agent

    搜索目标不是累计过程奖励，而是让预算结束后被选中的 Agent 获得更高的真实代码任务效用。

§2 · 整体搜索目标J(pi)=E[U(a_final)]; a_final=argmax_{a in T_B} Score_pi(a)

怎么理解：π 包含创建候选、追加评测和终止时版本选择三个决策，U 以平均任务通过率表示。

边界：对于动态权限、非静态任务与真实运行风险，U 不能自然推广为唯一目标。

§3.3：HGM 怎样用已经观察到的后代来估计 CMP？展开细节
支系成功率估计CMP_hat(a) = Σ_{v in C(a)} n_success(v) / Σ_{v in C(a)} [n_success(v)+n_failure(v)]

怎么理解：将节点 a 和当前已生成后代的通过/失败任务次数聚合；评测次数多的节点自然权重更大。

边界：这是历史支系统计，不是理论定义的未来最优后代期望。评测策略决定样本分配，估计可能带有选择偏差。

作者之所以聚合整个 Clade 的结果，是因为低分祖先的高质量后代本身就提供了“继续从这条支系搜索”的证据。相比单节点成功率，累积多节点的评测样本也减少了极端少样本估计的不稳定性。

扩展时：支系 Thompson Samplingz_a ~ Beta( τ·[1+n_success^C(a)], τ·[1+n_failure^C(a)] ); expand argmax z_a

怎么理解：用支系证据生成 Beta 后验样本，概率化选择父代；τ 随当前阶段逐渐偏向利用。

边界：Beta 建模是求解策略，并不自动补偿非独立后代数据的偏差，也不能保证发现所有潜在高价值支系。

需要分清：扩展父代使用支系级的聚合证据；对于追加评测哪个具体 Agent，HGM 使用该节点自己的成功/失败证据。二者对应不同的决策。

§3.3：Expand 和 Evaluate 为什么必须分开？展开细节
无限臂 Bandit 式调度Expand if N_t^α ≥ |T_t| ; main α = 0.6

怎么理解：N_t 是已完成评测次数，|T_t| 是当前版本树的节点数。根据可用证据决定是否继续引入新候选。

边界：这是算法采用的启发式调度规则，而不是实验证明的普遍最优比例。

  1. 先选动作类型

    这次预算到底用于生成一个新代码 Agent，还是用一个已有 Agent 再做一道测试？

  2. 需要扩展时选支系

    对各候选父代做 Thompson Sampling，考虑整条后代谱系而非单节点准确率。

  3. 需要评测时选节点

    基于具体节点后验不确定性与成绩，追加一个 Agent–Task 结果，不必强制新节点做完全部测试。

  4. 异步运行

    将扩展与评测以异步方式放到 CPU worker 中，不用等整批任务完整运行才继续搜索。

示意：为什么能减少浪费？（本站编造案例）

新节点 X 已连续失败九个测试；另一个旧节点 Y 在很少的评测中有成功记录。旧方法可能继续把预设数量的测试跑完，新方案可以优先给 Y 补评。这个示意不代表作者提供了相同数字的实验。

节省 CPU-hours 的归因

HGM 改变的不只是 CMP 指标，也改变了每个节点的评测粒度、是否立即评测子节点以及异步资源调度。因此 Table 2 的效率收益是算法整体效果，不能归给 CMP 单一组件。

实验设计：在等总计算量、独立测试、不同随机种子下，比较简单当前分数、Clade 代理和真正后续学习曲线。

在同一道题里反复修复，不等于系统能力持续提高。论文区分任务内的动作步 t 和系统更新周期 k：一次周期可以不接纳任何更新；只有被接纳的 Policy / Workflow 或 World Model 改变下一轮决策，才体现持久改进。

举个例子

今天修好了一个程序，不代表明天就会修同类错误。系统要在下一轮用上学到的东西，才算把这次经验留下来。

02 · Insight

为什么可解

先预测哪些方案值得试，可以少花测试成本。真实结果又能纠正预测器，但升级时必须看整套系统是否进步。

为什么用预测先挑，再用真实结果纠错？展开细节

关键不是让世界模型替代真实测试，而是把两者分工：预测负责省测试次数，真实结果负责检验预测准不准。Agent 变强后可能提出新方案，所以预测器也要根据新反馈调整。

碰到的问题容易掉进的坑作者的办法
测试费用高四个候选全部跑完，预算很快用光先预测，挑值得试的方案去真实执行
预测器会看走眼把模型猜测当成事实，后面越学越偏只用真实执行的结果检查预测是否可靠
模块之间不一定合拍Agent 和预测器单独更好，搭配却可能更差升级之前重新测试新组合
一句话理解

预测是为了少走弯路，真实反馈是为了知道有没有走对；系统是否进步，要看最后整套搭配。

更像“系统级自我改进协议 + 多领域验证”，而不是首次提出世界模型、基于反馈学习或检查回退。五类实验覆盖不同路径；论文也说明仍需单一任务中的长期联合多轮评估。

  • 即时排序无法生成原 Policy 从未提出的好解，也不能解决候选分布外的可靠性。
  • 只有被选中测试的候选提供观测，WM 可能持续低估某些正确但少见的方案。
  • 配对门控不等同于旧任务长期不遗忘，或恶意行为不会被写入记忆。
  • 评价标准在实验协议中固定；“评估器本身也会被改写”仍是开放问题。

Optimizing practice scheduling requires quantitative tracking of individual item performance

它真正解决的是“已学内容何时复习最划算”；并不证明一项不会的任务，只要等待就会变得容易学习。

01 · Challenge

难在哪里

同样的单词复习间隔，对不同学生和不同单词未必合适；答错还要花时间纠错，固定安排容易浪费学习时间。

为什么复习同一个间隔，学生效果会差这么多？展开细节

一个学生记得牢的词，另一个学生刚看过就忘。两人都隔三天复习，看起来公平，却可能一方练得太早、另一方练得太晚。答错还可能多花时间看正确答案，固定间隔把这些差别全忽略了。

先分清正在解决什么

这是“已经学过一个单词，现在要不要再练”的记忆保持问题。模型并不是在设计全新的数学课程，也没有靠等待学会此前没有的知识。

02 · Insight

为什么可解

最值得复习的不一定最难。既要估计现在还记不记得，也要比较练习后能多记住多少，以及花掉多少时间。

为什么不是优先练最容易错的词？展开细节

最难的项目可能需要更多思考与错误反馈时间；最容易的项目又可能练完也没有多少收益。所以作者不只看答对概率，还计算成功/失败各自的学习收益与时间成本。

Eq. (1) · 成功与失败的期望练习效率U = p·G_correct/C_correct + (1−p)·G_wrong/C_wrong

怎么理解：p 是正确回忆概率；G 是该次练习后预计增加的长期记忆收益，C 是答题和反馈占用的时间。难度越高并不必然越值得练。

边界：这是按条件收益/成本加权的效用表达，并非任何时候都等于“总预期收益 ÷ 总预期成本”。实际 OET 由模拟找出，不是直接逐次最大化这个单一公式。

最该记住的 Insight

最优练习难度来自收益与成本的平衡。失败若特别有帮助、又不贵，最佳难度可以变难；作者的 Fig. 8 也模拟了这种变化。

03 · Design

具体怎么做

根据每个学生、每个单词的练习历史预测回忆概率；先用模拟选出目标阈值，再逐次复习最接近该阈值的项目。

每次怎么选下一个复习词？展开细节
  1. 用历史记录估计每个单词的回忆概率

    考虑学生、单词差异、以往成功/失败、平均间隔和经过的时间；没有历史的词利用预估项目难度。

  2. 先模拟不同阈值，再采用 OET 选词

    如果 OET=0.94，优先选择当前低于 0.94 且最接近它的单词；不是每次都挑最难的。

  3. 练习后更新状态并继续

    已练过的词在预测回忆概率重新下降到阈值附近时，才更可能再次进入练习。

仅为解释 OET 的教学例子；概率不是论文真实参与者的数据。

一个重要实现边界

OET 最优阈值由事先的模拟研究选定；练习安排按每人每题实时更新。不能误解成每位学习者都能在线精准学到自己的最优 OET。

为什么同一个项目会越学越久才复习一次？展开细节

练习成功后，预测回忆概率上升；随后因遗忘而下降。容易且记得牢的词较晚才再次接近阈值，因此自然间隔更久。模型不是人工硬编码“每轮多隔一天”。

04 · Result

结果怎么样

日英单词实验中，0.86 和 0.94 的回忆概率阈值优于固定间隔及过难/过易阈值；0.94 组相对固定安排约多记住 40%。

40% 是怎么得到的？展开细节

作者先模拟不同复习策略，再在人类日英词汇记忆实验中比较固定间隔和五个 OET 条件。每人练习 30 组词，总练习时间约 22 分钟，之后进行延迟回忆测试。

模拟：6 种传统安排、22 种 OET 条件

评测设置：用回忆概率与反应时间模型，在给定练习总时间下模拟最终回忆表现。

作者报告：高回忆概率阈值（特别是 0.94）预计效率较好；较难或过易安排并非最佳。

能够支持：在模型假设成立时，时间成本足以改变推荐复习难度。

尚不能推断：所有题型或个体都有唯一固定最佳阈值。

真实实验：延迟日英词汇回忆

评测设置：S15 固定间隔对照与 OET=0.40、0.70、0.86、0.94、0.98；22 分钟内学习 30 对词。

作者报告：0.86、0.94 优于传统 S15 和 0.40、0.98；0.94 相对 S15 约多记住 40% 项目。

能够支持：同等学习时间下，该记忆任务中基于预测的练习调度能提高延迟回忆。

尚不能推断：“40%”不是 40 个百分点，不是跨题数学迁移，更不是 RSI 的权重更新收益。

样本和条件不要外推

本研究测的是人类已学词汇的延迟记忆。作者明确指出，单词相对独立是其简化假设；复杂知识之间的影响还需专门研究。

01 · Challenge

难在哪里

精确去重后，模型仍可能记住敏感或测试文本；仅数一段话原样出现了几次，可能遗漏隐藏重复。

Challenge：表面文字不同，为什么还会产生重复记忆？展开细节

过去常用精确重复解释LLM对训练文本的记忆：一段话出现得越多次，越容易留下可检测的成员信号。因此去重和训练集污染检查常从逐字匹配开始。作者提出更具体的问题：如果原文被改写、插入噪声或调换局部顺序，模型能否依靠共同片段继续强化对原文的记忆？

原论文研究对象

真正的被解释变量是对特定原文的文本记忆，用成员推断与抽取来衡量；不是模型是否获得了新知识或新的解题规则。

02 · Insight

为什么可解

多个不完全一样的副本保留相同的Token或局部片段，能够共同强化模型对一段原文的记忆。

Insight：重叠Token片段可能共同强化已出现原文展开细节

作者称其为Mosaic Memory：不同样本没有逐字重复，但共享的Token及短n-gram仍可能给模型提供重复的学习信号。必须让这些副本真的进入参数训练，再测它们对同一原文成员信号的边际贡献，不能只比较两段文字的相似分数。

层次要回答的问题不能由什么代替
文本新颖性文字、Token、n-gram与历史样本有多大重叠换变量名、换词序就必然是全新数据
规则新颖性（RSI）是否引入新的适用条件、关键反例或可迁移规则新场景就一定引入新知识
能力新增（RSI）真实更新后，撤掉示范能否解决过去不会的新任务训练样本数量、当前训练正确率或ρ
不要提前替论文扩大结论

论文只直接验证了文本记忆及模糊副本对原文记忆的影响。规则新颖性和跨题净学习收益是本站后续需要测试的问题。

03 · Design

具体怎么做

向公版图书加入原始100-Token Canary及九份模糊变体，真实续训模型，用MIA AUC校准精确重复等效ρ。

Design 1：200条Canary、两个成员组、同一继续预训练协议展开细节
  1. 构造原始标记文本

    Llama-2 7B生成200条恰好100 Token的参考Canary；其中100条随机设为Member，100条作为Non-member。

  2. 控制训练材料

    Member的完整原文及九个变体进入100本Project Gutenberg公版图书（约8.8M Token）；Non-member及变体均不进入。

  3. 真正更新模型参数

    从相同目标模型起点继续预训练1个epoch，主模型为GPT-Neo 1.3B、Gemma-2B、Phi-2、Llama-3.2-1B；主图报告五次独立重复。

  4. 以成员推断测原文记忆

    对参考Canary进行MIA，计算成员与非成员的ROC AUC，并用“精确原文重复几次时达到同一AUC”作为标尺。

实验控制最重要的限制

所有Member样本都出现一份完整原始Canary。证据支持“模糊变体进一步强化已经出现的原文”，不能直接写成“即使原文从未出现，模型也能从碎片准确重组”。

Design 2：把模糊重复转换成精确重复等效ρ展开细节
Exact Duplicate Equivalentρ = (ν_eq − 1)/(n_dup − 1) = (ν_eq − 1)/9，主实验n_dup=10

怎么理解：首先用不同的精确重复次数建立MIA AUC校准曲线；再找到模糊重复组对应的等效精确次数ν_eq。扣掉原本就有的1份原文，得到九个模糊副本平均保留多少精确副本效应。

边界：ρ不是背诵正确率、不是训练损失缩减比例、也不是新增知识占比。

举例说，若ρ=0.65，一个原文加九个模糊副本，在这个MIA量表上的效应近似等价于1+9×0.65=6.85份精确原文。这个解释依赖当次模型和训练设置的校准曲线。

可迁移的实验写法

先用可控、可解释的基线建立量纲，再把复杂现象映射到同一量纲；这比只报一个高低不同的AUC更能回答“到底相当于什么”。

Design 3：把“重复”拆成四种可控变化展开细节
生成模糊副本的方法改变什么想排除的解释
Token replacement随机替换R个原始Token共享字词变少时记忆如何衰减
Noise insertion在完整n-gram之间加入无关Token噪声打断局部片段后是否仍记忆
n-gram shuffling保留块内顺序但改变块的排列原始整句词序是否必需
Semantic replacement / paraphrase保留意思但换掉部分措辞，或让指令模型改写是共同意义还是共同字词主导记忆

作者还改变初始学习率、模型规模、Canary采样温度和成员推断方法作为消融。注意：模型参数和语料条件不变，并不意味着所有模糊处理都保留完全相同的Token长度或训练成本，实际比较需看对应实验的固定项。

哪些问题还没解决

Discussion：它证实了什么，仍有哪些边界？展开细节
  • 已证实：Member原文出现时，模糊副本继续增强MIA可检测的原文记忆，部分条件还增加续写抽取风险；精确去重不足以覆盖所有模糊重复。
  • 没有单独证实：训练从未包含完整原文时，模型仅靠碎片一定能准确还原从未见过的整段文本。
  • 没有直接验证：LLM通过这些材料获得新的解题规则、跨题迁移或多轮参数更新后的净能力保持。
  • 没有证明：只要语义相同就一定能记忆，或者所有语义记忆都不存在。
  • 现实数据结果是针对高精确重复文本的样本与5%扫描外推，不是整个语料的随机平均。
Nature Communications的直接价值

把模糊重复记忆做成一个受控现象，使用精确重复校准、不同扰动轴和真实语料交叉验证，为隐私、基准去污染、数据处理及机器遗忘指出现有做法的不足。

P0：词面重合 × 规则是否新增

实验设计：从同一模型检查点分叉，构造词面重合高/低 × 是否引入新规则的四格训练材料，固定题数、反馈、LoRA与总Token/梯度步数。

决定性证据：若低词面重合组只是记住同一规则，而高词面重合的关键反例反倒带来新规则迁移，就证明文本距离不能替代真实学习价值。

P1：三个独立终点

实验设计：分开测原文记忆、未见同规则/新规则题、经历其他任务更新后的旧能力保持。任务族按根规则拆分训练、诊断和测试。

决定性证据：只有在撤去教师和训练上下文后，新规则题正确率有独立净提升且旧能力不显著受损，才将其记为RSI能力增长。

Stop：与简单去重和规则分组对比

实验设计：比较完全重复去重、n-gram/MinHash近似去重、已知规则模板分组、随机等预算训练，不立即训练复杂新颖性估计器。

决定性证据：如果简单规则分组已解释全部收益，则只保留现象和审计方法；复杂调度器没有必要。

最重要的一句话

文字不一样不代表知识不同；知识不同也不代表已经学会。RSI新颖性必须最终回到未来独立能力的净增长。

01 · Challenge

难在哪里

在原目标上进步很快，可能只是找到局部有效的动作技巧；只看训练曲线无法知道是否掌握了真正的旋转规则。

为什么越容易做对训练题，反而可能越不理解规则？展开细节

想象电脑光标的运动方向被统一旋转 60°。你可以记住“这个特定目标往左偏一些就能打中”，但并不知道它为什么有效。若只考原来的位置，局部平移技巧和真正旋转规律可能都能通过。

先看同一错误的两种解释

H1：鼠标与光标方向相差固定旋转角；H2：光标仅被平移某个距离。训练位置很近时，两种解释可能都说得通；但换一个远方向，预测会分开。

02 · Insight

为什么可解

让不同训练位置排除错误的平移/镜像解释，并用没有反馈的新位置检验，就能区分局部成功和规则迁移。

学习难度还不够：任务能否区分竞争规则才是关键展开细节

如果两个目标离得近，参与者很容易找到一个在这些位置有效的局部技巧；当目标离得远，这种技巧更容易失效，迫使学习者尝试、排除不同解释。难点不是“错误越多越好”，而是反馈能否帮助区分什么规则才成立。

与 p≈0.5 的区别 · 研究提案，不是原论文公式Same p(success), different rule discrimination → possibly different transfer

怎么理解：两组题训练正确率可以都接近 0.5，但是否能排除错误规则可能不同。因此不能仅由成功率决定训练材料价值。

边界：本文没有操纵 0.5；这是把其机制与 SOAR 的 intrinsic learnability proxy 对照后产生的 RSI 假设。

对 SOAR 的最直接启发

SOAR 的教师如果只奖励学生在生成题上约 50% 成功，可能选择许多可用局部捷径完成的题。值得另测这些题是否促使学生区分错误规则，但必须同难度、同预算配对再验证。

03 · Design

具体怎么做

560 人分两实验学习 60° 光标旋转；改变训练目标排列，并在不反馈结果的探针位置测规则。实验 2 进一步匹配探针距离。

观察什么随机探索/渐进纠错的简单预测假设检验的预测

评测设置：通过 von Mises 混合模型拟合圆周动作数据，以 BIC 选择模式数量。

尚不能推断：不能由角度峰唯一推断每一次的内在语言假设。

实验二 · 证据强弱

评测设置：八训练位置，两组最近训练点至探针均为 110°。

作者报告：组别×训练/探针交互 F=6.3、p=0.012；训练分布 JSD p=0.694，探针分布 JSD p=0.088。

能够支持：主要训练—迁移反转并非仅由实验一的距离差异解释。

尚不能推断：实验二也显著复现了实验一的全部分布差异。

不应写成“推翻强化学习”

作者在 Discussion 将假设检验视作 model-based RL 的一种可能实现；研究反驳的是“随机探索+平滑纠错足以解释全部策略学习”的简化叙述，而不是所有 RL。

实验一：两个目标相距 20° 与 140°，为什么足以产生差异？展开细节
  1. 设定隐藏规律

    给 280 名参与者施加 60° 光标旋转，末端反馈延迟 1000 ms，以强调显式策略调整。

  2. 操纵训练约束

    140 人训练目标很近（20°），140 人目标相距远（140°）。目标位置与扰动方向在参与者间平衡。

  3. 加入不反馈的新目标

    每轮两次训练位置反馈后，安排一次橙色探针位置；探针不给当前结果。这样训练成功和真实规则迁移成为两个不同测量。

这是两种规则的预测解释，并非对个体真实思维的直接观测。
情形训练位置可能表现无反馈新位置预测
学到局部平移技巧可能很快成功可能在新方向偏离正确 60°
学到整体旋转规则不一定最先成功更有可能将 60° 补偿迁移到新位置
实验二：为什么必须把探针距离对齐？展开细节

第一实验的内侧组训练点离探针更远（170°），外侧组更近（110°）。若迁移差异仅来自距离，不能说是规则选择。作者因而重新设计了八训练点实验，把两组最近训练点离探针的距离都设为 110°。

一个值得学习的科学论证动作

第二次实验没有简单增加参与人数，而是专门控制可能推翻第一实验解释的变量——探针距离。这比直接用复杂机制名称解释第一实验更有说服力。

为什么不能只用最终训练成功率筛学习轨迹？

同样在训练点达标，有人掌握可推广的整体旋转规则，有人只得到当前位置有效的动作技巧。对 I6，研究价值可能来自失败过程是否排除了一个错误规则，而不只看这次错误的严重程度。

01 · Challenge

难在哪里

已有课程论文分别用题目复杂度、模型信心、困惑度来排题，训练设置也不同，很难单独比较先后顺序。

同一题到底有多难？为什么现有论文对不上？展开细节

有的研究用推理步骤数量定义难度，有的看答案的模型概率，有的根据模型反复回答的正确率排序。同一道题可能步骤很多但模型已很熟悉，也可能步骤很少却反复时对时错。因此，不能用一个笼统的“难”字解释所有课程实验。

先用例子理解差别

十步计算题：模型 20 次答对 19 次，RS 高但 ACC 也高；三步概率题：20 次答对 10 次，RS 低却有最高 VACC。不同难度指标会把两道题排到不同位置。

作者真正控制的变量

主实验保持 20k 训练题、优化目标、LoRA 设置不变，只改变排序；SGC 分层实验则只用三分之一题库，是不同的实验。

02 · Insight

为什么可解

一题步骤多不代表模型不会；模型犹豫也不代表答案错。需要把难度分成五类并固定其余训练条件。

五类十指标：它们实际上问的是五个不同的问题展开细节
五类难度具体指标它想回答什么
① Problem DifficultyRS、SC、CD、ACC步骤多吗？符号复杂吗？理解难吗？模型答对几次？
② Model SurprisalSLP、TLP模型对完整答案和局部候选有多意外？
③ Confidence MarginLG第一选择比第二选择高出多少？
④ Predictive UncertaintySLE、TLE下一步 token 的概率分布有多分散？
⑤ Decision VariabilityVACC同一道题多次做，结果是不是忽对忽错？
为什么五类不可互换

ACC 越高意味着做对越多；LG 越高意味着首选更有把握；困惑度和熵高代表模型更意外或更不确定；VACC 在 p≈0.5 时最高。把所有指标统一“从低到高=从易到难”会误读结果。

五类共 10 项具体量。论文用 RS/SC/CD 辅助描述题面复杂度，用目标模型多次采样得到 ACC/VACC，并根据模型 token 概率计算 SLP/TLP/LG/SLE/TLE。不同指标包含的模型条件和测量成本并不相同。

03 · Design

具体怎么做

对 2 万道数学题计算五类难度量，做升序、降序、随机排序；用三个基座模型、五个数学基准比较。

① Problem Difficulty：步骤、符号、理解、答对率不是一回事展开细节

② Model Surprisal：模型觉得答案多“意外”？展开细节
指标怎么计算用人话解释

怎么理解：SLP 看已经生成的解答概率，TLP 看多个候选 token 的局部概率分布，两者计算对象不同。

③ Confidence Margin：第一选择比第二选择坚定多少？展开细节

假设生成下一 token 时首选 A 的概率明显高于次选 B，模型就比较“坚定”；若两者接近则犹豫。但是坚定可能也在自信地犯错，所以 LG 不是实际答题准确率。

Eq. (4) · LG / Logit GapLG = mean_t [log p(top1) − log p(top2)]

怎么理解：把有两个以上候选的位置的首选和次选 log 概率差取平均；LG 越高代表首选越突出。

边界：LG↓ 表示从高信心到低信心排题，不应自动叫“难题优先”；LG↑ 是从低信心到高信心。

④ Predictive Uncertainty：概率分布是集中还是分散？展开细节
指标怎么算区别

TLE · Token-Level Entropy单个位置的 top-5 token 分布熵局部这一步是否有多个差不多概率的候选
Eqs. (5)–(6) · 熵H(qₜ)=−Σᵢ qₜᵢ log₂ qₜᵢ ; SLE=Σₜ H(qₜ) ; TLE=H(qₜ)

怎么理解：分布越平，模型越不确定，熵通常越大。SLE 跨位置累积，TLE 观察位置上的局部不确定性。

边界：熵越高不一定错得越多，也不一定学习收益越大；SLE 和 TLE 数值不处于完全同样的计量口径。

⑤ Decision Variability：时对时错究竟意味着什么？展开细节

VACC 不看模型口头说自己多自信，而是同一题独立做 K 次，计算正确/错误的波动。一直全对或全错时 VACC 为零，一半对一半错时最高。

Eq. (7) · VACCVACC = p̂(1−p̂); p̂=0.5 时 VACC=0.25

怎么理解：20 次里答对 10 次，p̂=0.5、VACC=0.25；答对 4 次或 16 次，VACC 都是 0.16。它不能区分“太难”和“很容易”。

边界：论文 VACC 是训练前采样后固定排序，不是每轮更新 p 再选 p≈0.5 的 Online P50。

04 · Result

结果怎么样

没有一种排序普遍最优。VACC 高值优先在 15 组方向比较中赢 12 组，但不代表全都胜过随机。

训练控制是什么：一样的数据，只改变排列顺序展开细节
  1. 固定 20,000 道数学训练题

    从 MetaMathQA-40K 中随机抽取 20k；不引入新的题目，测试集中包含 MMQA、ASDiv、GSM8K、MBench、MATH，每个 512 题。

  2. 使用三个非指令微调的基座模型

    Gemma3-4B-pt、Mistral-7B-v0.3、Llama3.1-8B；LoRA SFT 3 epochs，训练目标与预算固定。

  3. 比较指标升序、降序、随机

    分别按同一个指标从低到高、从高到低排题。分档 SGC 则只取一档 1/3 训练，与等数据量随机子集比。

数据顺序与数据子集别混报

主表只改同一批 20k 样本的排序；Figure 2 的 SGC 使用不同难度子集。后者证明“选什么样的题”有关系，并不能直接证明“同一批题如何排”有同等效果。

难在哪里

学生在一类数学题上128次采样全错，直接RL很难得到有效奖励；怎么靠自己生成题目继续学习？

Introduction：不会做的难题，真的完全学不了吗？展开细节

当RLVR对同一道数学题采样很多次都无法答对时，二元正确性奖励几乎不提供组内差异，直接优化会陷入平台期。SOAR用fail@128数学题制造这一研究场景：初始模型在固定采样协议中128次都答错，但并非真实正确概率严格为0。

生活化解释（本站构造）

模型不会一道复杂组合数学题，但能生成基本计数、简单递推和局部恒等式的练习。教师的能力不必等于最终解题能力；中间题若能改变Student参数，就可能让原本困难题出现成功轨迹。

论文的科学问题

在不提供新的人类编写的中间题的情况下，模型能否通过生成训练材料，突破自身在已有带标准答案的困难问题上的RL停滞？

02 · Insight

为什么可解

模型可能不会直接解难题，却已具备生成有用基础题的知识；当前成功率不等于训练后的真实收益。

Insight：出题能力可能先于直接解难题的能力展开细节

作者提出潜在教学知识假设：预训练模型即使不能完整求解某道高难度题，仍可能包含生成其基础子题的知识。有效训练题可以把Student的采样/梯度信号引入新的区域，让困难题开始产生非零有效反馈。这里强调的是“可学习性边界”而非仅从同题多次采样提升pass@k。

区别它问什么SOAR的处理
当前难度学生现在做这道生成题有多大概率成功作为Intrinsic对照，而非教师主目标
课程真实收益学生练这组题后，在真实困难题上是否多做对Grounded Reward，驱动Teacher更新

SOAR真正的新意

不是首次让教师和学生双边训练，也不是首次按成功率选题；它使用真实Student更新的困难题收益作为外层出题奖励，验证有用中间题可从预训练教师中学出。

03 · Design

具体怎么做

教师每轮生成4组各64道题；学生从同一检查点分别试训，按真实困难题准确率增益奖励教师，并在增益足够时晋升学生。

Method §3.1–3.3：双层Meta-RL分别更新Teacher和Student展开细节
原文 Eq.(1) · Bilevel Optimizationmax_φ E_{X~π^T_φ}[R(π^S_{θ'(X)}, D_train)]，s.t. θ'(X)=RL-update(θ,X)

怎么理解：Teacher采样一组训练题X，Student从当前固定快照用X做真实RL更新；外层优化的是更新后的Student在真实困难题上的表现，而不是Teacher自己的答题分。

边界：每次生成的Student只是局部分叉；除Promotion外，不把每次试训得到的Student永久累积。

  1. Teacher提出候选

    每个外层RLOO步生成g×n=4×64=256条可解析的问答，再分为4组各64题。

  2. Student分别试训

    对每组从同一Student基准分叉，用RLOO训练约10步（随Student晋升可加长），各重复r=4次。每个外层步需16次Student试训。

  3. 抽样真实困难题打分

    从D_train选64道fail@128真实困难题，计算更新前后的贪心准确率差；对4个Student重复取平均，作为这组训练题的奖励。

  4. Teacher更新并决定Promotion

    外层RLOO用四组相对奖励更新出题策略；若近3步平均奖励超过阈值，才接纳最优组的中位奖励Student作为下一基准。

组奖励而非逐题价值

64道生成题分享同一组平均收益。论文验证了一个题集是否有用，并未严格识别组内每道题独立的边际学习贡献；这与I6固定失败轨迹价值的研究有本质差异。

Grounded Reward：为什么必须真实训练学生？展开细节
原文 Eq.(2) · 课程收益R(X_k)=Acc_greedy(S'_k,Q_R) − Acc_greedy(S,Q_R); R_k=(1/r)Σ_j R_(k,j), r=4

怎么理解：在同一批随机抽出的64道真实困难训练题上，比较学生参数更新前后的贪心解题率，四次独立试训平均得到课程奖励。

边界：Q_R来自真实困难训练集，不是最终冻结测试集；它能对齐当前目标，但会成为被Teacher反复优化的奖励信息。

Teacher本身不看到真实困难题内容，只收到由学生试训产生的标量学习增益。生成题的数学答案不是预先用标准答案逐一严格验证。所谓grounded，是目标通过真实困难题的可核验成绩锚定，而不是保证所有生成题都正确。

有代价的强监督

在相同起点对课程做实际更新，比预测“这个题现在做对概率是多少”更接近目标学习收益，但每次Teacher更新要付出许多Student分支训练与诊断成本。

Promotion：临时试训什么时候变成下一轮Student？展开细节
  1. 计算三步移动平均

    在外层训练中，计算各候选数据集奖励的平均，再对最近m=3步做移动平均。

  2. 超过τ=0.01才晋升

    如果移动平均高于门槛，选择当轮平均Grounded奖励最高的64题。

  3. 选择一个代表性学生快照

    在该组r=4个试训Student中选择奖励处于中位水平者，而非最幸运的最优种子，以降低过度选择噪声。

  4. 保留Student与Promotion Questions

相同点：都认为课程应该基于学生实际表现，而不是只依靠固定难度顺序。

Related Work：SOAR已经覆盖哪些新意？展开细节
  • R-Zero、Absolute Zero、SeRL等已利用LLM自生成训练任务和各种内在奖励；SOAR的关键增量是把教师奖励接到真实Student的有限步参数更新及困难任务成绩。
  • 教师学会生成有效课程 ≠ 教师自己变得会直接解难题；Grounded-T直接推理约8.3%与它所生成课程训练Student达19.1%要分开说。
  • 与I2最近：它已经完成“Teacher从Student真实学习收益中优化、Student经Promotion成长”的双层闭环，不可仅改个教学标签再声称首次。
  • 与I6不同：SOAR奖励的是64题集合的联合收益，而非同一道错题的不同失败轨迹；二者可共享真实试训范式，但处理变量不同。
  • 与I8不同：SOAR发现答案正确性不能单独预测题集价值，未对同规则错误和规则级跨题迁移做固定反馈因果配对。
  • 与I9不同：SOAR对比合成/真实混合日程，没有系统研究“规则形成—规则辨别”状态驱动的跨主题切换。
参考文献与创新边界

SOAR不是首次自生成题目，也不是首次使用双层优化、教师—学生共同更新或学生学习进展信号。研究新意在具体外层真实收益奖励和稀疏数学任务上的有效实现；本研究站任何新方案都要避开这条已证实的主张。

E1：同一Student的短/长期收益排序反转

实验设计：同一参数检查点上，对每组候选课程做相同短内环真实更新，并保存分支；继续用冻结的同一后续任务流进行多轮其他知识更新，不改变教师与更新器。

决定性证据：比较短期奖励、独立新题迁移与后续旧能力净保持的排序是否反转；若一致，就不必引入更复杂长期预测器。

E2：控制Concept Diversity再比较Intrinsic/Grounded

实验设计：从两种Teacher各自生成题目，按类别/难度/题数/Token等匹配分布，固定Student训练和后测预算；不从最终测试反向挑题。

决定性证据：如果匹配概念覆盖后差异消失，则多样性可能解释大量收益；如果仍有差异，需要进一步分析题目结构与规则相关性。

E3：错误答案的真正因果贡献

实验设计：选择相同的well-posed题目集合，分别给正确答案、原生成的错误答案、无答案；统一学生更新器和预算，并报告题目数量和格式通过率。

决定性证据：只有同题同预算下准确答案状态仍改变跨题净收益，才能归因于答案是否正确；82题vs144题不能支持这个归因。

最后只保留一条问题

真实学生进步比内在难度代理更接近学习目标，但它仍依赖任务、模型阶段、内环长度、课程分布与评价窗口；值得研究的是何时能够代表未来可保留的能力，而不是再次发明“用真实收益训练教师”。

Discussion与投稿判断：这篇论文到哪里为止？展开细节
  • 论文有较强证据支持：学习不到的数学难题可以经自生成中间课程突破、Grounded教师比论文实现的Intrinsic对照更稳定、教育能力与直接解题能力可以分离。
  • 不能写成“模型0%可能性也能学会”：fail@128只是一次采样筛选；不同种子依然有小概率正确解。
  • 不能写成“完全无需外部监督”：真实困难题的标准答案与数学验证器用于Student训练/Teacher Grounded奖励，Teacher只是看不到题目的内容。
  • 不能写成“错误答案对学习越多越好”：原文比较同时改变82→144题的数量与概念覆盖，且正确率由Claude审查。

01 · Challenge

难在哪里

模型已学过正确答案，SFT 收敛后重新考试仍有约 15.3% 的训练样本无法稳定答对。只看训练 Loss 找不到原因。

训练 Loss 收敛了，为什么训练题还会答错？展开细节

论文研究的是“明明提供过正确监督，训练后还是不能稳定恢复”，不是一般意义上的未见题泛化失败。作者先把自由文本 SFT 问答转成四选一，原答案是正确选项、另外三项是干扰项；模型收敛后才重测。

Section 3.1 · 不完全学习的操作判据pass@N(x)=1/N × Σₖ 1[answerₖ correct]; unlearned if pass@N(x)<T

怎么理解：主实验采用 BoN-5 与 T=0.2，十个 SFT 数据集平均 15.3%±2.1% 的样本被归为未学会，随后挑选 1,000 条严重案例诊断。

边界：本论文 pass@N 写的是正确次数比例，和代码生成常用“至少一次成功”口径不同。多选题失败不直接证明原自由文本知识未入权重。

混淆在一起的三种情况本文有没有直接证明？
训练题重新做仍稳定错有：在转换后的多选题评估协议下测量
训练题做对却不会未见同规则题不是本文主要评测对象
训练新知识导致旧任务能力退化部分涉及：Left-side forgetting 的特定顺序训练实验
15.3% 的解释边界

它是训练后按指定重测协议筛出的失败比例，不是“模型有 15.3% 的参数知识完全没有学入”，也不是对模型长期新知识学习能力的普适估计。

02 · Insight

为什么可解

同样答错，可能缺基础、旧知识冲突、训练数据互相矛盾、先学后忘，或只是训练不够；不能统一多训几轮。

为什么不能把所有未学会题统一加训？展开细节
同样是训练题答错可能的真实情况该怎样进一步检查
基础知识缺失正确答案依赖模型原本不会的基础事实/概念独立前置知识探针与增补语料对照
与预训练旧知识冲突模型原先相信另一答案，并在 SFT 后仍偏向旧信念SFT 前后预测分布与冲突样本核验
SFT 内部矛盾相近问题有相反标注或多种答案位置重复/相似输入的独立标签审计
先学后忘训练开头学会，继续训练时被后期材料覆盖时间位置切片与重采样对照
优化不足稀有/复杂模式的梯度曝光尚不够递增 epochs 与独立验证集早停
原文最重要的科学观点

当前表现相同，不等于原因相同，也不等于下一次采取相同更新动作会产生同样的收益。五种模式是可检查的假设，尚未证明它们完全互斥。

03 · Design

具体怎么做

把训练样本转成选择题，重复测试找未学会样本；再检查基础知识、监督冲突和训练历史，针对五种模式分别干预。

① 缺基础知识：为什么再训八轮也难学会？展开细节

如果基础模型连目标概念的前置知识也不会，直接把一个复杂正确答案重复交给它，可能只能记住表面表达。作者使用原模型 zero-shot 的“知识存在”代理检查，先检索基础事实再引入相关语料做 CPT，然后继续原 SFT。

Eq. (2) · 作者用于判断基础模型是否“已知”的代理P_exist(x)=1[Acc(M_base(x))>0.8]

怎么理解：它根据基础模型在给定测试中的正确率，给知识状态一个粗略二值标签。

边界：原模型没答对 ≠ 参数里完全不存在相应知识。仍需不同格式和前置技能探针。

② 旧知识与新监督冲突：模型为什么坚持旧答案？展开细节

模型预训练时形成的答案可能与新监督矛盾；即使 SFT 提供正确选项，旧信念仍可能干扰。作者测基础模型与 SFT 模型预测分布之间的 JS Divergence，并采用 CPT 校准相关知识，再完成监督微调。

Eq. (3) · JS Divergence（分布改变的指标）D_JS(P_base || P_SFT)=1/2 KL(P_base||M)+1/2 KL(P_SFT||M); M=(P_base+P_SFT)/2

怎么理解：原模型与微调后模型对答案的预测分布差多少；Table 10 的相关分类使用 D_JS>0.3。

边界：分布差异不直接等于“知识冲突”；也可能来自提示格式或模型信心变化，需要独立事实核验。

哪些问题还没解决

这些是尚未解决的科学问题，不应当写成原论文已经证明的结论。

和我们的 I3 / I6 / I8 有什么关系？展开细节
我们的方向这篇论文已经做到什么仍要自己验证什么
I3：温故知新对先训练的旧数据做 shuffle + 重采样改善保持旧/新规则都正确但适用条件不同，是否能靠条件辨别训练同时保留
I6：失败轨迹价值训练结束后定位低通过率样本并给失败原因标签同一题、同一终点、同一个纠错方式，只改变失败过程后会不会产生不同迁移收益
I8：错误迁移区分前置知识、先验冲突与监督冲突，补救后恢复训练数据前置知识状态×错误规则范围×固定更新，在未见同规则题上是否有特异性净迁移
I8 应先做最小决定性实验

从同一模型快照分叉，匹配目标题正确率与训练预算。按是否具备前置知识与是否存在经人工确认的监督冲突分层，让各组分别接受普通纠错和相关知识补充后纠错。后测必须清空示范，分开测原题、同规则异结构新题和旧能力。

相关前置知识 × 干预方式交互实验

实验设计：同一模型检查点，Relevant CPT vs 无关等预算 CPT；两组再固定 SFT 更新器与目标错误。控制额外 tokens、训练步、正确答案与验证次数。

决定性证据：若只在缺前置知识的组中，相关 CPT 才特别改善未见同规则题，就更支持知识准备的机制解释；若两组增益相同，不能把 CPT 收益归因为特定前置知识。

区分 ILP 检测器和规则内化

实验设计：对同一批训练题同时使用四选一、自由文本等价判断、原始格式续写，并做不同难度干扰项对照。

决定性证据：若不同题型下的“未学会”集合差异很大，先修正诊断协议，不应直接用其标签调度 RSI 训练。

不要把题目学会与模型持续自我改进混为一谈

训练题重新答对只是最低层级的修复；未来同类题迁移、旧能力保持和下一轮还能继续学习才是我们的独立指标。I3、I6、I8 的核心变量保持不变。
