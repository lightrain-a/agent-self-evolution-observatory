RSI-Anything: Unlocking Recursive Self-Improvement with World Models

World Model 如何将一次真实试错变成下一轮能力改进？重点是预测、反馈、按需更新以及新旧组件的组合保留。

此页是本站研读记录。论文报告结果、教学示例、研究推断分开标注；未独立复现。

三句话记住

  1. 预测选候选不等于生成好候选：Policy 提不出的解法，World Model 不能靠排序找出。
  2. 真实反馈与预测版本绑定；证据不足时不能判断预测可靠，也不应机械更新。
  3. Policy、World Model 的独立进步不保证组合更好，接受新版本前还要检查配对行为。

01 · 研究问题与角色：到底什么才算递归改进？

在同一道题里反复修复，不等于系统能力持续提高。论文区分任务内的动作步 t 和系统更新周期 k：一次周期可以不接纳任何更新；只有被接纳的 Policy / Workflow 或 World Model 改变下一轮决策，才体现持久改进。

角色职责误区
Policy / Workflow（θ）生成候选、选择动作；可更新参数或持久工作流本题答对不代表 θ 已修改
World Model（φ）预测候选执行结果，接受真实反馈的校准不是最终真实评估器
Verifier / Evaluator约束可执行性、衡量任务指标、规定接纳门槛在实验协议中评价规则固定，不随 φ 同步自改写
  1. Propose → Predict

    提出候选，再由 World Model 预测结果或有限轨迹。

  2. Select → Observe

    依据任务效用和预算挑选真实执行对象；只为已执行对象记录预测—观测配对。

  3. Update → Retain

    依据反馈提出 Policy、WM 更新；组件及配对检查决定下一轮继承哪个版本。

证据边界

跨领域统一的是决策与反馈协议，不是七个领域共用一组通用世界模型权重（§2.1–2.2）。

02 · 公式 (7)–(8)：选哪个候选、哪些证据允许学习？

Eq. (7) · 预测效用与可选不确定性惩罚R_d(τ̂) = Σ_j w_(d,j) · r_(τ,j) − Δ_d(τ̂)

怎么理解：先按有效性与操作约束排除非法候选，再按预测收益排序；只有任务设置开启不确定性惩罚时 Δ 才非零。

边界：代码实验实际聚合五类执行结果概率，选四个补丁中的一个执行；不是简单地直接套用预测成功率。

证据层级是什么解释边界
E0确定性规则检查只覆盖明确规则
E1学习模型预测 / 想象轨迹不是实际执行真值
E2专用模拟器或高保真计算受模拟范围约束
E3外部测试或真实实验只覆盖真正被测试的候选
Eq. (8) · 想象轨迹准入e_τ = 1[v_τ=1] · 1[R_d(τ̂)≥r_min] · C_U(τ) · 1[ℓ_τ∈E_train]

怎么理解：通过合法性、预测效用、不确定性检查和证据来源限制的模拟轨迹，才可能进入训练。

边界：选择去执行谁与选择让哪些想象轨迹参与训练是两件事；未开启模拟学习时 D_sim 为空。

选择偏差

World Model 决定谁得到真实反馈；而这些反馈又用于训练下一版模型。被低估的好候选可能始终没有机会获得真实证据。

03 · 一个完整的代码修复算例（教学示意）

示例数字，并非论文运行记录

固定代码生成器生成四种补丁，假设不确定性惩罚系数为 0.5。该例只是为了说明候选排序；论文真实实验是五类执行结果预测。

补丁预测效用不确定性示例最终分数
A 修改边界0.350.100.300
B 改索引更新0.750.400.550
C 补充终止条件0.600.050.575（选择）
D 重写循环0.480.200.380
  1. 选择 C 并实际运行

    假设失败。只有 C 得到了真实结果，A/B/D 的预测不能当作已验证事实。

  2. 判断是否需要更新 WM

    “预测成功率 60%、实际失败一次”并不足以证明 WM 失准；要积累同版本预测—观测记录。

  3. 更新后仍须完整配对检查

    新 Policy、新 WM 单独更好时，最终系统也可能更差；不通过则继续使用旧组合。

04 · 公式 (10)–(12)：何时更新 World Model？

Eq. (10) · 三种可靠性状态ρᵂ_k ∈ {reliable, unreliable, insufficient}

怎么理解：从当前版本的预测与真实观测检查误差、校准和覆盖；证据不足不等于预测可靠。

边界：不能把旧版预测记录直接混入新版错误率；必要时用新版重算历史输入。

Eq. (11) · 适配触发uᵂ_k = 1[ρᵂ_k=unreliable] · 1[D_adapt 足够] · 1[B_update≥c_adapt]

怎么理解：同时确认失准、有足够修正数据、有足够预算，才尝试适配。

边界：长期没被选择执行的候选缺少反馈，既不能宣称模型准确，也未必能触发适配。

Eq. (12) · 提出新预测器φ′_(k+1) = Adapt(φ_k, D_adapt) if uᵂ_k=1; else φ_k

怎么理解：提出一个新版本不等于已保留；更新候选仍要经过后续的组件和配对接纳检查。

边界：Policy 和 WM 可以异步更新，但外部反馈消耗与训练/评估计算开销不是同一个成本口径。

05 · 公式 (13)–(18)：组件变好 ≠ 系统变好

Eqs. (13)–(16) · 组件检查Gπ = Qπ(θ′; θ, D_gateπ) ； GW = QW(φ′; φ, D_gateW)

怎么理解：分别检查新 Policy 和新 WM；若某组件未通过，仍使用它的旧版本与其他已通过组件组装。

边界：新 WM 平均更准确，不代表它对新 Policy 产生的候选也更准确。

Eqs. (17)–(18) · 配对检查与保留Gpair = Qpair((θ̄, φ̄); (θ, φ), D_compat); Gpair=0 则保留原配对

怎么理解：组合决策行为需要在预先设定、可比的任务与约束下检查；配对失败时整体回退。

边界：已有的是通用协议定义，不能直接视为充分的 Pair Gate 消融证据。

教学示例（非论文数字）独立指标 / 配对成功率解释
旧 P₀+旧 W₀任务成功率 68%基线
新 P₁+旧 W₀任务成功率 74%新 Policy 有改善
单独检查新 W₁Brier 0.40→0.32新预测器有改善
新 P₁+新 W₁任务成功率 64%组合变差，拒绝升级
最重要的机制洞察

新 Policy 改变候选分布，新 World Model 改变被选中接受反馈的候选。版本接纳必须从单组件得分推进到组装后真实决策行为。

06 · 各领域实验，到底各证明了什么？

代码修复 · 预测选择与适配的受控比较

评测设置：ReasonFlux-Coder-7B 固定；CodeContests 200 题×3 种子；每轮四候选选一执行，最多三轮。

作者报告：随机 26.0%；静态验证器 26.3%；固定 WM 29.2%；适配 WM 31.2%。平均在线测试调用 3.71–3.72 次/题。静态→固定 WM 排序准确率 66.5%→72.8%，Brier 0.488→0.358。

能够支持：预测器更会选、适配后还能进一步提升修复成功率。

尚不能推断：Coder 自身变强；总训练和门控计算费用完全相同。

GUI · 任务表现与动作效率

评测设置：MiniWoB++ checkbox 同一批 100 个实例；同时报告 OSWorld。

作者报告：成功率 51%→79%→99%；平均动作 5.30→3.21；OSWorld 相对初始 Agent 提升 18.4%。

能够支持：Policy 与 WM 的不同保留版本改善部分 GUI 任务结果。

尚不能推断：单独由 Pair Gate 导致全部提升，或在所有网页任务可复制。

实验室规划 · 连续 Policy 改善

评测设置：LabHorizon F200 Level-2，200 个任务，单个 4B Policy 的五个版本。

作者报告：规划得分 21.80%→38.03%→41.99%→44.56%→46.01%。

能够支持：连续 Policy 更新能提高所测规划指标。

尚不能推断：在相同任务里也完成多轮 WM 联合优化的独立证明。

化学实验 · 实测产率与预算

评测设置：Suzuki–Miyaura 的流动 LC–MS 筛选；BO 对照相同 40 次实验。

作者报告：平均最佳观测产率 96.15%，Bayesian Optimization 为 82.16%。

能够支持：在所报告的化学条件空间与预算内搜索更有效。

尚不能推断：任意反应或无限预算均占优。

免疫科学 · 研究假设生成

评测设置：工作流改进 + 状态预测 + 自我纠正的应用示范。

作者报告：形成拟开展实验验证的干预假设。

能够支持：完整研究系统可以串联多个领域能力。

尚不能推断：治疗有效性或湿实验已经得到证实。

07 · 科学贡献与证据边界

已有技术背景该论文的推进
MuZero、Dreamer：预测模型用于规划把预测纳入候选反馈分配及跨轮次系统更新
强化学习、自训练、Reflexion：利用反馈改进行为明确 Policy/Workflow 的版本继承和异步更新
常规校准与版本回退用预测可靠性、证据覆盖、预算和 Policy–WM 配对检查组织统一协议
合理的创新定位

更像“系统级自我改进协议 + 多领域验证”，而不是首次提出世界模型、基于反馈学习或检查回退。五类实验覆盖不同路径；论文也说明仍需单一任务中的长期联合多轮评估。

  • 即时排序无法生成原 Policy 从未提出的好解，也不能解决候选分布外的可靠性。
  • 只有被选中测试的候选提供观测，WM 可能持续低估某些正确但少见的方案。
  • 配对门控不等同于旧任务长期不遗忘，或恶意行为不会被写入记忆。
  • 评价标准在实验协议中固定；“评估器本身也会被改写”仍是开放问题。

08 · 接到我们的四问 + 安全：下一步实验应做什么？

延伸研究构想（非 RSI-Anything 原文结论）

Agent 能否预测“哪一次真实试错会让下一轮独立能力提升最多”，而不仅是“当前哪一个方案成功概率最高”？

我们的学习收益目标（概念式）V_learn(a) = E[Perf(θ_after | test(a)) − Perf(θ_after | matched no-test(a))]

怎么理解：与相同训练预算但没有该候选反馈的路径做对照，度量真实学习增益。

边界：不同于论文 Eq. (7) 的即时效用；需要来自相同检查点的受控训练和独立测试。

实验 A：即时成功 vs 学习价值

实验设计：固定代码生成器、更新机制及反馈预算；比较即时成功率排序与下一轮学习增益排序。

决定性证据：在独立任务上衡量 ΔPerf、负迁移、实际测试成本；小型诊断集全测候选，估计选择偏差。

实验 B：Pair Gate 的独立必要性

实验设计：由同一组更新构造 P₀W₀、P₁W₀、P₀W₁、P₁W₁ 四配对；有/无 Pair Gate 多轮对照。

决定性证据：记录“组件分别变好但组合退步”的频率、长期净增益和额外门控成本。

实验 C：I5 模型间交换舞伴

实验设计：从同一学生模型检查点，按最强伙伴、相近伙伴、随机伙伴、预测最高学习增益伙伴等预算学习。

决定性证据：独立测试中相对于无教师等预算学习的增益，以及随模型能力变化而发生的最优伙伴迁移。

安全与追溯要求

保留候选/预测/真实执行/训练准入/门控数据的版本归因，独立检验评估器被绕过、越权操作及有害知识持久化，而非仅凭提高当前分数宣布安全。
