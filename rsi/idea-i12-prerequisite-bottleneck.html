Observable Phenomenon｜为什么补一个基础知识，可能解锁一批原本学不会的任务？

I12 · CAUSAL PREREQUISITES · RSI · 2026-10-28

Discovering the Prerequisites of Self-Improvement

一个数学 Agent 有 30 道未能通过验证的复合规则题。重复纠正各题，更新后仍不能迁移。但这些任务可能共享一个它尚未真正掌握的前置规则。能否在不事先知道答案结构的情况下，通过少量失败诊断找出这个共同缺口，先补它，再让原本难以学会的任务获得有效学习信号？

不是先画一张知识图再推荐课程。我们研究的是一条前置知识关系是否在给定模型当前状态和固定更新器下具有可验证的因果作用：学会 P 后，学另一批任务 T 的未来独立学习增益是否提高。即使 P 与许多题相关，也不保证是必要瓶颈。

有没有新东西采不采得到吸收了会不会丢

主变量：修复哪个共享前置缺口。主要观察：同预算补完之后，下游任务是否从“无有效新增学习”转向“能获得可靠后续增长”。当前题目答对率、生成更多题和技能图检索成绩都只是辅助指标。

共同泛化专题｜前置补救为什么必须测第二阶段的真实学习增量？

泛化与未来可学习性总专题统一了I12的两阶段评测：先补前置知识P后直接做对T，属于Immediate Transfer；补P后使用相同训练器再次学习T，第二段独立增量超过等预算伪前置和直接练T，才支持Unlocking Future Learning。P2共同对照 → · 实验契约JSON。[E710][E401]

Challenge｜共享错误、相关知识与真正因果前置，不能混为一谈

C1 · 一个规则出现得多，不一定补它就有用

高频公式、图中 hub 节点、语义相似的技能，可能只是共同被提及；模型其实已经会了它，或失败的真正原因另在别处。要用同预算的真正前置 vs 高频但非前置对照排除这一解释。

C2 · 同题解出，不代表下游变得可学习

预先给出关系图或在上下文放入口诀，可能立即提高准确率，却没有让模型独立学会后续任务。必须从同一检查点做真实 Skill/LoRA 持久更新，撤除资料、提示、外部图谱后再观察下一阶段的更新。

C3 · 先学前置与额外花更多预算容易混淆

如果 P 组额外练 1000 token，T 组只练目标题，再好的成绩也无法归因于前置结构。主实验固定总 Token、优化步数、验证调用和元诊断预算，并把节省出的资源允许强基线继续直接练 T。

C4 · 先修关系可能是状态依赖的，而非绝对真理

对弱模型，P 可能是门槛；对已经掌握 P 的强模型，它可能无增益。题面换一种写法也可能不再依赖 P。需要同时构造真正依赖 P、表面相似但不依赖 P、以及模型已会 P 的负对照。

Nature 证据｜学习“结构骨架”与真正的规则先修有什么区别？

Ren 等，Nature Communications 2026，Compressive learning scaffolds higher-order network structure to enhance human knowledge acquisition：在人类 16 节点图片转换网络中，先用同频率、不同顺序的 HubToLeaf 预学习路径突出高阶枢纽结构，然后学习相同的随机游走序列；实验二有 238 名参与者，HubToLeaf 的后续网络学习更好；另有 MEG 和计算建模支持网络结构表征的解释。[E401]

能借鉴：先利用有代表性的共享结构建立学习骨架，后续碎片经验可能更容易被整合。不能照搬：论文操纵的是节点度分布与网络路径顺序，并没有在数学任务中验证“某条规则是掌握另外十条规则的必要知识”；高连接度不等于因果先修，不能直接推出 I12 有效。

LLM 最近邻：SOAR（ICML 2026）已通过真实 Student 试训收益学习生成中间题；ACL 2026 Why SFT Fails to Learn 已研究缺少前置知识导致训练无法吸收的案例；CoT 组合泛化工作已证明简单技能可组合成复杂规则。I12 的问题不是首次提出桥接任务、知识图谱或组合学习，而是主动发现哪些前置补救可以解锁一批任务的后续可学习性。[S47][M27][S406]

碰撞结论：图、桥接课程、Self-Play 和按学习收益选训练数据均不是新颖性；唯一待检验的科学关系是模型知识状态 × 共享前置因果效应 × 后续学习范围。

Insight｜失败背后可能存在共享、状态依赖的“学习瓶颈”

待检验机制：多道表面不同的失败任务，可能依赖同一个当前尚未掌握的中间规则 P。直接反复训练目标题 T，学习梯度缺少必要基础而无法形成可迁移能力；若先真正学会 P，后续 T 的有效纠错信号可能显著增加。不是因为 P 在图上连接多，而是因为当前模型的状态发生了足以改变后续训练收益的变化。

例如多个代码程序题都调用二维坐标变换。模型可以背诵具体 API 但不理解坐标系复合与逆变换，导致多题失败。对一组明确依赖变换组合的任务，补好组合规则可能让后续学习发挥作用；对结构相似但只需常数映射的任务则应没有对应作用。这个例子是机制假设，不是实验结论。

因果桥接与知识迁移的区别：只学 P 后能做对一部分 T，叫直接迁移；先学 P 再训练 T，比相同预算的对照更能学会原先不会的 T，才是我们关心的“解锁下一轮学习”。两者都测，但不能混称。

定义｜前置知识的价值应由“后续学习增量”而不是相关度确定

令 θ 是当前模型检查点，U_P 表示用固定预算补前置候选 P，U_T 表示随后用固定更新器学习目标任务族 T，B 是总成本。独立评估在未见 T 测试集进行且清空训练上下文：

V(P → T | θ, B) = [Acc_T(U_T(U_P(θ))) − Acc_T(U_P(θ))] − [Acc_T(U_T(U_C(θ))) − Acc_T(U_C(θ))]

C 是等预算对照（如高频但非先修规则、直接练 T、普通 stepping-stone 或随机技能）。前后两组都真正学习 T，因此 V 衡量的是前置补救使后续 T 变得更易学习的增量，而非补 P 本身的即时作用。第一层的 U_P 和 U_C 必须有匹配的 token、反向步数、验证成本；总预算包括模型的规则诊断和候选筛选。允许负 V。

当某任务族在原模型上多轮给定预算 U_T 仍几乎没有提升，但 P 补救后其 U_T 的增量稳定转正，我们将其记为一个被解锁的学习机会；不可用一次 zero-pass 或一个随机种子就判定原任务绝对不可能学习。

潜在学习范围（Unlockable Frontier）：在预注册候选任务族集合 F 和统一预算 B 下，统计获得具有置信支持的正后续学习增益的族数/比例，同时报告全体加权净收益、负迁移和未受益的族。它是有限评测集合上的操作性指标，不声称突破模型理论能力上限。

负对照：不依赖 P 的 T_neg、已经掌握 P 的 θ_prepared、只把 P 放在 Prompt 而不更新、同样频繁但非前置的 P_hub。若这些条件同样提升，则应改写机制解释。

Design｜诊断多题共享失败，选择最有因果潜力的前置补救

任务族失败簇已有验证器与失败轨迹
提出候选前置 P共享子规则 / 已知依赖 / 互斥对照
廉价试验判真假探针 + 同预算学习分叉
补救并持久更新固定 LoRA 或 Skill，记录版本
后续独立学习 T固定更新器，撤辅测增益

1. 不预先假定前置图一定正确

在合成环境中，任务生成器的程序依赖关系可作为外部真值；训练时 Agent 不能直接读取该图，而是根据多个失败任务的验证结果提出少量候选缺口。额外设置“语义相关但实际不必要”的伪边和高连接节点。实际数学与代码任务的前置关系由人工/程序依赖规则审核，不能仅依据 LLM 自报知识图。

2. 轻量诊断必须先于正式补救

对每个候选 P 先运行前置技能的独立探针；在开发集上对少数 P 进行匹配起点的小预算分叉，确认是否可能改变后续目标学习增量。分叉只使用开发/探针数据，绝不读取最终测试；不能把观察到的错题答案反向当作“先修图标签”。

3. 固定训练器与验证器，仅改变 P 的选择

首轮固定一个 LoRA 优化器、统一反馈格式、同一类 T 更新任务流；不同策略选择随机 P、按频次 P、按图度 P、按语义相似 P、按直接难度选任务，或按候选因果效应选 P。补完之后均学习相同数量的 T，且全部测试在撤除 P 文本后进行。

4. RSI 的递归性要来自“新学习机会”

如果补 P 后某个以前学不会的 T 可学习，模型可能获得解决更复杂任务所必需的规则。下一轮再次从尚未解决的任务中诊断新的共享瓶颈，但不允许用新的验证器、外部答案、更多专家调用冒充递归增长。首版只需两层合成依赖链，确认后再做多轮。

与 I1–I11 的边界｜只研究“先补哪种共同前置缺口才能解锁后续学习”

已有 Idea已有研究的变量I12 保持的边界
I1知识内化还是外查固定 LoRA 为更新面，不能把外部 graph retrieval 的帮助冒充学会。
I2针对同一学生的教学动作和教师教学能力固定教师反馈形式，不优化怎样讲课。
I5十模型互教、伙伴更换使用单个学习者与固定的知识来源，不换教师伙伴。
I6同一道题哪条失败过程最值得纠正多任务共享前置诊断，固定每道题失败采样数与选择规则。
I8纠正一个当前错误后能迁移多少同规则题补一个前置知识后，再让多个不同任务分别继续学习，测 T 的后续学习增量而非 P 的直接迁移。
I9固定材料、集中与交错的排列/顺序不优先研究学习顺序效应，主要变量是选择哪个必要前置 P；材料数量和学习顺序作匹配。
I11同一反馈的情绪性语言固定中性反馈，不改变语气。

交叉使用数据可以，共享新颖性不可以：I8 发现“模型缺 P 时某条错误不容易纠正”，并不自动证明“补 P 能解锁很多不同任务之后的学习”；I12 需要额外的前置补救 × 多任务后续更新交互。两篇可以共用技能标注与测试脚本，但研究问题和终点分开。

P0｜最小因果实验：一个前置缺口，是否真的让多题“变得可学”？

先小规模、可失败：固定一个 1.7B / 4B 预训练模型及 LoRA 训练器，在程序化构造的规则 DAG 中选择 4 个前置规则 P，每个 P 连接 6–8 个不同的下游任务族 T；同时产生相同出现频率但不构成先修的高频节点 H。合成任务由独立程序验证，训练时不提供真实 DAG。具体任务数与预算是首轮候选设置，不是既有实验结果。

分支第一段训练第二段训练为何必要
A · 真前置补 P同一批 T测前置学习能否改变后续 T 更新响应
B · 高度相关但非先修补语义相关、频繁出现的 H相同 T排除频率、语义相似和 hub bias
C · 直接练习更多直接 T 练习（等预算）相同 T排除更多训练/熟悉题型带来的收益
D · 普通中间题SOAR 式难度与真实短程增益选题相同 T排除只是选择了容易吸收的练习题
E · 已会前置负控对已掌握 P 的匹配模型补同样 P相同 T检验价值是否随当前知识状态消失

成功条件：对于真正依赖 P 的任务，A 的第二段独立增益显著超过 B/C/D；对于不依赖 P 的任务和已掌握 P 的模型，这种差异应减弱或消失。若 A 只是第一段就让 T 变好、第二段学习增量无优势，说明是直接迁移，不是“解锁后续学习”。至少 3 个独立训练种子和多个规则族；按族、种子聚类区间，不能把单题重复采样当独立实验。

P1｜真实未知图：从失败簇发现 P，而不是用预知答案选 P

P0 使用真实依赖图作为判定外部真值，但下一阶段必须遮蔽图，避免“方法”只是从答案里挑正确 P。将失败任务的可见报错、失败中间步骤、当前技能探针作为输入，让诊断器提出最多 K=3 个候选 P。

本研究候选因果前置未证实的 I12 假设额外的便宜试验是否以更低成本挑出能解锁多个 T 的 P。

数据隔离：提出 P 的训练样本、开发候选试验、最终 T 后测必须按规则 DAG 模板和任务族分开。诊断准确率是辅助指标；最终在同一预算下的多任务后续净学习增益才决定方法是否有效。对候选的每一次试训与验证都计入完整元成本。

P2｜跨轮 RSI：一次基础补救能否带来下一轮更多自主改进机会？

从 P0/P1 中确证的真实前置干预开始，构造至少两级依赖链：P₁ → T₁ → T₂。每轮 Agent 根据已有失败提出候选 P，经过固定验证器检查，使用相同预算选择一项补救、更新 LoRA，然后再尝试以前无法有效学习的目标任务族；如果解锁了 T₁，则下一轮检验是否帮助 T₂。

冻结任务生成器与评估器。首版只更新学习者 LoRA 与经版本门控的技能诊断记录，不让任务生成器、校验器、外部题库同时变强；否则与 SOAR / Skill Self-Play 的共同进化机制混在一起。上轮解决过的任务只用于回归测量，不回流为最终测试答案。

两个任务领域：先用程序化数学规则确保先修因果地位，再用可执行字符串/列表操作或代码单元测试的组合依赖复核。只在合成任务出现稳定“解锁”现象后扩大模型规模，不将 synthetic benchmark 上的优势直接宣称通用代码能力。

报告：每轮原本无进步的 T 族中转为正后续收益的比例、全班（单学习者多个任务族）独立能力曲线、旧任务回归、总 FLOPs、诊断误判率；同时给出被错误诊断的失败案例。若只提升一次性准确率而后续轮次没有扩大有效学习范围，则保留局部课程结果。

评测契约｜如何避免把“补基础”误报为“递归能力上限增长”？

指标操作性定义防止的误判
Post-Prerequisite Learning Gain第一段补 P / 补 C 后，第二段学习 T 的独立准确率增量之差只测第一阶段就变好的直接迁移
Unlocked Task Families在预定 T 族中，原本固定预算无可靠进步，补 P 后可观察到可靠正后续学习增量的数量单个 pass@k 为零就断言绝对不可学
Old Skill Regression原来答对的独立旧任务在补 P 和学 T 后变错的比例新能力增加掩盖旧能力遗忘
Prerequisite Diagnosis Precision候选 P 是否对应人工或生成器可验证的真实依赖；另报告因果试训验证率语义相关图边误认必要前置
Total Budget所有试训、候选提出、验证器调用、LoRA 更新、生成 token 与 GPU 时间诊断器多花计算获得假优势
Frontier Curve累计总算力下，每个阶段独立新任务族净收益的轨迹及 AUC某一阶段走运，长期并未持续改进

主对照随机化：每个模型与任务图检查点，随机分配真实前置、伪前置和直接学习；更新器相同，使用成对数据流和多个模型种子。预注册主要 estimand 为第二段学习 T 的增量与组别交互，而不把探索中“效果最好的一批规则”当作全体结论。最终测试只由独立评测器持有。

Go / Merge / Stop｜什么结果真正值得把 I12 写成独立论文？

判断必要证据后续处理
GO：独立 I12缺 P × 真正依赖 P 存在稳定交互：补 P 后学习 T 的增量提高，且超过相关高频节点、直接练 T、SOAR 风格中间题等预算强基线；诊断器能从未知图有效发现 P，并跨任务族复核。再扩展至多轮 RSI，证明后续有效学习任务范围持续扩大。
MERGE：回归 I8 / I9补 P 只提升原目标题修复、同规则迁移或课程排序效率，却没有额外的后续 T 学习增量。把证据并回 I8 错误迁移或 I9 课程机制，不包装独立“解锁”方法。
STOP无从区分真实先修与语义相关，高频节点同样有效；收益来自更多试训预算或验证器泄漏；不同种子无稳定作用。停止独立方法推进，保留负结果与消融。

论文结构候选：Observable Phenomenon（多个失败共享瓶颈）→ Challenge（因果先修难发现）→ Insight（补 P 改变 T 的未来可学习性）→ Design（少量因果探针）→ E0/E1/E2（独立学习增量）→ 失效边界。不要写成大型知识图谱平台或多 Agent 工程系统。
