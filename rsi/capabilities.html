本章科学问题

如何把经历变成以后能够使用的能力？

从实例形成规则与技能，在外部状态中保存和调用知识，将经验巩固到参数，协调外部支持与内部学习。

按主要科学贡献归档；方法、能力载体和组织方式分别描述，其他功能中的作用通过交叉引用连接。

5.1 从具体经历形成知识

原始实例、抽象规则、程序和技能保存不同层次的信息。应检查抽象保留与丢失了什么、规则是否记录适用条件，以及所得知识能否在新情境中复用和组合。

要回答的问题：系统学到的是某个答案、局部操作，还是可复用的关系？

5.2 在外部状态中保存和使用能力

情景记忆、语义记忆、技能库、提示和工具代码可以形成持久系统状态。需要把写入内容、组织方式、调用条件与后续实际行为的变化联系起来。

要回答的问题：什么内容值得保存，何时调用，怎样判断调用确实有帮助？

5.3 将经验巩固到模型参数中

监督微调、蒸馏和强化学习是不同的能力更新方法。比较时记录学习信号、训练信息、预算和学习者状态，并用未见任务检查形成的能力。

要回答的问题：什么条件下，经验能够经由参数更新形成可迁移的能力？

5.4 协调外部支持与内部学习

同一经验可以保留为实例、压缩为规则、写入技能或用于参数更新。选择取决于知识准备、任务变化、调用成本和修订需求。移除外部支持的测试帮助定位收益保存在哪里。

要回答的问题：哪些经验值得内化，哪些适合继续查询，两种方式何时相互促进？

代表工作 · 机制与证据

代表工作主要解决的问题已有研读记录与证据范围
R²Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop [S26]自博弈经验先提炼为技能，再巩固到参数并撤去支架。通过自博弈将经验蒸馏为技能再内化进参数；以撤掉技能后效果是否保持决定 Skill Withdrawal。I1 研究何时该内化、何时保留外部支持。
Rote Learning Considered Useful: Generalizing over Memorized Data in LLMs [M24]先记忆关系再赋予语义，检验记忆向可用知识的转换。Wu 等：先用无语义 token 记关系再以少量示范学习自然语义；在语义事实调用上有效，但两跳生成仅0.14→0.36，多选0.08→0.16；ICL直给两条事实为0.95，信息访问条件不同；推理拓展属于初步证据。
The mosaic memory of large language models [M17]解释模糊重复怎样形成参数中的文本记忆。Shilov、Meeus、de Montjoye 在4个模型上用200条100-token canary、成员推断AUC及精确重复等效系数ρ测量模糊副本对原文记忆的贡献；替换10% Token时ρ约0.60–0.65，替换50%仍约0.13–0.19；语法词序重叠影响强于语义一致；SlimPajama高重复文本中仍有大量模糊重复。主指标是记忆风险，不直接证明RSI中的新规则学习或持久净增益。
Hybrid neural–cognitive models reveal how memory shapes human reward learning [E370]用历史潜状态表达记忆，解释多时间尺度奖励学习。Eckstein等用862名参与者、4134区块、617871有效试次比较六参数Best RL、RL-ANN、Context-ANN与Memory-ANN。保留参与者行为预测指标BestRL60.6、RLANN60.8、ContextANN65.4、MemoryANN68.3；独立历史潜变量能解释奖励/动作的多尺度效应，但不验证LLM参数持久学习或RSI。
Human-like systematic generalization through a meta-learning neural network [E350]通过跨语法元训练形成词汇组合能力，另检验结构外推边界。Lake与Baroni用多解释语法episodes元训练Transformer，词汇组合SCAN/COGS大幅优于基本Seq2Seq；20%人类式错误监督为模拟人类行为分布，Table1并非正确率；Table2为组合泛化错误率，SCAN Length及COGS新结构错误率100%；新episode测试权重冻结。
Learning produces an orthogonalized state machine in the hippocampus [E353]研究学习如何形成可区分潜在状态的表示。11只小鼠在230cm VR 2ACDC任务中学习近/远奖励，长期CA1数千神经元活动逐步按潜在状态去相关，CSCG复现最终状态及形成顺序；常规LSTM/小Transformer能序列预测却不自然形成相同OSM。该结果不证明大LLM必须正交化。
Trace2Skill: Distill Trajectory-Local Lessons into Transferable Agent Skills [S31]从多条执行轨迹抽象可复用技能。并行分析多条执行轨迹，归纳为可复用且尽量无冲突的技能。I4 不是再次强调多轨迹，而是决定何时需要追加辨别实验、何时证据足够归纳。
From Memory to Skills: Evidence-Grounded Governance for Long-Horizon LLM Agents [M534]以证据和适用条件把episode提炼为可调用技能。MSCE以证据链接、适用条件、反思值回填将episode经验转成可调用skills；比较时分别检验完整Memory/Skill系统的迁移与保持收益，以及经验巩固到参数后的独立收益。
