CHAPTER 03 · RSI LEARNING MECHANISMS

When Does Another Example Matter? · Rule Disambiguation and Learnability

I10 · 什么样的练习才能让模型真正学会规则？

主归属 · 经验获取关联 · 能力形成关联 · 学习信号

从 Mosaic Memory 的模糊重复出发，I10 聚焦同一规则内部的关键区别：有的样本反复强化已有捷径，有的提供排除错误规则的新证据；但有区分信息不等于模型通过参数更新学会了可迁移的正确规则。主线为规则区分信息 × 模型可学习性 × 当前掌握阶段。

Observable Phenomenon｜同一条规则，为什么有些练习只强化捷径？

泛化专题入口：从当前表现到真实掌握，再到未来可学习性。I10仅操纵区分信息D与组合覆盖K，检验真实规则内化；不能仅凭这一步声明模型下一轮会学得更快。共享P0规则分歧实验 →

一句话：模型连续做对十道不同的题，仍可能依靠一个恰好在训练分布里成立的错误捷径。新的一道题即使题面很像，却可能让正确规则和错误捷径给出不同答案。I10 想知道：这道题提供了能区分规则的证据吗？即使提供了，模型能否通过真实参数更新把它变成可迁移能力？

重复巩固

数字、叙述不断变化，但正确规则与捷径在所有训练题上的答案都相同。模型更熟悉这些题，却仍不必识别真正起作用的变量。

规则区分

只改变一个关键条件，就能让正确规则和错误捷径给出不同结果。这个样本可能比十道表面不同的练习更有用，也可能只被模型记成一个例外。

状态依赖

模型尚未形成规则、已经习得局部捷径、真正掌握规则时，对相同区分性证据的吸收能力与边际收益可能不同；这是待验证的交互效应。

与 I6 / I8 / I9 的正交边界：I6 固定题目比较不同失败过程；I8 研究纠正哪种错误能迁移更多题；I9 固定材料研究跨主题练习顺序。I10 固定模型起点、更新器、教学反馈和练习顺序，改变追加样本是否消除现有规则歧义，再在独立新题上观察实际参数学习。Mosaic Memory 提供记忆研究起点，不是该机制已在 LLM 中成立的证明。

论文起点｜Mosaic Memory 发现了什么，又没有证明什么？

The mosaic memory of large language models，Shilov、Meeus 与 de Montjoye，Nature Communications 17，Article 2142（2026）[M17]。在原文加九个模糊变体的继续预训练中，作者用成员推断 AUC 校准“相当于重复原文多少次”的 ρ。替换约10%的 token 时，ρ 约0.60–0.65；替换50%时仍约0.13–0.19；重叠的词面结构比语义一致更能解释记忆效应。

不能越过的证据边界：原始 canary 在训练中本来就出现一次；ρ 衡量的是对原始文本的等效重复记忆，而不是训练准确率或规则泛化。作者没有证明“不同样本不提供新知识”，更没有验证 LLM 的自我改进策略。I10 把这一点作为需要实验检验的动机，不能把论文的隐私风险指标直接当作 RSI 的学习增益指标。

另一个必须同时看待的结果是 Data Repetition Beats Data Scaling in Long-CoT Supervised Fine-Tuning（2026年2月预印本）：在报告的固定更新预算实验中，400条长推理样本训练128轮，比51,200条独立样本训练一轮更好；token 准确率接近完全记忆时，进一步重复的泛化收益趋于饱和。因此“重复有害”与“多样性必然更好”都不成立。[M51]

核心例子｜同规则的两道题，为何只有一道能区分捷径？

设研究者预先定义正确规则 f(a,b,c)=(a+b) mod 10，并构造一个竞争捷径 g(a,b,c)=(a+c) mod 10。当训练题碰巧总满足 b=c 时，两个规则的预测完全相同，即便题面再多样也不能用这些标签将它们区分。

训练例子正确规则 f捷径 g是否能区分？
(3,2,2)55否
(4,1,1)55否
(6,3,3)99否
(3,2,5)58是：两条规则给出不同标签
注意三层不同含义：这个例子中的“可区分”仅是研究者预先指定的两个候选规则在该输入上预测分歧，不表示 LLM 内部确实存储 f、g 两个明确假设。如果训练后模型只答对 (3,2,5)，却仍在新的 b≠c 输入上执行 g，就只是记住了一个例外。真正的规则学习必须由训练时没有见过的分歧输入验证。

由此形成两个独立变量：（1）样本在预先冻结的候选规则集合中提供多少 disambiguating evidence；（2）当前模型能不能通过给定 LoRA 更新真正吸收这些证据。还要在不同前置掌握状态下测量交互。高信息量并不保证高可学习性。

Challenge｜为什么有区分信息仍可能学不成规则？

1. 题目新颖性无法说明规则是否被区分

只看 MinHash、embedding 或技能标签，容易把改变措辞误认为新证据。甚至同一个真实规则内的两个例子，其消除错误捷径的能力也可能完全不同。

2. 逻辑上可区分，不表示参数更新能学会

已知的候选规则集合中，一道反例可能足以排除捷径；但神经网络仍可能记忆个别输出，或者在已有前置知识不足时根本无法吸收。用 oracle 教学信息量解释 LLM 的实际学习会跳过这一层。

3. 先前研究已经能选信息量高的题

主动学习和黑盒机器教学已研究如何用例子排除任务歧义；FisherSFT 直接把信息增益用于 SFT 数据选择，Interaction-Aware Influence 能估计成对样本的冗余与互补。不能把首次设计区分性样本、首次计算两样本交互或首次动态选题当作 I10 创新。[M61][M65][M62][M60]

4. 同样的区分性证据也可能因模型状态而改变价值

尚未形成规则、形成捷径和稳定掌握规则的模型，可能需要不同练习。但当前准确率无法区分“偶然答对”和“能在分歧输入上持续使用正确规则”；必须控制数据、优化器、计算预算，真实更新后检验独立规则迁移。

Related Work｜最近邻论文，究竟与 I10 冲突在哪里？

检索组织：先比较直接碰撞的“学习收益/训练状态”研究，再看“去重/多样性”、重复训练和自博弈。以下为原始会议/作者页面核验的研究边界，不能据此声称这些方法在统一 I10 数据上已经被我们复现。

原工作已经做了什么对 I10 的约束及需增加的证据
RHO-LOSSICML 2022 [M52]用可约化的 holdout loss 近似挑选“可学、值得学、未学会”的点；已有模型状态依赖的学习价值选择。高碰撞：不能声称首先识别冗余或已掌握数据；I10 需展示两条题的条件迁移收益关系，超出逐样本可约化损失。
DSPECAI 2025／2026年在线 [M50]根据当前模型输出评价样本难度，逐阶段自步调选择，同时用 DPP 提升批内和跨轮多样性。高碰撞：模型动态能力＋多样性选择不是新点；要控制同等难度、同样文本差异下的样本间真实迁移重叠。
Skill-it!NeurIPS 2023 [M53]建立技能间先修依赖并在线分配预训练/微调数据。同规则/异规则与前置技能影响已有直接先例；I10 需在固定技能依赖下测同技能内部样本的条件收益，而非重建课程图。
ICA / Holdout-Loss SelectionICLR 2026 [M58]通过上下文近似估计候选样本微调后的 holdout loss，随模型参数变化动态赋权。高碰撞：训练前用廉价代理估计数据价值已存在；新内容只能来自“第二条题的条件增量”及规则间状态依赖。
RICoAAAI 2026 [M57]用 in-context contribution 量化个体样本对任务和全局表现的贡献，再训练轻量选择器。个体数据价值不是空白；需要证明单样本评分不能替代“学过 A 后再学 B”的条件差异。
LESSICML 2024 [M10]用优化器感知的低秩梯度相似度找到对目标能力有影响的数据。“不是文本相似而是技能相似”已有梯度基线；I10 要与梯度相似和真实两次更新共同比较。
A Critical Look at Targeted Instruction SelectionICML 2026 [M56]系统解耦数据表示和选择算法；梯度表示与贪婪轮转在低预算常较强，大预算优势会缩小。梯度表示＋覆盖已经是强基线；必须匹配不同预算档，不能只打败随机与语义去重。
R-Diverse2026年2月预印本 [S205]发现 self-play 题目的“表面多样性幻觉”，使用跨轮记忆惩罚及技能层面多样性测量。最需要警惕：“看似不同却练了同一种技能”已被直接提出；I10 不能重做技能标签去重，需测同一技能下的参数学习增量如何随熟练程度改变。
D4NeurIPS 2023 [M54]先去重再用嵌入提升覆盖；有选择的重复优于随机重复。文本/嵌入多样性不是新方法；有益重复的条件是我们的待解释对象。
Data Repetition Beats Scaling2026年2月预印本 [M51]长 CoT SFT 在固定更新预算下适当重复可优于更大不重复数据集，且存在饱和信号。反例：简单“高多样性更好”会失败；I10 需要区分巩固期与饱和期。
Deduplicating Training Data / SemDeDupACL 2022／2023预印本 [M59][M55]精确/近重复清除可减少泄漏与记忆；语义去重可提升数据效率。必须保留 exact/MinHash/embedding 去重对照，但仅证明去重更好不足以写 I10。
Interaction-Aware Influence Functions2026 预印本 [M60]明确估计一组训练样本中成对交互的冗余/互补，并在指令微调中使用。最近邻：样本交互本身已有人做；I10 要实测“规则区分信息 × 不同模型掌握阶段”的独立迁移，而非再定义一个成对贡献评分。
Active Learning Helps Pretrained Models Learn the Intended TaskNeurIPS 2022 [M61]选择能消除歧义、暴露虚假相关的样本；区分正确任务行为已经是明确前作。最近邻：不能宣称首次利用反例排除捷径；主实验必须回答相同可区分性条件下为何有的 LLM 权重更新只记住例外。
FisherSFTICML 2025 [M62]以 Fisher 信息矩阵近似信息增益进行有预算的训练样本选择。逻辑区分信息、Fisher 信息量和真实跨题规则迁移必须分别测量；不把信息量优先视为创新。
Self-Play Only Evolves When … Learnable Information GainICML 2026 Position [M63]已提出自生成数据循环会因缺乏可学习的新信息而停滞的系统机制观点。I10 给出具体的规则歧义—参数吸收可否证实验，而不只是重述 Self-play 需要新信息。
Bayesian TeachingNature Communications 2026 [M64]用规范贝叶斯教师示范微调 LLM，获得跨任务泛化的概率推理行为。说明真正的推理迁移可以通过教学形成，但没有分离同规则证据的区分性和模型状态吸收能力。
Teaching a Black-Box LearnerICML 2019 [M65]在未知学习者假设类时，使用交互收集有效教学例子。选择区分性样本和交互教学不是新概念；I10 的对象必须限定为 LLM 参数更新后的可迁移规则。
Rote Learning Considered UsefulICLR 2026 [M24]先记忆关系再学习语义映射能够支持后续部分泛化；事实记忆和抽象规则运用并非同一评测。不能假设重复记忆零价值。对原题、近似变体、未见规则题以及保留期分别报告。

最近邻碰撞结论：训练前选“能区分候选规则的例子”已有主动学习；信息增益选数据已有 FisherSFT；估计成对样本交互已有 Interaction-Aware Influence；循环中新信息不足已有 Self-play Position。I10 不重新命名这些机制。需要新增的证据是：给定同等规则区分信息，模型在不同掌握状态下是否会把它转化成真正的未见题规则应用；这一差异是否无法被当前 loss、Fisher/梯度信号和已有样本交互方法解释。这是待验证的研究边界，不是已证实的新机制。

Nature 2023 MLC｜学会规则还是只记住答案？

NHB 2026｜样本频次、表面多样性与规则区分信息不是同一种变量

可借鉴现象：Nature Human Behaviour 2025/2026 的 530人/双层Transformer 实验中，同一图片频繁重现会强化历史标签记忆，更多不同图片倾向促进上下文规则；混合数据能让两种策略共存，而分块训练的小模型会出现策略覆盖。此文控制的是样本频次与顺序，并没有操纵训练标签是否排除正确规则的竞争捷径。[E360]

对I10必须额外控制：在相同Zipf频次/表面多样度下，用规则生成器制造D=0（正确规则f与捷径g预测一致）和D>0（f/g预测不一致）的正确监督。经过同预算LoRA更新撤掉课堂提示，测未见分歧题、未见组合及旧能力。这是待验证的因果检验；原论文的in-context能力不等于新知识已被持续写入参数。

最近邻强对照：NeurIPS2025已直接以梯度空间多样性预测7B推理迁移；ICLR2026多模态数据选择已结合相似性/多样性预测训练收益；如果I10的区分性证据D无法超出这些解释，就不独立包装数据选择策略。[M503][M508] 大模型与VLM综述 · NHB原文精读

Science Advances 2020｜换训练样本与换学习目标，为什么要分开研究？

原始现象：高水平钢琴家在100次直接运动误差练习后没有显著改善，但主动触觉二择辨别+反馈帮助训练指的特定低力度控制。该研究没有证明只增加反馈密度就一定使专家进步，而且普通重复与触觉组按键次数不同。[E380]

与I10的正交区分：I10固定监督方式，改变训练样本是否提供能排除竞争捷径的信息D；学习信号瓶颈候选则在训练样本和规则相同、顺序/优化器固定时，改变训练任务/反馈形式：直接执行答案、细微条件辨别有反馈、辨别无反馈、非诊断性辨别。两者可以共享f/g人工规则生成器，但不混成一个创新主张。

决定性对照：如果任何D>0的反例无论使用何种任务都有效，这更像I10的规则辨识收益；如果只有先测到基础辨别缺口的高水平模型从对症辨别反馈中获益，并转移到撤辅后的完整任务，则存在独立的信号学习问题。

Insight｜信息能够区分规则，不代表模型能吸收规则

四个层次应分别测量：表面新颖性（词面/语义表示不同）、规则身份（真实规则及其适用边界）、规则区分证据 D（样本能排除预定义候选捷径多少）、实际学习增益 L（真实参数更新后的无提示独立迁移）。D 是由任务生成器定义的逻辑可辨识性，L 是模型经更新后的行为改变；两者既不等价，也不应互相充当标签。

可复验的规则区分指标：对研究者在训练前冻结的有限候选规则集 C（含真实规则 f），定义 D(x;C)=Σ(g∈C,g≠f) 1[g(x)≠f(x)]/(|C|−1)；也可报告每个候选规则被排除的比例。它刻画给定标签的理论区分性，不宣称 C 是 LLM 内部真实假设空间，也不使用最终未见测试题挑选训练样本。多个规则族需要独立预设竞争捷径。
核心机制假设需要观察到什么主要替代解释
H1 · 题面不同 ≠ 新的规则证据表面多样的同规则样本未必排除捷径；近似同形反例却可能有更高 D仅仅是难度/输入分布不同
H2 · 有区分证据 ≠ 真正学会同样高 D 的样本在一些模型快照中只改善原题，在另一些快照中提高未见分歧题表现输出记忆、优化器差异、训练 token 差异
H3 · 增益依赖当前掌握阶段巩固、局部捷径纠正、已掌握饱和三个阶段的收益排序可能改变一般可塑性损失或当前 loss 已足以预测

固定当前模型参数 θ、优化器及训练预算。令 Ux 是使用样本 x 做一次受控参数更新的过程，H 是事先冻结且训练时不可见的迁移题集合，F(θ,H) 是这些题的评分：

单样本独立收益（离线真值）：Gθ(b) = F(Ub(θ), H) − F(θ,H)
已经学过 A 后 B 的额外收益：Gθ(b|a) = F(Ub(Ua(θ)), H) − F(Ua(θ),H)
条件收益差：Oθ(a→b) = Gθ(b) − Gθ(b|a)

如何解释：O 大于零意味着 B 在 A 之后的边际收益比单学 B 小，可能存在重叠/饱和；O 小于零意味着 A 可能帮助了 B 或形成互补。但单次观察不能排除顺序、非线性学习率、优化器状态和旧能力干扰，因此须配对换序及等计算对照。这个定义用于离线机制实验，不是已经可以在真实 RSI 训练前免费算出的打分。

真正要验证的是 H2 的信息—吸收裂缝：在 D 相同、规则相同、token/更新预算相同的条件下，模型实际在未见分歧题上仍可能呈现不同学习增益；若主要由已有 loss、Fisher/梯度、Interaction-Aware Influence 或一般可塑性指标解释，就应把 I10 合并而不是单独包装。H1 是现象起点，H3 是该效应随模型状态变化的关键检验。

Design｜规则证据 × 表面变化 × 模型掌握阶段

用程序生成并验证多个规则族，例如模十计算、条件分支、变量依赖和短程序执行。对于每个真实规则，在训练开始前同时注册错误捷径候选、允许的输入域、分歧集合与新输入测试域。题目均提供同一形式的正确答案与相同教师反馈，不在某一组额外提供规则讲解。

固定同一真实规则表面近似表面多样
不能区分捷径 · D=0S1：同形新题，真实规则与竞争捷径预测一致S2：更换数字、故事、符号，但仍无法排除该捷径
能够区分捷径 · D>0S3：只改一个关键条件，使正确规则与捷径预测分歧S4：同时更换表达/场景，仍包含足够的规则区分证据

补充两个对照：S0 原样重复（测巩固）；S5 新的独立规则任务（测新规则学习、负迁移）。S3/S4 的 D 应先在生成器层严格验证；把文本长度、数值范围、正确答案分布、基线 loss、梯度范数、样本数量和总计算预算尽量匹配。由于输入分布改变可能不可完全匹配，要记录残余差异并单列反事实对照，不能直接把 S3>S2 归因于规则区分。

三个模型状态，不按最终结果挑选检查点

状态 U：规则尚未形成，在训练前冻结的独立开发题上正确率低；状态 S：局部捷径，在原分布题上表现良好、在规则分歧题上稳定偏向竞争输出；状态 M：规则已掌握，在原分布和规则分歧开发题上均可靠。使用预定训练前缀构造快照，记录所有种子和无法进入指定状态的失败数量；状态标签仅是可观察行为，不声称知道内部表示。

定义真实规则与竞争捷径预注册生成器、分歧集合
冻结 U / S / M 快照开发探针确定状态
按 S0–S5 配对训练同 LoRA / token / 更新器
撤辅测真实学习原题 / 未见分歧 / 旧能力

实验主处理变量：追加样本的 D 与当前模型状态；表面差异和技能标签用于交叉对照。保留旧方案的 A→B / B→A 真实条件增益作为后续机制诊断，但不要在 P0 混入 I9 的跨主题课程顺序设计。统一重置下一阶段 AdamW 动量作为主实验，继承动量另做消融。

决定性实验｜P0 先验证信息—吸收裂缝，再谈 RSI 选择器

P0 · 一次最小但有说服力的参数更新实验

选约1B–3B的可训练开源 LLM，固定 LoRA 参数、学习率、优化器、答案监督和训练 token 数。先在多个程序可验规则族上构造 S0–S5，并从同一基座得到 U/S/M 三类行为快照；每个状态 × 样本条件至少三个独立种子。正式 P0 以前冻结训练题、状态探针、样本选择开发题、未见分歧题、表达变形题及旧能力回归题。实际训练记录所有条件及无法成功匹配的分母，不能根据最终测试分数筛种子。

测量层主指标避免什么误解
原题/近改写训练 loss、原题正确率、近似模板恢复率仅记住了答案或模板，不算规则迁移
未见规则分歧题无提示正确率 ΔAcc；独立分歧样本中选中预设捷径答案的比例（Shortcut Preference）用外部行为检测捷径，不能声称直接读出了内部假设
新的表达/组合保持同规则但改变表面形式、变量角色、输入范围时的正确率只会一类 b≠c 训练模板
持续保持和净收益后续干扰更新后的保持、旧任务退化、总 token/FLOPs暂时修好例外却破坏旧能力

最重要的两个预注册检验：（1）同一规则下 S3/S4（有区分信息）能否相对 S1/S2（无区分信息）在真正未见分歧题上提高迁移，同时控制文本变化和训练难度；（2）当 D 相同且预算相同，U/S/M 的实际规则迁移增益是否系统不同。可能观察到捷径状态更受益，也可能尚未形成规则的状态根本吸收不了；两者都要允许被实验否定。

数据和选择偏差控制：事先程序验证 f/g 的预测分歧；改变训练/评测数字和模板生成种子；对调真实规则与捷径所依赖的输入位置；尽可能匹配输入长度、数字范围、答案频率、初始 loss、梯度范数。若有区分样本必然造成不可匹配的分布变化，必须报告该残余差异，并增加相同输入分布的负对照，不能直接归因为认知层面的“理解”。

P1 · 强最近邻与机制解释对照

比较方法/诊断要回答的问题
固定重复、随机、多样性抽样、Exact/MinHash、SemDeDup、D4是否只是普通样本数、词面/语义覆盖的效果？[M54][M55][M59]
R-Diverse 技能级去重、Skill-it 技能分配是否只要知道同一技能标签就够了？[S205][M53]
当前准确率/loss、RHO-LOSS、DSP、ICA、RICo动态难度或单样本可学性是否已足以解释？[M52][M50][M58][M57]
LESS / 梯度表征、FisherSFT梯度相似度或 Fisher 信息增益是否直接预测真实迁移？[M10][M62]
Interaction-Aware Influence 与等预算的真实 A→B/B→A成对样本交互是否已经解释全部条件迁移收益？[M60]
训练前分歧信息 D、更新后真实增益 L、训练前后 Shortcut Preference是否存在“可排除捷径但模型未学成规则”的可测裂缝？

所有方法限定相同的训练前可用信息，训练器和总 compute 匹配；若参考模型、HVP、额外试训很昂贵，必须将成本单独计入。真实独立测试集只用于最终评价，不作为样本选择器的 oracle。对 D、L 和 Shortcut Preference 的关联报告种子区间和按规则家族聚合的置信区间，避免把同模板题重复采样当独立重复。

P2 · 将机制转成 RSI，而非先造一个去重框架

只有 P0/P1 支持稳定机制后，才让 Agent 从自己的失败或成功轨迹中生成同规则候选练习，并优先请求能够检验竞争捷径的反例；候选答案需程序/外部验证。用真实独立迁移收益更新下一轮选题策略，比较随机出题、基于成功率选题、技能多样性选题、Fisher/RHO/交互影响评分，按未见规则族和后续更新阶段报告收益。若模型只在临时上下文里看到反例，没有权重或版本化 Skill/Memory 的真实保留，不应算 RSI 学习成功。

推进顺序：先冻结规则生成器和 P0 数据协议 → 真实少量 LoRA 分叉确认机制 → 跨规则族复核 → 再做低成本预测与多轮自出题。未发现信息—吸收差异时直接并入其他数据选择研究，不扩充组件。

Go / Merge / Stop｜哪些证据才支持 I10 独立成文？

决策可观察条件
GO · 机制论文在多个预注册规则族、模型状态和种子上，观察到稳定的规则区分性 D × 参数吸收 L差异：相同 D 的样本在不同状态产生显著不同的未见规则迁移，且有“答对新例外却未摆脱捷径”的可复验失败模式；现有 loss、技能标签、Fisher/梯度信息和样本交互评分不能充分解释。
MERGE · I8/I9 的辅助控制或数据选择研究只有“区分性反例优于重复”或“部分阶段更值得练”的一般现象；已有主动学习、FisherSFT、Interaction-Aware Influence、RHO-LOSS 能同样解释、预测等预算收益，缺乏 LLM 特有的新机制。
STOP · 不单独设计 RSI 模块独立分歧题无稳健改善；样本效果仅来自训练分布变化、训练 token 更多、测试泄漏、无关优化器状态，或者只在原题/近模板上出现。

暂定英文研究题目：When Does Another Example Matter? Disambiguating Rules in Self-Improving Language Models。原题 When Does Another Example Teach Something New? 留作问题来源；“新信息”和“学会规则”之间的区别是当前最值得研究的增量。

一句话主线（尚待实验）：同一规则下，样本是否提供排除错误捷径的证据，以及当前模型能否通过参数更新吸收该证据，可能共同决定持续自我训练能否获得新能力。
