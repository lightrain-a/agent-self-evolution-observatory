Reward Function Compression · NC 2026

Reward function compression facilitates goal-dependent reinforcement learning

发表单位（作者署名） University of California, Berkeley（加州大学伯克利分校）

Reward Function CompressionHuman Reinforcement LearningGoal RepresentationWorking MemoryEvaluation RulesLearning Science

研究对象是人类：同样学习按键规则，能把抽象反馈归纳为简单、稳定奖励规则的人，学得更好；重复次数本身不足以解释。

Challenge难在哪里

一个人既要通过试错记住哪张刺激图该按哪个键，又要判断抽象反馈图到底意味着成功还是失败。

Insight为什么可解

同样的反馈数量，若成功结果能归纳为一条简单的共同规则，就可能减少每次重新评价的负担。

Design具体怎么做

用 Points 和 Goals 两种反馈；六项人类实验依次操控目标数、可压缩性、稳定性、重复率及相互冲突的目标标签。

Result结果怎么样

Exp 2 配平图形数量和频率后，可压缩组仍显著更好（p=0.002）；Exp 5 单纯重复无显著整体收益；Exp 6 冲突标签降低表现。

核心机制 · 记住这几个公式

  1. 奖励必须先被解释，才能用于学习

    Goals条件额外要求把结果图片与当前目标比较，而不是像+1/+0一样直接得到奖励价值。

    outcome image → identify Goal/Nongoal → r_t → Q update
  2. 可压缩规则不同于重复实例

    能凭单个图形特征判定是否为Goal，可能比把每个结果图逐一记住更经济；实验2匹配了图形出现次数。

    shared outcome feature → reusable reward mapping
  3. 行为学习的价值更新

    delta-rule描述得到奖励后如何更新刺激—动作价值；奖励识别效率与学习率拟合相关，但不是长期记忆的神经证据。

    δ_t = r_t − Q_t(s,a); Q_{t+1}(s,a)=Q_t(s,a)+αδ_t

实验证据（作者报告，未复现）

  • Exp 1（54 人）：增加需要识别的 Goal/Nongoal 图片对数（1、2、3、4对），按键学习表现下降（p<0.001）。
  • Exp 2（51 人）：8种形状×颜色×填充组合图形、相同频率，可压缩目标（单一特征划分）优于必须综合多个特征的目标（t(50)=3.31，p=0.002）。
  • Exp 3（90 人；旧数据重分析）：逐试次更换目标图片时，Goals按键正确率约67%，Points约80%。
  • Exp 4（93 人；旧数据重分析）：固定使用同一对Goal/Nongoal图片时，Goals整体正确率约77%，实验后期与Points接近。
  • Exp 5（51 人）：改变目标重复比例（25%、50%、75%），未检测到显著整体重复收益（p=0.355）。
  • Exp 6（51 人）：同一图形的价值标签保持一致时约62%，赋予冲突的正负价值时约55%（p=0.002）。
  • 计算模型：奖励收集反应时间较短与更好学习表现相关；由反应时间调制价值更新效率的模型优于仅用选择噪声解释的方案。

限制与易错理解

  • 六项实验研究的是人类，不是AI Agent；模型仅拟合人类行为。
  • Exp 3与Exp 4是既有数据的重新分析，不能说六项都是本论文独立新招募的实验。
  • Exp 2控制了图形数量和呈现频率，可压缩性的优势不能粗略归因于“多看了几次”。
  • Exp 5“未发现显著效应”不等于证明重复在所有情况下完全没用。
  • 反应时间和学习率之间的关联及模型拟合，尚不能证明某条奖励规则已从工作记忆转移到长期记忆。
  • “压缩奖励规则”不是把AI Judge蒸馏成小模型的实验结论；评价器复用促进RSI学习仍需要新的因果验证。

对我们的 RSI 研究有什么启发？

  • 科学假设：面对等量评价经验，能形成可复用奖励规则的 Agent，是否比只记住评价实例的 Agent 在下一轮独立学习中更受益？
  • 重要边界：生成或保存Rubric本身与Eval-Skill、SCRIBE、EvoRubrics等已有工作有重叠；真正需要研究的是何时固化、何时失效、是否促进真实能力更新。
  • 与现有I6/I8（失败及纠错迁移价值）和I10（练习是否带来新知识）互补；这个候选主要研究评价能力的形成及其对下一轮学习的影响，暂不抢占已有正式编号。
下一步最值得做的辨别实验

固定初始模型、训练样本、优化器及总成本，操控可压缩/难压缩/高重复无共性/标签冲突四类评价经验，比较大Judge每次评价、实例缓存、规则编译和失效回退。先测评价正确性与延迟，再用相同反馈进行真实参数更新；撤掉辅助评价器，在未见同规则题和旧能力测试上测净收益。

Self-organized Study Orders · npj 2024

Optimizing self-organized study orders: combining refutations and metacognitive prompts improves the use of interleaved practice

发表单位（作者署名） Maastricht University · School of Health Professions Education 等 3 家署名机构

Learning ScienceMetacognitionSelf-regulated LearningInterleaved PracticeStudy PlanningI9Near Transfer

反驳错误学习观念并展示学习体验轨迹，能提高学生自主安排交错练习的比例；但未显著提高干预组分类成绩。

Challenge难在哪里

学生往往把集中练习的即时顺畅当作学得更好；以前多数干预只让学生选择预排课程，难以反映逐项自主安排。

Insight为什么可解

纠正“费力就是学得差”的误判，并让学生回顾两类策略的努力感和学习感变化，可能改变后续自主选题行为。

Design具体怎么做

91 名大学生随机分两组，都体验集中与交错；46 人额外读反驳文本并看元认知图；逐项安排画作，再于5–7天后安排鸟类。

Result结果怎么样

干预后交错率 76% vs 55%，延迟鸟类 81% vs 57%；自主分类成绩组间主效应 p=0.222，未显著。

核心机制 · 记住这几个公式

  1. Item-level self-organized study order

    不是让参与者从 ABCABC 与 AAABBB 中整体选一套，而是每次自主决定下一张学哪一类。

    Switch Rate = n_switch / 35
  2. Refutations + metacognitive prompts

    先明确指出两类错误认识，再让参与者比较集中/交错时自评的努力和学习感随时间变化。

    Joint intervention = correction of beliefs + strategy experience + experience visualization
  3. 行为与成绩的证据分离

    随机分组因果支持顺序选择行为变化，但不能据此宣称分组干预已提高分类准确率；切换率与成绩只建立相关关系。

    p_group = 0.222 (not significant); odds ratio per switch ≈ 1.04 or 1.05 (association)

实验证据（作者报告，未复现）

  • n=91（干预 46 / 对照 45），预注册；每次自主排序有 35 次类别 stay/switch 选择；干预前 blocked 57% / interleaved 43%。
  • 干预后绘画类别切换率：干预组 0.76 (SD=0.31)，对照 0.55 (SD=0.36)，t(89)=-2.98，p=0.004。
  • 5–7 天后鸟类近迁移：干预组 0.81 (SD=0.29)，对照 0.57 (SD=0.34)，p<0.001。
  • 研究者安排的交错 vs 集中体验阶段，24 题分类均值 6.56 vs 3.57，配对 d=1.05、p<0.001。
  • 自主安排条件的分类成绩：无干预组别主效应 p=0.222；时间×组别 p=0.205；不能得出实验组分类成绩显著提高。
  • 逐项切换与分类准确率相关：绘画每额外一次切换 odds 约 +4%，鸟类约 +5%；这是统计关联的 odds，不是准确率百分点的因果增益。
  • 自主任务中最长连续交错段：干预后 21.15 vs 13.67（p=0.012），延迟任务 24.67 vs 13.37（p<0.001）。

限制与易错理解

  • 联合干预含反驳文本、策略体验及可视化元认知提示；没有完整的“仅反驳/仅提示”随机析因，因此不能把最终干预效果精确归因于其中一项。
  • 延迟实验检验在新鸟类类别任务中是否继续采用交错策略，属于 5–7 天近迁移；不是同一画作长期记忆测试，更不是更远期泛化。
  • 人类主观“费力”及“感觉学到了”与真实成绩不是同一信号；可视化并没有直接证明元认知监控准确度永久改善。
  • 组别×时间和组别的分类分数差异不显著；交错次数与正确率的回归是相关分析，不足以证明自选交错越多必然导致成绩提高。
  • 不能从视觉类别识别直接推导所有数学/代码任务都应最大化切换比例；练习最优顺序依赖规则相似度、基础知识和任务需求。
  • 原文主要考察人类行为，没有训练持续修改的 RSI Planner，也没有模型撤除提示后依旧自发改进规划能力的证据。

对我们的 RSI 研究有什么启发？

  • I9 最贴近：已有 I9 主要检验交错/集中/切换时间的学习结果，这篇启发研究 Planner 能否纠正自己对即时顺利程度的误判，并将策略迁移到未见主题；仅能作为 I9 的扩展实验，不直接证明 RSI 已成立。
  • I2 研究具体教学动作如何选择；I9 仅固定学习材料、更新器，研究自主安排跨主题练习顺序与策略保留，二者不要混成一个万能决策器。
  • I6 与 I8 不因这篇论文重新定义；其关注失败轨迹或错误迁移，不是交错比例。
  • 设计 RSI 对照时，必须单独报告 Planner 选择行为、下游 Learner 真实能力、撤除提示后的策略迁移和额外评测开销；不能把“更多交错”作为优化目标本身。
下一步最值得做的辨别实验

先验证模型是否把训练批次的即时准确率误当成长效；然后用“反驳错误观念 × 过程轨迹提示”的 2×2 消融，固定数据/预算/教师，更新可保留的 Planner 规则或参数，撤除提示后在新任务族自主逐项排课；报告净学习收益、过度交错、旧能力保持与成本。若固定交错规则同样有效，应并回 I9 而不独立立题。

  2. 效率必须算答对与答错的成本

    成功和失败有不同学习收益与耗时，因此不能只按当前错得最多的项目排序。

    U = p × (gain_correct / cost_correct) + (1-p) × (gain_wrong / cost_wrong) [Eq. 1]

    先通过模拟找合适的回忆概率阈值，再从未达到阈值的项目中选最接近阈值的进行练习。

    i* = argmax_i p_i subject to p_i < OET (simplified policy)

仍未解决：没有研究 Agent 自主产生新信息。

仍未解决：离线排序不证明在线 P50 有效，也不扩展初始采样支持集。

仍未解决：无越权、投毒、恶意记忆持久化的安全测试。

核心机制 · 记住这几个公式

  1. 五类十种难度量

    题目复杂度 RS/SC/CD/ACC；意外程度 SLP/TLP；信心差 LG；预测熵 SLE/TLE；决策波动 VACC。

    5 categories: 4 + 2 + 1 + 2 + 1 = 10 concrete metrics
  2. 只改顺序的受控比较

    相同训练数据和 LoRA 预算，比随机、指标升序↑和降序↓；方向不等于所有指标统一的易到难。

    Same 20K examples, same SFT; ascending vs descending vs shuffled
  3. P50 与 VACC

    反复采样同题正确率 p，结果方差为 p(1-p)，0.5 时最大；不等于训练中实时选择 P50。

    VACC = p̂(1−p̂), maximum 0.25 at p̂=0.5

限制与易错理解

  • 五类共十个具体指标；ACC 被归入题目侧，但由目标模型多次答题估算，并非严格模型无关。

核心机制 · 记住这几个公式

  1. 语义重解释

    先用 [X] 把一组事实组织起来，再让少量自然语言关系示范对这批事实生效。

    Phase1 (s,[X],o) → Phase2 relation_prompt(s) → o
  2. Phase 2 留出 ≠ 从未出现

    泛化事实必须标记第一阶段已见而第二阶段未见；不能误称训练全程未见。

    seen_in_phase1 = true; seen_in_phase2 = false
  3. 两跳能力缺口

    记忆深度带来增益，但跨关系组合明显不可靠。

    2-hop generation 0.14 → 0.36; MC 0.08 → 0.16; ICL 0.95 (facts in context)
  4. RSI 核心区分

    正确回忆、语义访问、组合推理和未来持久收益是不同指标。

    Recall ≠ semantic access ≠ two-hop reasoning ≠ lasting learning

    固定任务与当前策略，随机分配隐藏/保留 Skill；两组成功率之差估计该 Skill 的剩余贡献，避免把任务难度和 Skill 效果混在一起。

    zₓ = mean(y_visible) − mean(y_hidden)
  3. 后验撤回与回测

    为每个 Skill 累积对照记录，用 Dirichlet 加权的 Bayesian Bootstrap 估计平均贡献；仅当预期正向贡献足够低才撤回，之后仍定期回测。

    withdraw iff nₖ ≥ 12 and E[max(Δₖ,0) | data] ≤ 0.02

实验证据（作者报告，未复现）

  • 论文在 12 个 IID/OOD 数据集报告多领域结果；AIME 2026：81.33%（PATS 74.00%），SWE-Bench：42.81%（PATS 40.16%）。
  • 在 AIME 2026 的消融中，去掉 Recursive Learnability 后为 70.67%，换成固定 Skill 库后为 66.67%（完整方法 81.33%）。

限制与易错理解

  • L_rec 衡量小 KL 更新下的局部结果方差，不等于未来真实学习增益；冻结 Worker 的随机性也会制造结果方差。
  • 对照无偏性依赖固定任务/策略、随机分配和无干扰；记录在自适应选题与持续更新下会发生分布漂移。
  • 无 Skill 部署指不提供外部 Skill 文本，仍可调用冻结 Workers 和 Agent Graph；Proposer 主要从候选题库选题。

对我们的 RSI 研究有什么启发？

  • 对 I5 的十模型共进化：将“选下一道题”对应为“选下一位教学伙伴”，但不能直接用交互成功率替代学习后的独立能力提升。
  • 可复用 3/2 随机对照 + 后验决策的思路；实际迁移时应从同一学习者检查点分叉，等预算训练后在独立测试集比较无教师增益。
  • 把“辅助撤离”作为实验协议：验证 Skill/教师何时已不再贡献新收益，而不是只报告当前任务正确率。
下一步最值得做的辨别实验

在同一学生检查点上，比较不同教师、随机教师和无教师的等预算学习；以撤掉教师后的 held-out ΔAcc 与负迁移率，检验 L_rec 是否优于直接学习增益。

五问标签怎么理解？

四步读懂一篇论文之后，可以用这五个问题比较它研究到哪一步。重点研究指有直接方法和证据，不代表已经彻底解决。

信号对不对

评估分数和真实能力是否一致；评估器也在变化时，用什么独立证据校准它。

有没有新东西

自己出题、自己造数据时，能够纠正模型的信息究竟从哪里来。

采不采得到

高质量解法是否处在可采样的候选空间中，候选支持范围在哪一环节收窄。

吸收了会不会丢

改进进入权重、记忆或技能后，旧能力是否保留、错误经验是否被排除。

安全

评估器被绕过、越权修改真实系统、坏行为被持久记录三类跨环节风险。
