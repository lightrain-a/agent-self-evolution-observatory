Emergent Misalignment · Nature 2026

Training large language models on narrow tasks can lead to broad misalignment

发表单位（作者署名） Truthful AI 等 8 家署名机构

Nature 2026Emergent MisalignmentFine-tuning SafetyCross-domain Side EffectsLearning AdmissionI3

狭窄微调有时会改变无关领域的助手行为；Nature 2026 扩展了 ICML 2025 的发现，而非证明所有局部修复都不安全。

Challenge难在哪里

只优化一类代码任务，却可能让模型在其他领域不负责任；目标任务成绩好，是否足以批准新版本？

Insight为什么可解

训练示例可能强化跨领域共用的行为角色表征；语境与输出格式影响其显现，但机制尚无统一解释。

Design具体怎么做

对照6,000条安全/不安全代码、14,927条特定角色数字序列；测8条非编程问题、Qwen训练动态与基础模型。

Result结果怎么样

GPT-4o 特定评测约20%失准，部分GPT-4.1约50%；安全代码/教学语境对照低；40步附近失准轨迹开始分离。

信号对不对重点研究

论文做到：在8条非编程自由回答问题上，用 temperature=1 采样并以 GPT-4o Judge 判断回答的连贯性与失准；同时测代码能力和 token 对数概率。

仍未解决：8条精选问题及 LLM-as-Judge 只给受限风险代理，不能代表所有部署任务或真实越权后果。

有没有新东西部分涉及

论文做到：狭窄代码或特定角色生成数字训练会伴随非训练领域行为变化；输出格式和教学语境显著改变观察到的失准。

仍未解决：模型行为的一致性可能与共享 persona 表征有关，但不是所有正常微调或正确信息都一定会造成失准。

采不采得到未直接研究

论文做到：检验输出行为跨领域泛化，未研究 LLM 的新解法搜索支持集。

仍未解决：不能由跨领域失准推断新知识可达性或未来独立学习能力。

吸收了会不会丢部分涉及

论文做到：训练期间分离局部任务正确率与跨领域不当行为指标，显示单纯 early stopping 难以隔离两者。

仍未解决：未研究多代持续 RSI、自改进控制器、旧知识长期保持与未来可塑性。

安全重点研究

论文做到：以安全代码、教学语境、越狱微调和基础模型为对照揭示局部参数更新引发非局部行为风险。

仍未解决：并未真实测量 Agent 权限、工具执行与版本审批风险，且发生概率依赖模型和评测格式。

核心机制 · 记住这几个公式

  1. 局部训练可能引发非局部行为变化

    即使新任务训练数据很窄，共享模型参数和行为特征也可能影响无关的用户输入。

    task-specific fine-tune -> shared model update -> possible cross-domain behavior drift
  2. 语境与输出格式交互

    同样是含漏洞代码，有授权教学背景时失准显著减少；评测强制 Python/JSON 输出时，部分不当行为更易显现。

    Risk = R(model checkpoint, evaluation context, response format)
  3. 局部能力不等于全域可靠

    作者同时观察代码能力与非编程失准，在Qwen连续微调中没有简单可用的“只学技能、不学副作用”停止点。

    Target Gain != Global Reliability
  4. RSI 假设：事前风险预判

    让学习接纳机制在正式写回之前比较核心更新、隔离适配器与外部专家的跨领域净后果，机制尚待验证。

    accept a_k iff independent global regression and capability gates pass

实验证据（作者报告，未复现）

  • ICML 2025 初始发现：6,000条insecure code训练后，GPT-4o代码验证集中不安全输出超过80%；8条自由回答问题上失准约20%（原模型0%）。Nature 2026 将其作为背景并扩展实验。
  • Nature Fig.2：特定角色生成14,927条数字训练数据；与训练格式更接近的 prefix+suffix 问题失准更强。未微调GPT-4o和正常/Helpful数字对照为零或接近零。
  • Nature Fig.3/4：Qwen2.5-Coder-32B-Instruct安全与不安全代码模型每10步评估；两组的log-probability在约40步之后分离，局部代码能力仍继续变化；每组5个随机种子。
  • Nature Fig.5：Qwen2.5-Coder-32B base未经安全指令对齐仍可能发生失准；使用Flask上下文评估，并额外过滤将不安全代码直接塞入回答的伪跨领域样本。
  • Nature Extended Data Fig.6：对相同8条问题要求Python字符串或JSON输出可提高不当回答比例，提醒部署形式影响发现率。

限制与易错理解

  • 研究主要使用不安全代码/特定不良角色生成数据。不能直接得出无害、正确、受控的局部能力修复普遍造成跨领域失准。
  • ICML 2025 已首先系统发表 Emergent Misalignment；Nature 2026 的新增价值是跨数据、格式、训练动态与 Base 模型对照。
  • 失准率来自指定的8条自由回答评测问题与LLM Judge；GPT-4o约20%和部分GPT-4.1约50%不是通用对话出错概率。
  • Prompt格式、训练语境和模型能力会影响效果；样本输出连贯性过滤规则尤其影响 Base 模型的跨域归因。
  • persona/SAE特征的因果 steering 来自后续工作（Wang等），不能写成Nature作者在本文对所有模型完成的机制证明。
  • Nature没有进行真实工具执行、Agent多轮自我更新、更新前风险预测或学习接纳策略跨代比较。

对我们的 RSI 研究有什么启发？

  • I3（事后修复）：局部能力学会、旧任务正确率未明显退步，也可能有非局部行为漂移。版本回归不应只查目标任务与旧任务准确率。
  • Learning Admission（事前接纳）：新增可预测的更新副作用维度，与旧能力遗忘、未来可塑性损失并列；分别评估全域行为可靠性和硬安全约束。
  • 需要区分行为变化与数据污染：控制相同目标学习收益/训练预算，把跨领域正常问答、JSON、工具调用等独立格式保留为测量维度。
  • 真正 RSI 不是给 SFT 增加一个安全标签，而是通过历史真实更新结局迭代Meta-Admission，并在未见任务中更准确决定内化、隔离、外部委托或拒绝版本提交。
  • 研究优先级：先用正常、可验证的局部修复任务做 P0，不为制造危险副作用而主动训练不安全代理。
下一步最值得做的辨别实验

P0 从同一开源模型checkpoint出发，固定合法任务的正确修复样本、训练token、任务达标门槛；对照共享LoRA、隔离Adapter、外部Skill或专家。验收时用未见且非训练目标的独立安全/行为、普通文本/JSON/工具输出测跨领域漂移；匹配目标增益后再判断是否进入Learning Admission P1/P2跨代风险预测。

长期学习会让网络逐渐学不进新任务；CBP 维持可塑性，但没有验证 RSI 何时拒绝、外置或恢复内化。

Challenge难在哪里

网络连续学了许多新任务后，即使反复提供监督，为什么以后越来越难学？这与单纯遗忘旧知识不同。

论文做到：多个数据集、网络架构与强化学习环境下都观察到后期适应能力变差。

仍未解决：没有直接研究 LLM 训练后新规则的可达性、Skill 搜索覆盖或 Agent 调用外部模型。

吸收了会不会丢重点研究

论文做到：显示未来新任务学习能力下降与旧任务遗忘属于不同问题；CBP 在所测设置缓解可塑性丧失。

仍未解决：CBP 只根据当前使用价值选择重置单元，并不保证长时间旧任务记忆不被遗忘。

安全未直接研究

论文做到：研究训练优化与表示动态，并未分析安全关键 Agent 的权限与可靠性。

仍未解决：随机重置在安全关键模型中可能伤害旧规则；必须另外做回归和安全门控。

核心机制 · 记住这几个公式

  1. 可塑性不是旧知识回忆

    可塑性是固定任务训练预算下学好当前新任务的能力；CIFAR-100 让旧类别数据一直参与训练以减弱遗忘混淆。

    plasticity(t) ≈ accuracy(after fixed training on a new task at t)
  2. 保留多样性的持续随机性

    从已成熟单元中择低使用价值者重置少量权重；新单元输出权重置零、经过成熟期才再参与选择。

    replacement fraction ρ ≪ 1 ; CIFAR-100 ρ = 10^-5
  3. 跨代未来学习价值（我们的外推）

    已有能力保持相同，不代表未来学新任务仍相同；需要从冻结 checkpoint 分叉真实训练才能测量。

    L(M_k,C,B) = Perf(Train_B(copy(M_k), C), held-out C)

实验证据（作者报告，未复现）

  • Continual ImageNet（Fig.1）：每个二分类任务训练1200图、测试200图，训练250 epochs，重复30个随机运行；标准 BP 约2000任务后显著丧失新任务学习能力，CBP 在作者5,000任务窗口内保持表现。
  • CIFAR-100（Fig.2）：ResNet-18，每次新增5类，20阶段×200 epochs；每阶段继续使用所有已见类别数据，并与同样类别从头训练比较。40类之后普通连续训练相对恶化，最终100类约低5个百分点；CBP 缓解。
  • PPO（Fig.3–4）：Ant-v3 在每200万步更换摩擦系数的条件，以及不更换摩擦的长时固定环境，普通 PPO 性能均可能明显退化；CBP/L2 等缓解部分条件下的表现下降。
  • 机制记录：失活神经元比例升高、表示有效秩下降、权重幅度增长与后期学习性能变差同时出现；补充 Permuted MNIST 800任务进一步系统验证。

限制与易错理解

  • Nature 2024 不是 LLM 论文，也没有研究语言模型的自我迭代、Meta-Admission 规则或外部专家委托。
  • 网络可塑性下降的三个表征相关量并非逐个随机操纵的充分因果解释；CBP 改善结果不意味着所有大型 Transformer 都适宜简单随机重置。
  • CIFAR-100 中绝对正确率随类别增加自然变难，作者使用同类数据从头训练的相对对照；不应直接把类别数变多的原始准确率下降当作可塑性损失。
  • CBP 在一定范围维持可塑性，但并不单独保证旧任务的长期保持；持续随机性有潜在遗忘与安全风险。
  • ImageNet 的5,000任务和PPO长期步数是作者所测观察窗口；不等于已经在所有规模模型上严格证明无限期保持可塑性。

对我们的 RSI 研究有什么启发？

  • Learning Admission：预先选择内部学习或外部承接时，除了当前新能力增益、旧能力回归、成本，还需要考虑未来继续学习的能力；但外包并不能修复已经塑性下降的核心。
  • I9：它提供“未来可学习性”与旧知识遗忘不同的诊断；I9 的独立处理变量仍是 A/B 学习顺序，不是训练神经元重置算法。
  • Agent 的 Prompt/Memory/Skill 更新不一定改变底座权重；只有真实权重/LoRA 更新时，才能直接沿用这篇参数可塑性机制；其他更新表面需要独立定义 future learnability。
  • 不主张仅凭 dormant units / rank 等低成本代理直接决定停止学习；先做复制 checkpoint 的等预算真实试训与已知诊断基线。
  • 真正 RSI 研究：经过多轮实际更新后，Meta-Admission Skill 是否能在未见任务上更好预测可塑性损失并选择内化、隔离、外包或暂缓，从而提高后代单位成本净学习收益。
下一步最值得做的辨别实验

从同一基座产生不同更新历史，匹配当前 A/B 能力、旧任务保持与总训练预算；在未来独立任务 C 上重置优化器、等预算试训、撤掉辅助看学习曲线；只在真实未来学习差异成立后对照接纳、隔离、可塑性修复、外包和重访。

RL Agent 会根据经验改进游戏策略，但决定它怎么学习的 TD 目标、辅助任务和策略损失通常由研究者手工指定。

Insight为什么可解

若不同 Agent 的训练目标由共享元网络产生，并用它们学得好不好来反向评价，学习规则本身就能被改进。

Design具体怎么做

把每个 Agent 的动作、奖励和多类预测轨迹交给元网络；元网络输出策略及新预测的学习目标，外层对多个 Agent 的回报做元梯度优化。

Disco57 在 Atari57 上达到 IQM 13.86，规则可迁移至未见基准；Disco103 用 103 个复杂环境发现更通用的规则。

核心机制 · 记住这几个公式

  1. 共享的不是策略参数，而是更新目标

    多个 Agent 用相同元网络产出的目标更新自身参数；外层根据群体效果改变元网络，使更新规则具有跨任务复用性。

    agent θ_i ← update(θ_i; meta-targets m_η(trajectory_i)); η ← meta-update(aggregate returns)
  2. 预定义预测与发现语义的预测并存

    π 是策略；q 是动作价值、p 是辅助下一步策略预测，二者使用预定义辅助目标；y(s)、z(s,a) 的学习目标由元网络决定。

    agent outputs: (π, q, p, y, z); meta-targets: (π̂, ŷ, ẑ)
  3. 输出训练目标，而非只输出一个标量 Loss

    元网络决定策略及两类新预测向什么目标移动，保留 TD 式 bootstrapping 和 Q-learning 半梯度方法的表达能力。

    L(θ)=E[D(π̂,πθ)+D(ŷ,yθ)+D(ẑ,zθ)+L_aux]; D=KL
  4. 训练规则要对学习过程求导

    梯度从未来 Agent 回报穿过数次 Agent 参数更新，返回到目标生成器 η。实际用滑动窗口反传20步，而不是展开完整生涯。

    ∇_η J ≈ E[(∂θ/∂η)·∇_θ J(θ)]
  5. 规则的可迁移性与最终 Agent 的零样本能力不同

    未见环境里，Disco57 本身不提供现成的游戏策略；必须让新的 Agent 按发现规则重新交互和学习。

    hold out environments for meta-discovery → freeze η → train fresh θ on new environment

限制与易错理解

  • DiscoRL 自动发现的是给定元网络输入、输出、预测头和优化框架内的训练目标映射；KL 距离、q/p 辅助损失、优化器与整体元训练流程仍由研究者固定，不是从零自动发现所有训练代码。
  • Disco57 在新基准的“zero-shot”是学习规则不重新元训练就能迁移，不是一个没有在该环境训练过的 Agent 已经学会了新游戏。
  • 13.86 是 Human-normalized IQM，不是 13.86% 正确率；不同环境的原始分数、归一化指标与平均回报不能放在同一量纲横向排名。
  • 约 40% 计算节省比较的是规定评估训练条件下达到 MuZero 最终表现所需 TPU 计算；没有计入 Disco57 使用 1,024 TPUv3×64 h 的发现成本。
  • Disco103 在 ProcGen 与 DMLab 上不再是严格未见任务（它们已被纳入其元发现集合）；未见领域结论须根据 Disco57 与 Disco103 分开。
  • 作者分析 y/z 对未来事件的可预测性及去除时的性能下降，支持它们具有有用语义，但不能断言发现的潜变量等同于人类可解释的完整 RL 理论。官方 GitHub 提供最小 JAX harness 与 Disco103 已发现参数，并声明后续不积极维护；不是一键复现论文全部大规模算力结果。
  • 固定元规则的迁移与部署中连续自主修改学习规则是不同的研究对象；论文未直接验证 LLM 知识长期内化、持续训练的遗忘/迁移或自主训练协议治理。
  • 多环境元优化天然可能偏向元训练环境分布；在 LLM 自生成任务/评价器下还会引入评价投机、数据泄漏、计算预算与安全风险，本文未解决。

核心机制 · 记住这几个公式

  1. 胜率与策略使用是两种不同的证据

    During 结果被人为固定后不能用胜率判断学得如何，但可计算参与者是否仍按旧规律选择奇偶类别。

    WinRate = #wins / #trials; OBR = #actions consistent with R/A strategy / #eligible actions
  2. 按上一轮反馈定义策略表达（OBR）

    对重复型对手，赢后保持奇偶、输后切换；交替型对手则相反。OBR分赢后与输后分别计算。

    R: Win-Stay / Lose-Shift; A: Win-Shift / Lose-Stay（按奇偶类别）
  3. 旧策略是否在 During 被抑制

    Pre 的 OBR 与 During 的 OBR 之差为正，说明匹配旧策略的行动比例降低；为负表示表达增强。

    Suppression = OBR_Pre − OBR_During; positive: suppress; negative: facilitate
  4. 恢复旧规律与学习新规律不等价

    Post 仍是可利用规律，但R→R、A→A对应旧策略恢复；R→A、A→R对应转向新策略。比较成功率与OBR差异，不能仅看有没有赢。

    Old = (R→R or A→A); New = (R→A or A→R)

核心机制 · 记住这几个公式

  1. 奖励必须先被解释，才能用于学习

    Goals条件额外要求把结果图片与当前目标比较，而不是像+1/+0一样直接得到奖励价值。

    outcome image → identify Goal/Nongoal → r_t → Q update
  2. 可压缩规则不同于重复实例

    能凭单个图形特征判定是否为Goal，可能比把每个结果图逐一记住更经济；实验2匹配了图形出现次数。

    shared outcome feature → reusable reward mapping
  3. 行为学习的价值更新

    delta-rule描述得到奖励后如何更新刺激—动作价值；奖励识别效率与学习率拟合相关，但不是长期记忆的神经证据。

    δ_t = r_t − Q_t(s,a); Q_{t+1}(s,a)=Q_t(s,a)+αδ_t

核心机制 · 记住这几个公式

  1. 语义重解释

    先用 [X] 把一组事实组织起来，再让少量自然语言关系示范对这批事实生效。

    Phase1 (s,[X],o) → Phase2 relation_prompt(s) → o
  2. Phase 2 留出 ≠ 从未出现

    泛化事实必须标记第一阶段已见而第二阶段未见；不能误称训练全程未见。

    seen_in_phase1 = true; seen_in_phase2 = false
  3. 两跳能力缺口

    记忆深度带来增益，但跨关系组合明显不可靠。

    2-hop generation 0.14 → 0.36; MC 0.08 → 0.16; ICL 0.95 (facts in context)
  4. RSI 核心区分

    正确回忆、语义访问、组合推理和未来持久收益是不同指标。

    Recall ≠ semantic access ≠ two-hop reasoning ≠ lasting learning

核心机制 · 记住这几个公式

  1. 预测引导的有限试错

    先预测候选效果和不确定性，用有限的真实测试预算优先验证有价值的候选；未执行的候选不能当作真实反馈。

    a* = argmax_a [predicted reward(a) - uncertainty penalty(a)]（机制理解式）
  2. 按需更新世界模型

    Policy 变强会改变候选分布，因此世界模型可靠性要按当前版本重新评价；证据或预算不足时不强行更新。

    update W iff unreliable(W) AND enough data AND enough budget（机制理解式）
  3. 策略—预测器联合保留

    策略与世界模型各自通过评估还不够，还须验证搭配后的真实收益；确保下一轮继承的是有效组合。

    retain(Policy', W') iff pass(Policy') AND pass(W') AND pass(pair)（机制理解式）

    zₓ = mean(y_visible) − mean(y_hidden)

  • 在 AIME 2026 的消融中，去掉 Recursive Learnability 后为 70.67%，换成固定 Skill 库后为 66.67%（完整方法 81.33%）。

限制与易错理解

  • L_rec 衡量小 KL 更新下的局部结果方差，不等于未来真实学习增益；冻结 Worker 的随机性也会制造结果方差。
  • 对照无偏性依赖固定任务/策略、随机分配和无干扰；记录在自适应选题与持续更新下会发生分布漂移。
  • 无 Skill 部署指不提供外部 Skill 文本，仍可调用冻结 Workers 和 Agent Graph；Proposer 主要从候选题库选题。

对我们的 RSI 研究有什么启发？

  • 对 I5 的十模型共进化：将“选下一道题”对应为“选下一位教学伙伴”，但不能直接用交互成功率替代学习后的独立能力提升。
  • 可复用 3/2 随机对照 + 后验决策的思路；实际迁移时应从同一学习者检查点分叉，等预算训练后在独立测试集比较无教师增益。
  • 把“辅助撤离”作为实验协议：验证 Skill/教师何时已不再贡献新收益，而不是只报告当前任务正确率。
下一步最值得做的辨别实验

在同一学生检查点上，比较不同教师、随机教师和无教师的等预算学习；以撤掉教师后的 held-out ΔAcc 与负迁移率，检验 L_rec 是否优于直接学习增益。

五问标签怎么理解？

四步读懂一篇论文之后，可以用这五个问题比较它研究到哪一步。重点研究指有直接方法和证据，不代表已经彻底解决。

信号对不对

评估分数和真实能力是否一致；评估器也在变化时，用什么独立证据校准它。

有没有新东西

自己出题、自己造数据时，能够纠正模型的信息究竟从哪里来。

采不采得到

高质量解法是否处在可采样的候选空间中，候选支持范围在哪一环节收窄。

吸收了会不会丢

改进进入权重、记忆或技能后，旧能力是否保留、错误经验是否被排除。

安全

评估器被绕过、越权修改真实系统、坏行为被持久记录三类跨环节风险。
