本章科学问题

下一步经历什么，才可能学到有用的东西？

识别能力缺口，构造有信息量的任务与交互，从教师、伙伴和工具获得新信息，选择与当前学习者相适配的经历。

按主要科学贡献归档；方法、能力载体和组织方式分别描述，其他功能中的作用通过交叉引用连接。

3.1 识别能力缺口与学习需求

系统首先要判断当前做不对什么，以及哪些缺口有可能被修复。不确定性、失败分布和能力边界提供线索；前置知识准备程度影响同一经历对不同学习者的价值。

要回答的问题：什么证据能区分缺少信息、缺少知识准备与缺少有效更新方式？

3.2 构造有信息量的任务与交互

自生成任务、探索、自博弈和环境交互都在创造学习机会。比较它们时，重点是新经历是否提供原先缺少的信息，或者能够排除当前混淆的解释。样本的表面变化应与规则变化分开。

要回答的问题：哪个例子或反例最能区分真实规则与当前捷径？

3.3 从教师、伙伴和工具获得新信息

教师、伙伴和工具是信息来源，也是系统组织方式。需要记录它们提供了什么、与学习者共享哪些盲点，以及所得信息能否改变后续能力。跨轮教法变化和伙伴重组在第6章集中讨论。

要回答的问题：伙伴贡献的是新信息、纠错线索，还是已有答案的重复？

3.4 选择具有学习价值的经历

难度、新颖性、覆盖度和失败类型描述经验的不同性质。学习价值还取决于当前知识状态与后续更新，应把选择依据与真实学习后的迁移、保持和成本连接起来。

要回答的问题：同样的失败，哪些值得学，哪些应该继续尝试或暂缓？

代表工作 · 机制与证据

代表工作主要解决的问题已有研读记录与证据范围
Hypothesis testing governs strategic motor learning [E26]用目标几何与辨别性试探研究竞争规则的探索。Ding 等用 560 人的两项视觉运动旋转实验改变目标几何；近目标组训练时进步较快但无反馈新位置迁移较差，8 目标实验匹配探针距离后仍有差异。支持局部成功与规则辨别需分开，但未检验 LLM 或难度 p=0.5。
Socratic Students: Teaching Language Models to Learn by Asking Questions [S24]学习向教师主动提问以获得所需信息。训练学生主动询问教师以改善学生的学习效率；不能把会追问的 Student 当作空白，需证明问题对 Teacher 自身能力有独立信息。
Self-Error-Instruct: Generalizing from Errors for LLMs Mathematical Reasoning [S40]从错误类型构造并筛选可用于训练的新数据。从模型错题聚类错误类型、合成数据，并用 one-shot 效果筛选微调数据；I8 不能声称首次按错误类型发现迁移价值。
When the Strongest Teacher Is Not the Best Teacher: Student-Centric Answer Selection (SCAS) [S102]依据学生学习成本从正确教师答案中选择监督。依据学生相关的学习成本代理，从已验证正确的教师输出中选监督；强教师不必给出最有用的训练答案。I2 不把答案选择或教师强弱比较声称为新机制。
R-Diverse: Mitigating Diversity Illusion in Self-Play LLM Training [S205]维持技能层面的新信息并缓解自博弈多样性幻觉。跨轮记忆和技能层面多样性用于缓解 self-play 表面多样而底层重复；I5 应以验证过的技能覆盖测群体同质化。本轮不沿用尚未核验的 ICML 录用标签。
Active Learning Helps Pretrained Models Learn the Intended Task [M61]主动选择能排除潜在任务歧义的样本。研究预训练模型如何利用不确定性选择可以区分潜在任务的样本；已直接讨论消除伪相关和任务歧义。I10 应进一步检验同样有区分证据时，LLM 实际参数更新后是否能形成独立规则迁移。
FisherSFT: Data-Efficient Supervised Fine-Tuning of Language Models Using Information Gain [M62]依据Fisher信息增益选择SFT经历。利用 Fisher 信息矩阵的近似信息增益选择固定预算的 SFT 样本；I10 不能把信息量最大化本身当创新，需区分规则证据与实际被参数更新吸收的泛化。
Prismatic Synthesis: Gradient-based Data Diversification Boosts Generalization in LLM Reasoning [M503]依据梯度空间多样性构造有泛化价值的训练数据。300多次受控训练；梯度空间G-Vendi与OOD泛化Spearman ρ约0.9；PrismMath-7B以32B教师生成数据优于部分强对照。说明有效多样性不是词面新颖，但不研究课程先后。
