先看五个发现：一个指标变好，另一个可能变差

我们想找的不是一个笼统的“泛化分数”，而是这些具体矛盾：现在学得快不快、换情境会不会、旧规则还能不能用、下一轮还学不学得动。下面先把洞见说清楚，再往下看原文和实验。

01原题学得快，换个情境却不会眼前学习速度 ↔ 真正规则的泛化能迅速解决练习，可能只是找到了局部有效的捷径。 02新旧规则越像，越可能互相帮忙，也互相干扰复用旧知识的收益 ↔ 新旧规则的区分与保持一起学时可能更费劲；先后学时也可能 B 学得快，却把 A 用错。 03练习时感觉更难，后来反而更会独立解题练习时的顺手感 ↔ 延迟记忆与新题解法选择把不同题型穿插起来，可能比一路套同一公式更能训练“何时用哪种方法”。 04今天的模型更强，明天却可能更难继续学当前训练表现 ↔ 后续适应性与旧能力保持继续训练不一定只带来收益，也可能让下一次参数修改更困难或更容易破坏已有能力。 05准备阶段看不出多强，下一次教学才显出优势眼前产出与准备成本 ↔ 下一阶段真正学到多少有些经历的价值，不在当场多答对几题，而在后来接受相同教学时学得更多。

研究目标不是一律“学慢一点”或“少复用旧知识”。我们要找出什么时候出现代价，能否通过改例题、分清规则适用条件、调整练习顺序，尽量同时改善多个指标。这些关系也不一定是无法突破的取舍。

从发现到办法：其他领域怎样处理，LLM／RSI 可以怎样做？

每条都沿着同一个顺序读：观察到了什么 → 哪两个指标在牵制 → 原领域有什么办法或线索 → LLM 怎么试 → RSI 学会怎样选择。原论文的结果与下面标出的 LLM／RSI 提案分开；提案还没有在本项目中运行。

01

学得快，可能是找到了捷径；学得慢一点，反而学对了规则

原目标学习速度↔新位置的规则泛化

原研究发现：在光标旋转任务中，某组训练位置允许“旋转”和局部“平移”等不同方法都做对。参与者进步较快，换到新位置却常暴露错误策略；另一组位置更能排除错误解释，前期较慢，之后更一致地使用正确旋转规则。[E26]

原领域的办法
改变练习位置，让捷径不再好用；用不给答案的新位置检验。关键不是故意让人学慢，而是让训练真正区分不同解释。
LLM 怎么试待检验
少加一些换词重复题，多加正确规则和错误捷径会给出不同答案的反例。在相同训练量下，同时看原题进步与未见条件题的正确率。
RSI 进一步做什么待检验
Agent 根据过去的纠错结果，逐步学会挑出“能揭穿当前错误规律”的下一道题，而不是总挑最容易涨分的题。对应 I10 与 I8。

一起测：训练进步速度、新条件正确率、总采样与训练成本。

证据说明：这里的“捷径”不是已经测到的“快脑回路”

对应 Ding 等 npj Science of Learning 2026 的行为实验，不是 Nature Communications，也没有直接测量快速/慢速脑回路。实验改变的是哪些错误假设在训练中仍可成功，不说明“所有慢学者都更理解”，也不说明主动增加无效尝试能提高学习效率。读完整实验 →

02

旧知识能帮新任务上手，也可能把两套规则搅在一起

共享规律带来的迁移↔新旧任务的区分与保持

先分清两种观察：NC 2025 的交错训练中，共享结构的任务反而出现更大的初期干扰，继续练习后差距缩小；NHB 2025/26 的 A→B→A 实验则发现，Near 规则使 B 更容易上手，但返回 A 时更容易误用 B。一个是初期一起学更难，一个是新任务学得快却损害旧规则。[E99][E100]

原领域的线索
NC 中练习后的表征逐渐分开，干扰减轻；NHB 的计算模型中，较独立的表示减少干扰，却牺牲部分迁移。启发是共享相同部分，明确区分不同规则的使用条件，而非全部混合或全部隔离。
LLM 怎么试待检验
对相似但答案不同的任务，补充“什么条件下用 A、什么条件下用 B”的成对例子；与普通混合训练、旧题回放、独立 Adapter 比较，检查 A/B 以及混合情境。
RSI 进一步做什么待检验
Agent 在发现规则错用后，学习判断应该补适用条件、重学旧规则，还是拆成独立 Skill。以实际修复结果改进下一轮判断，对应 I3，而不是只给每个任务新增一个模块。

一起测：B 的学习速度、返回 A 的规则错用率、新组合泛化、隔离与修复成本。

证据说明：相似不一定冲突，也没有“越相似越难学”的通则

完全相同的规则可以直接复用；真正需要区分的是输入/情境相近而输出或适用条件不兼容的情况。Menghi 的 NC 实验不是直接操纵“新规则与旧规则矛盾”，后期泛化也没有显著组间差异。Holton 的人类结果并非“慢者泛化更好”：其中共享规则的 Lumpers 迁移和泛化较好，代价是旧任务干扰。NC 精读 · NHB 精读

03

一路练同类题很顺，打乱以后反而更会自己选方法

练习时的顺手感↔延迟记忆与新题解法选择

原研究发现：本科物理学生练同一批题，只改变集中或交错安排。交错组觉得更难、以为自己学得更少，却在之后不预告、包含新组合的测试中表现更好。这里首先分离的是主观学习感受与真实后测，不能把它改写成“训练速度一定更慢”。[E20]

原领域的办法
穿插不同题型，并延迟检验。学习者需要辨别这道题该用哪种方法，不能依赖上一题的公式一直做下去。原物理研究保持总题目不变。
LLM 怎么试待检验
固定数据总量，比较集中练习、完全交错和先集中后交错；先后检验单类题、混合题及未见组合。不能因为人类受益，就预定交错对 LLM 也最好。
RSI 进一步做什么待检验
当 Agent“单类会做、混合会选错”时，尝试改变课程；基础规则都没学会时，先试集中练习。让真实后测而非当前训练 Loss 决定何时切换，对应 I9。

一起测：练习表现/学习感受、延迟新题成绩、混合题规则选择、同预算学习收益。

证据与方案边界

Samani 与 Pan，npj Science of Learning 2021，是课程作业顺序的对照研究；“先集中后交错”和按模型状态自主切换是我们的候选方案，不是该论文已验证的结论。查看原论文。

04

当前训练更充分，不代表下一轮更容易学

当前能力与训练投入↔未来适应速度、旧能力损失

原研究发现：Nature 2024 在持续训练的深度网络中观察到，后来学习新任务的能力逐渐下降；ICML 2025 的语言模型研究则发现，部分预训练更久的模型微调后结果更差。学不进去，与一改参数就破坏更多旧能力，是需要分别检查的两种解释。[M22][M554]

已有机器学习办法
Nature 的 Continual Backpropagation 少量重置低使用价值单元，为新特征保留空间，在所测网络中缓解退化。它不是对大型 Transformer 或旧知识保持的通用保证。
LLM 怎么试待检验
从冻结检查点复制模型，给相同新任务与监督，比较学习曲线；控制学习率和优化器状态，再比较继续更新、新 Adapter、已有塑性保持方法，同时测旧能力。
RSI 进一步做什么待检验
版本选择不仅看本轮涨分，还看下一轮是否更难学；学习器若已经迟钝，可检验换更新方式或隔离学习，而非继续盲目加步数。I14研究更新规则本身，I9仍只改变课程顺序。

一起测：当前成绩、未来 C 的完整学习曲线、旧能力保持、所有试训和恢复成本。

哪些已经有证据，哪些仍待验证？

参数网络的塑性损失不能直接解释只修改 Prompt/Skill 的 Agent。后者需要独立研究规则冲突、错误记忆或编辑器限制。外接专家可以维持系统表现，却不等于核心模型恢复了学习能力。Nature 精读 · ICML 论文。

05

有些准备现在看不出收益，却让下一次教学更有效

眼前产出与准备成本↔接受相同新教学后的学习增量

原研究发现：Schwartz 与 Martin 的人类统计教学研究中，先做发明式探索与直接讲授练习两组，在无新资源的迁移测试中表现相近；给出可供继续学习的新资源后，前者学得更好。它提示某段经历的价值可能要在下一次学习才显现，并不是已经证明一种因果前置补救算法。[E710]

教育学的办法
先让学习者接触需要解释的差异，再提供正式讲解；评估时允许两组使用同样的新资源，看谁更能从中受益，而不只考已经知道的答案。
LLM 怎么试待检验
把“先探索”“补关键基础”“直接练目标题”分成不同实验，不混作同一机制。第一阶段花相同预算，第二阶段给相同新任务训练，分别记录即时收益与后续新增收益。
RSI 进一步做什么待检验
Agent 从失败里判断是否缺少可核验的基础 P；只有补 P 后真的提高多个新任务的第二阶段学习增量，才继续投入。对应 I12；先试后教的顺序则归 I7。

一起测：准备成本、准备后立刻会做多少、下一段训练额外学会多少、跨多个后续任务的总收益。

效率限制：不是要求每题都先失败很久

这里保留的是“评估后续学习收益”的思路，不是把昂贵多样化探索设为默认策略。若直接纠错、直接练目标题在总预算下更好，就不走准备路线。研究者要区分原文的发明活动、我们提出的先修知识补救，以及真正的长期成本收益。

LLM 层先检验“哪一种处理真的有效”，RSI 层再研究“系统能否从历史后果中学会选择合适的处理”。不要在基础现象还没有复现时，先把五种做法拼成一个大控制器。

用一道小题理解“捷径”这些权衡分别归哪个 I？进入三组决定性实验

先看一个例子：两个人都做对题，为什么我们还说学得不同？

同一道训练题

两个模型都答对了

题目给出三个数字。真正的规则是“前两个数字相加”，但模型也可能误以为是“第一个加第三个”。假如练习里后两个数字碰巧总一样，两种做法都能答对。

换一个关键条件

差别立刻出现

输入 (3, 2, 5)：正确规则算出 5，错误捷径却得到 8。原来都答对，不代表学到了同一条规则。

这还只是第一层差别。再假设我们给两个模型一组从没学过的新规则 C，并让它们接受完全相同的新训练。它们现在看起来一样强，下一轮却可能一个学得快、另一个学得慢。

这页想讲清两个问题：（1）模型到底学到了什么规则？（2）过去的学习，会不会改变它以后学习新规则的能力？第二个问题不是简单的“换一道相似题还能做对”。

先弄清我们要测什么为什么会出现这种差别我们的 I 在研究哪一步怎样做真正的实验

以上数字题是为了说明实验区别而设计的例子，不是某篇论文报告的结果。本专题是跨 Idea 的研究笔记，不新增编号；实验仍待验证。

“学会”至少有五种意思，先不要混在一起

我们过去经常说“泛化能力提高了”，但这句话可能指五件完全不同的事。先看日常说法，再看论文指标。

01

现在做得对吗？

刚练过的题能做对。也许理解了，也许只是背下了答案。

02

换一个关键条件，还知道该用哪条规则吗？

把“后两个数字总相同”这个巧合打破，看模型是不是仍按正确关系计算。这里检验真正掌握规则。

03

不再教它新东西，能直接做多少新题？

把旧知识拿去解决相似任务，叫直接迁移。但此时还没有发生下一轮学习。

04

给它同样的新教学，后来谁学得更多？

这是我们最关心的未来可学习性：比较真实训练之后的整条进步曲线，不能只看新题的初始分数。

05

学了新知识以后，旧知识还在吗？

还要返回旧题，看是不是忘了、用错了规则，或在其他场景出现退化。

最容易混淆的是第 3 和第 4 项：以前学会加法，所以没经过训练就能做一道新加法题，是迁移；以前的学习让模型下一轮更容易掌握一条陌生规则，才是未来学习能力的改变。

L4 · 长期保持A→B→A、延迟测试、旧/新规则组合只报最新任务一个总分

这里的标签是本专题的评价约定，不是某篇论文提出的一套通行分类。原文证据见学习与表现分离综述、MLC、可塑性及规则干扰研究。[E711][E350][M22][E100]

学得会和现在会做，可以是两回事

这意味着不能简单把模型排成“聪明”和“不聪明”两类。下面四种状态都值得在实验里单独找证据：

现在懂，也容易学新东西

旧规则能正确使用，遇到新规则也保留了调整空间。

现在懂，但以后学得困难

旧题很强，新规则需要改写原有表示时却学不进去，或一学就损害旧能力。

现在还不懂，但教对了就能学

当前依赖捷径；一旦看到真正能区分规则的示例，就可能快速纠正。

现在不懂，继续教也收效很小

可能缺前置知识，可能有规则冲突，也可能是当前更新方法不合适。

这四格是研究者组织问题的假设分类，不是说已有论文测出了四种模型类型或它们的比例。未来学得难，不能直接归因于“模型不够聪明”。

为什么学得快，有时反而会埋下问题？

现在把很多看似相似的论文放在一起，就能发现四种不同原因。它们可能相互作用，却不能预先说成同一个机制。

原因一：练习太像，根本没有逼它学正确规则

换了十种题面，但错误捷径依旧能蒙对。真正有价值的可能是那一道让两条规则给出不同答案的反例。对应 I10 的规则区分，以及 I8 的纠错价值。[E26][M17]

原因二：把新规则学在了旧规则上

旧规则能帮助新任务快速上手；如果新旧规则只差一点，却共享同一套表示，之后返回旧任务就可能套错。Holton 的 A→B→A 人类实验正是这类现象的证据。[E100]

原因三：模型做对题的方法在悄悄改变

继续训练，成绩可能变好，但模型可能从“看当前例子推规则”转向“记住训练映射”，也可能经过很久才形成真正的泛化算法。必须在训练中间检查，不只是最终成绩。[M552][M553]

原因四：前面学了什么，会改变后面能不能学

好的前置知识可能为新规则搭基础；长期训练也可能让模型越来越难更新。前者需要验证真正的先修关系，后者需排除优化器状态和学习率等原因。[E401][M22][M554]

所以，“学得更快”不是好坏的最终判断。还要问：是复用了正确的规则，还是借用了错误的捷径？这次学得快以后，旧能力有没有损害？以后遇到不相容的规则，能不能再学？

这些想法不是突然出现的：从教育学到模型自我改进

为什么我们要把“今天做对”和“以后学得快”分开？这条线在教育学里早就出现了，只是后来被机器学习、元学习和持续学习从不同角度重新研究。

2004

先前的学习，可能让下一次教学更有用。Schwartz 与 Martin 研究了中学生的统计学习：仅看没有新资源的测试，两种教学安排可能相近；但再给一份新学习资源，先前经历带来的差别才显现。这叫 Preparation for Future Learning，通俗说就是“为下一次学习做准备”。[E710]

2015

练习时顺利，不保证后来记得住或会应用。学习心理学综述提醒我们，训练时的表现与长期学会了什么要分开。这不是“越难越好”，而是“当下顺利不能作为唯一标准”。[E711]

2017—2020

元学习开始直接研究“换一道新任务，怎样少训练就学会”。MAML、OML 等方法已经让快速适应与旧知识干扰成为正式优化对象；但 ANIL 又发现，在某些实验中所谓快速学习主要来自已有的好特征，只需训练最后一层。[M21][M551][M550]

2023—2025

模型训练得更久，不代表一直用同一种方法做题。研究者观察到模型可以先学会从上下文推规则，随后又更依赖权重中的固定记忆；另一类受控任务则要过很久才出现可泛化算法。只看 Loss 很容易漏掉变化。[M552][M553][M11]

2024—2026

今天能力不错，明天可能越来越难学。Nature 的可塑性论文、ICML 的过度预训练研究和充分回放下的持续学习研究，都提示后续学习有自己的困难；其中更新对象和故障机制并不完全一样。[M22][M554][M555]

把这些文献连起来，专题的问题就清楚了：一个模型过去学到的，不只是答案，也包括用来表示和调整知识的方式。我们想知道哪些经历能真正改变下一次学习，而不只是提高本次考试分数。

展开：每个研究阶段与我们还没有验证的部分

教育学的人类学习资源实验，并没有在 LLM 中训练 LoRA；MAML/OML 不能证明某种特定规则区分样本更有用；ANIL 在特定少样本任务中的特征复用结果，也不能推广到所有语言模型；Grokking 与暂时性 ICL 的内部解法分析，使用了受控的小规模任务。当前我们提出的“学习历史 → 规则掌握 → 未来 C 真实训练”仍是待检验的因果链。

更直接的近邻还包括 ICML 2026 的顺序 Lie-bracket 分析以及2026年预印本的未来可学习性读出层诊断。它们已研究训练顺序与可塑性，所以不能声称“首次发现学习顺序影响未来能力”。[M18][M20]

我们以前读过的论文，分别解释了哪一段？

这一组论文不要按期刊名字背，而要按它们真正回答的问题来读。每篇下面保留了完整精读入口，方便需要时核对原文实验。

第一组：它是真的学会了规则，还是碰巧做对？

Hypothesis Testing（npj 2026）：训练时做对，不一定能在新的运动位置上识别同一规则；最好设计能排除错误解释的试验。[E26]

Mosaic Memory（Nature Communications 2026）：表面不同的样本，仍可能一起强化同一段记忆。换措辞不等于学到了新的规则。[M17]

MLC（Nature 2023）：模型可以学会一部分新组合，却仍在某些结构外推任务上失败；组合泛化也有不同层次。[E350]

第二组：学新任务为什么会伤到旧任务？

Holton（Nature Human Behaviour 2025/26）：新旧规则相似时，B 学得更快，但返回 A 时更容易错用 B 的规则。[E100]

Menghi（Nature Communications 2025）：交错学习时，即使任务有共享结构，初期也可能更难；后来可能逐渐消除干扰。[E99]

Tian（Nature Communications 2026）：灵长类能复用类似任务的决策结构，但当规则反转，旧结构也可能带来困难。[E320]

第三组：过去的经历怎样改变“下一次学习”？

训练分布与策略竞争（NHB 2025/26）：练习样本的重复与多样性，会影响记住固定映射还是根据当前上下文推规则；人类有效的安排不必然同样帮助小 Transformer。[E360]

Loss of Plasticity（Nature 2024）：连续训练很长时间后，模型可能越来越难学新任务；这与简单忘掉旧知识不同。[M22]

Centaur（Nature 2025）：可以从大量实验行为预测人的选择，但“能预测学习者怎么回答”还不等于“能预测它真实训练后会提高多少”。[E701]

第四组：能不能让下一轮的学习过程也更有效？

SOAR（ICML 2026）：教学价值应该看学生真实训练后进步多少，而不只是老师生成题目的当前成功率。[S47]

策略层学习（Nature Human Behaviour 2025/26）：反馈可能改变学习者对一类决策规则的依赖，而不只是强化某一个动作。[E311]

这里的人、动物、简单人工网络和大型语言模型属于不同研究对象。我们借鉴的是实验提出问题的方法，不是认为这些论文已经在 RSI 系统上证明了同一套机制。

新补查的顶刊顶会告诉我们：哪些想法前人已经研究过？

新调研的重要意义，是帮我们避免重复发明。下面先说最接近专题的三个结论，再给出完整论文对照。

“学完以后，更会从下一次教学受益”不是新概念

教育学在 2004 年就提出 Preparation for Future Learning。我们的新实验必须进一步测：真实模型权重或 Skill 更新后，接受同样下一阶段训练，谁获得更多独立新增能力。[E710]

“少练几步就学得快”，可能只是旧特征刚好够用

ICLR 2020 的 ANIL 在其少样本设置中发现，只更新任务头部就能取得与 MAML 类似的效果。我们的实验要比较冻结主体、只更新少量参数和完整更新，而不是直接把快适应叫作学会新规则。[M550]

“训练更久”，可能更难在下一轮改变

ICML 2025 的过度训练研究，以及 ICLR 2026 的充分回放研究都说明：旧知识保留、当前分数和未来学习难度并不是同一个量。[M554][M555]

展开九篇新增文献：论文具体做了什么、哪些结论不能照搬

Schwartz & Martin · Cognition and Instruction 2004：先发明再接收新资源，可能比直接教学更能为下一次学习做准备；研究对象是人类中学生，不是 LLM 参数训练。[E710]

Soderstrom & Bjork · Perspectives on Psychological Science 2015：练习中的高表现不等于持久掌握；这是一篇综述，不提供适用于所有模型的“困难越大越好”定律。[E711]

Raghu et al. · ICLR 2020：ANIL 表明某些快速适应的收益主要是特征复用；需要独立测真实主体参数更新。[M550]

Javed & White · NeurIPS 2019：OML 已将快速适应与降低持续学习干扰结合起来；不能首次宣称要兼顾两者。[M551]

Singh et al. · NeurIPS 2023：合成任务里模型先有上下文学习能力，后被权重记忆取代，尽管训练 loss 继续下降。[M552]

Nanda et al. · ICLR 2023：对受控模加 Transformer 追踪记忆与泛化电路的形成和清理；不能说所有 LLM 都按同一个阶段变化。[M553]

Springer et al. · ICML 2025：延长部分语言模型的预训练，后续微调成绩反而可能变差；这不等于每种训练越多越不好。[M554]

Cho et al. · ICLR 2026：有大量旧数据可回放，也不能自动解决学习新任务时的塑性问题。[M555]

Irie & Lake · Nature Machine Intelligence 2025：以激励和练习组织对多种人工网络学习困难的观点综述，不是统一因果实验。[M556]

怎么证明“下一次更会学”？先看这组示例数字

假设我们有两个已经经历不同学习历史的模型。现在给它们一套之前完全没学过的 C 规则，先测一次，再给相同的新教学，再测一次。下面数字只用于讲清比较方法，不是实测结果。

模型学 C 之前同样训练之后本轮进步
模型甲40%70%+30 个百分点
模型乙55%75%+20 个百分点

乙最后成绩更高，甲这轮进步更多。我们能不能就说甲“以后更会学”？还不能。乙起点更高，可能更接近天花板；而且下一轮如果换一类冲突规则，优势可能反过来。

因此要从第 0 次训练开始，持续记录每一段进步，并同时测旧任务有没有退化。不能只拍一张最终成绩截图。

展开：正式公式、学习曲线和统计口径

记 H 是以前的学习历史，SH 是学习历史结束后的模型，C 是新的任务族，b 是在 C 上实际继续训练的预算。把独立 C 测试表现写作：

L(H,C,b) = Perf( Update(C,b)(S_H), Test_C )

直接迁移是没有学C时的 L(H,C,0)；后续学习响应是 G(H,C,b)=L(H,C,b)−L(H,C,0)。两条历史的增量差：

Γ(C,b) = [L(H₁,C,b)−L(H₁,C,0)] − [L(H₂,C,b)−L(H₂,C,0)]

不能只报 Γ；必须给绝对曲线、初始C成绩、到达阈值所需训练预算、学习曲线面积、旧能力回归与所有额外诊断成本。若外部答案仍在上下文，就不能把分数提高认定为核心参数学到了新知识。

新任务不能全是旧题变体：至少准备三类新规则

为了判断模型只是会复用旧知识，还是更广泛地“以后容易学”，我们不能只选与过去非常相似的新任务。建议提前冻结三组不同关系的新规则 C。

C₁：和旧知识相容

例如会一维坐标变换后，再学习二维组合。旧知识确实能帮忙，但仍须掌握新组合。

C₂：很像旧规则，却有关键冲突

例如两个工具的输入格式几乎相同，但一项关键操作条件不同；该用哪条规则必须看情境。

C₃：与旧知识关系较弱

例如先学数字变换，再学一个独立的字符串操作规则。用来检查效应是否只发生在相关任务上。

如果某种历史只提高了 C₁ 的表现，我们就说它帮到了相容任务。不能直接夸大成“所有新知识都更容易学”。C₂ 还有可能出现负迁移，C₃ 则是检验较广泛可塑性的对照。

展开：实验中需要固定什么，才能作因果解释？

保持相同底座检查点、模型参数可训练范围、训练总 token、学习率、反馈格式和后续C更新器。任务族按规则结构而不仅题面文本划分训练/开发/最终测试。每条历史报告所有随机种子，不能事后根据C最终成绩挑出“刚好同分”的版本。进入C主分支重置 AdamW 优化器状态，并将继承动量作为补充对照。每一次候选筛选、诊断试训与验证器调用都计入成本。

如果仅在 C₁ 观察到差异，还要用只训练读出层/冻结主体的基线，排除“现成特征刚好有用”的解释。相关近邻包括 ANIL、OML 与2026年可塑性诊断研究。[M550][M551][M20]

论文级 Method｜从观察现象升级到可解释、可操纵的学习机制

PROPOSED METHOD · MECHANISM FIRST · NOT YET EXECUTED

Rule-Contrastive Preparation & Future-Learning Assay（规则对照式准备与后续学习测量）

论文的单一主张：历史训练即使带来相近的当前正确率，也可能留下不同的规则选择方式及适用边界。这些差异会影响后来学习新规则 C 的响应；有针对性地排除错误规则，可能改变这种响应。我们用规则层面的诊断 + 随机干预 + 真实参数更新检验，而不是只比较期末成绩。

规则生成器正确规则与可执行的竞争捷径
匹配历史分叉同底座、同材料，改变顺序或信息
不反馈的规则探针分歧、组合、适用边界
小预算针对性补救规则分歧例 vs 表面新颖/难度/随机
新 C 真实更新相容/冲突/无关，完整学习曲线+旧能力回归

三个有因果次序的问题：Q1 同样的当前任务成绩是否隐藏不同的规则状态？Q2 这种状态和 C 的学习轨迹有何关系，能否排除梯度几何、C 前测和参数可塑性等解释？Q3 给定同样的补救预算，只改变旧任务中的规则辨别信息，能否主动改变其后的 C 学习效率？Q1 是现象、Q2 是机制鉴别、Q3 是机制干预。Q3 不成立时也应如实保留 Q1/Q2 的结论。

方法贡献的准确边界：基于竞争假设选分歧样本已有 Query by Committee（COLT 1992）；控制抽象特征的反事实增强已有 Findings ACL 2025。[M557][M558] 本方案的潜在新增贡献不是“第一次选择反例”，而是先诊断学习者形成哪种规则，再用受控补救检验其对新规则真实学习曲线的因果影响，并将起点迁移、更新能力与旧能力回归分开。

Design 1｜可执行竞争规则图：把“会做题”与“学对规则”分开

展开：竞争规则图、具体示例和三类分歧样本

形式化任务：每个规则族用一组有限、可执行的程序组成 R={r₁,…,rₘ}，每道题有输入 x、情境 c 和唯一 oracle 答案 r*(x,c)。真实规则与至少一种竞争捷径在旧训练样本上给出相同输出，但在专门构造的输入上必须发生分歧。程序解释器只保存在实验环境/独立验证器中，不作为提示泄露给学生模型。

可直接理解的示例（列表规则）输入与答案实验作用
旧训练样本：保留首次出现的元素（正确）vs原样返回（捷径）[2,1,3] → [2,1,3]两种规则都正确，普通训练得分无法区分
分歧 witness：只改变“是否有重复”[2,1,2] → [2,1]；捷径会输出 [2,1,2]直接排除错误规则，检验真正掌握
边界 witness：情境切换到“保留最后一次出现”[2,1,2] → [1,2]（按保留元素原始位置排列）检验是否把旧规则错用到新情境
无效对照：重写题面、换整数，仍无重复[7,4,3] → [7,4,3]表面不同，但无法区分两个竞争程序

构造方法：枚举程序长度受限的候选规则，形成与当前训练集一致的版本空间 V(D)={r∈R:∀(x,y)∈D,r(x)=y}。从同一合法输入域选出三类测试：Wsep（候选规则给出不同答案）、Wbind（情境字段决定选择哪条规则）、Wnull（候选规则结果一致但文本多样）。根据 oracle 输出自动标注、检查歧义比例、题长、标签频次、规则复杂度和输入距离，不人为挑中看起来成功的题。

防止“只是更难”的混淆：把规则可辨识性 D、结构组合覆盖 K、词面变化 L、A/B 相似度 S 分别作为可操作变量。匹配输入长度、表达式深度、输出格式、目标正确率区间及训练 Token；允许不同组在训练难度上仍不完全相同，但明确展示这些统计与控制，而不将其假定为相等。ICLR 2024 Shortcut Learning 已用受控生成器隔离线索的预测性与可获得性；npj 2026 Hypothesis Testing 用第二实验控制初始空间距离。我们也必须设置第二轮排除替代解释的实验。[M559][E26]

数据结构可复用：family_id, rule_id, context_id, program_ast, input, oracle_output, distractor_outputs, witness_type, surface_template, depth, split, seed。训练、诊断、补救和最终C测试使用互斥输入与模板；最终留出整批规则族／组合图，而不只随机划分题面。

实验二：材料完全一样，只换学习顺序，以后学新规则会不一样吗？

这就是 I9 最值得先验证的实验。

让两个模型从同一个起点学习同一批 A 题和 B 题：甲先集中学 A 再学 B，乙先学 B 再学 A。题目、答案、总训练次数和优化方法都不变。学完先测两者现在会不会 A/B。

然后才是关键：给两个模型同一批之前从未见过的 C 任务，真正再训练它们。训练第 0、1、5、10、20……步都测 C 的独立新题，观察谁学得更快、最终谁更准，同时返回检查 A/B 有没有受损。

如果只在学 C 之前就已经更强

更可能是旧知识直接迁移了，不能据此说明后续学习能力变好。

如果一开始差不多，之后学习曲线分开

这才是我们要继续解释的现象：究竟是旧规则组织不同，还是优化器/特征复用等其他原因？

如果相容的 C 学得快，冲突的 C 反而学得慢

说明复用旧规则既可能有帮助，也可能产生干扰。不能只挑表现好的新任务。

这个实验还要求保留全部模型，不只挑一两个事后恰好成绩相同的 checkpoint。应该先随机分配学习历史，再按预先约定的开发集做当前能力匹配分析。

展开 P1：现有工作、优化器与统计控制

应同时比较 A→B、B→A、集中练习与交错练习。后续新规则 C 分为相容 C₁、冲突 C₂、较弱相关 C₃，主分支重置 AdamW 动量；另一支保留状态。报告完整绝对曲线、起点、阈值成本、曲线面积及旧任务回归。

Lie-bracket 顺序分析已研究某一目标上的更新排序，Ren 等预印本已提出未来可学习性诊断；ANIL 说明只用现成特征就能出现快适应。必须把这些当近邻对照，不能直接宣称首次发现训练历史影响学习速度。[M18][M20][M550]

实验三：先补一条基础知识，能让原本学不会的题以后学得会吗？

这对应 I12，也是最贴近教育学“为下一次学习做准备”的问题。

设想一个数学 Agent 总是做错“两个坐标变换接起来”的题。可能不是这些目标题都太难，而是它根本没有掌握“变换的先后顺序”这条基础规则。

第一段

一组先补真正需要的基础 P；另一组花相同时间学一个看起来相关、但不是必需的规则 H。

第二段

两组接下来接受完全相同的新目标任务 T 教学。撤去第一段的示范，真实更新模型，再用独立新题测试。

最后比较

不仅看补完 P 就直接多做对几题，还要看第二段 T 训练本身多教会了多少。

例如 P 组补完基础后，T 立刻从 20% 涨到 40%，但再学 T 后仍是 40%；这说明补 P 有直接帮助，却不能证明它提高了以后学 T 的能力。只有第二段仍取得超出等预算对照的新增收益，才支持“解锁后续学习”。

展开 P2：怎样排除“多学了一会儿所以更好”

对照至少包括：真前置 P、语义相关但不必要的 H、直接把同样预算花在 T 上、已经会 P 的模型，以及仅在上下文临时提供 P 而不更新参数的分支。按任务的真实依赖关系预先冻结测试，不让诊断器读取依赖图真值。

正式报告第一段结束时 T 的立即变化和第二段学习 T 的新增增量。只在真正依赖 P 的新任务中稳定提高第二段增量，且强于相关非前置和直接练题，才是先修机制的有力证据。[E710][E401][S47][M27]

最后才到 RSI：Agent 能不能逐渐学会怎样让自己学得更好？

如果前面三个实验都没有找到稳定差异，我们就不该先写一个庞大的“泛化控制器”。如果确实存在差异，再问下一步：

Agent 经历了几轮真实学习以后，能不能比过去更准确地判断：哪个错误值得纠正、什么时候该交错练习、先补哪条基础，以及同样训练材料该采用哪种更新规则？

这里每一个 I 都必须独立做自己的选择实验。例如 I14 要保持学生、材料和课程完全相同，只改变“模型如何更新参数”的规则；I9 则必须固定更新器，仅改变顺序。不能哪个组件变了就把收益归给哪个。

真正的 RSI 证据是：把新版和旧版学习决策器放在同一个任务模型、相同任务和预算上，在没见过的新任务里，新版能让学习者获得更多独立能力。只把旧答案存得更多，或者多花预算多训练几轮，不是同一个结论。

另外，I13 单独检查自我更新的安全接纳与后代风险。一般学习收益或规则错用，不能替代真实授权和安全执行验证。

主终点：对每个新规则C，在固定预算范围内计算 AULG(H,C)=AUC_b[L(H,C,b)−L(H,C,0)]/B（归一化学习增量曲线面积）；同时把 AULC=AUC_b[L(H,C,b)]/B 作为同等重要的绝对表现。E1的主对比预先固定为 Blocked vs Interleaved 的 C₂-AULG 与 C₂-AULC，History×C类型作为主要机制交互；C₁和C₃整体报告。E3的主对比固定为 RCP vs Random 的 C₂-AULG，QBC为预设强基线。AULG在C起点高、接近上限时自然受到压缩，所以不能单独据此排名。

ΔHistory(C) = AULG(H_interleaved,C) − AULG(H_blocked,C)
ΔRescue(C) = AULG(H_RCP,C) − AULG(H_random,C)
